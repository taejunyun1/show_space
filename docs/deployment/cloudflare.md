재배포: `npm run deploy` (빌드 후 Wrangler 배포). 해당 계정 로그인이 필요하다. `gonggan-exhibition-shares` R2 버킷을 `SHARES`로 연결했다. 공개 URL에서 R2 원본 객체 주소를 직접 노출하지 않고 Worker가 활성 링크 상태를 확인한 뒤 이미지와 스냅샷을 반환한다.

공유 링크 생성·목록·중단에는 Worker 비밀 변수 `OWNER_TOKEN`이 필요하다. 이 작업에서 생성한 키는 저장소의 Git 무시 파일 `.env.share-owner-token`에 0600 권한으로 보관하며, 공유 창의 **작성자 키**에 붙여 넣는다. 소스나 GitHub에는 포함되지 않는다. 다른 기기에서 작성자 기능을 쓰려면 키를 안전하게 옮겨야 한다. 현재는 단일 작성자 키 방식이며 계정별 로그인·소유권 분리는 후속 단계다.

2026-09-27 임시 줄자 배포 검증: 자동 테스트 453개 통과·2개 건너뜀, 빌드 통과. 공개 HTTPS에서 치수 공개 링크를 새로 발행해 평면과 3D에서 두 점 거리 표시를 브라우저로 확인했다. 콘솔 경고·오류는 없었다. 검증용 링크를 중단한 뒤 공개 스냅샷 요청이 410을 반환함을 확인했다. 390px 브라우저 뷰포트에서 평면 줄자와 3D 화면 맞춤을 확인했으며 모바일 실기기 검증은 남았다.

2026-09-27 검증: 자동 테스트 449개 통과·2개 건너뜀, 빌드 통과. 공개 HTTPS에서 예제 작품 1개가 포함된 링크를 발행하고 별도 브라우저에서 3D·벽면 이미지 및 읽기 전용 화면을 확인했다. 직접 수정 요청은 405/409로 거부됐고 링크 중단 뒤 스냅샷·이미지는 모두 410을 반환했다. 검증용 공유 링크는 중단했다. 공개 브라우저 콘솔 오류는 없었다.

배포 전 빌드 및 테스트 129개 통과. 공개 HTTPS에서 3D 렌더링과 숫자 테스트 이미지 업로드의 자동 OCR/선 분석 확인(숫자 표기 5개). 브라우저 오류 로그 없음. 테스트 이미지는 채택하지 않고 취소했다.

편집 프로젝트는 브라우저 IndexedDB에 저장한다. 로컬 주소에서 작업한 데이터는 공개 주소로 자동 이전되지 않으므로 JSON 내보내기/불러오기로 옮긴다. 공유 버튼을 눌렀을 때만 공개 허용 목록의 현재 배치와 작품 이미지를 R2로 올리며 원본 도면·메모·분석 기록은 올리지 않는다. 편집 프로젝트의 계정 로그인·서버 저장·동기화와 전체 전시장 자동 생성 마일스톤은 미완료다.
