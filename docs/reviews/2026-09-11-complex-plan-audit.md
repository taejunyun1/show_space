# 복잡한 도면 대응 점검

## 결론과 검증 범위
현재 구현은 도면 참조 이미지와 수동 벽 편집기다. 복잡한 도면의 자동 해석·정확한 3D 복원을 검증한 상태가 아니다. 작업 폴더에서 실제 사용자 도면 PDF/스캔 원본을 찾지 못했다. 아래는 코드 확인에 따른 문제와 후속 검증 계획이며 실제 도면 인식률을 의미하지 않는다.

## 구현에서 확인한 문제

| 우선순위 | 문제 | 근거 및 영향 | 필요한 변경 |
|---|---|---|---|
| P1 | 이미지 도면의 세부 정보 손실 | planImport가 작품용 readImage를 재사용. 긴 변 2048px, WebP 0.9로 변환. 큰 도면의 작은 숫자·가는 선 손실 가능 | 작품/도면 입력 경로 분리, 원본 보존, 무손실 미리보기와 관심 영역 확대 |
| P1 | PDF 구조와 원본 소실 | 페이지 전체를 최대 2400px로 래스터화하고 그 이미지만 저장 | 원본 PDF 보관 및 필요한 영역 재렌더. 벡터 경로·텍스트 위치는 별도로 추출 |
| P1 | 낮은 원본 해상도 판별 없음 | 스캔 PDF를 2400px로 렌더해도 실제 정보량은 늘지 않음. 픽셀 크기만으로 품질 판정 불가 | 벡터/스캔/혼합 유형 구분, 원본 이미지 해상도·흐림·대비 평가. 판단 불가 상태도 표시 |
| P1 | 확대·이동 도구 부재 | 평면도는 벽과 이미지 전체를 자동 맞춤. 복잡한 도면의 정확한 클릭 어려움 | 평면도 줌/팬, 100% 상세 보기, 기준점 확대 표시, 영역 선택 |
| P1 | 축척 검증 부족 | 1px 이상 두 점이면 허용. 원본 기준점·입력 길이 기록 없이 calibrated=true로 저장 | 긴 기준선 권장, 기준점/단위/길이 저장, 별도 치수로 교차 검증, 입력 완료와 정확도 검증 상태 구분 |
| P1 | 벽/문자/치수선 구분 없음 | OCR·선 분류·벽 자동 인식 미구현 | 벽 후보, 치수선, 문자, 문/창, 해칭, 가구·기호를 분리하고 사용자 검토 후 확정 |
| P1 | 실제 건축 연결 구조 미지원 | 바닥이 끝점 차수 2인 독립 루프에 한정. T분기·공유벽은 거절하며 연결 오차 1mm도 자동 복구하지 않음 | 허용오차 기반 스냅 후보와 수정 미리보기, 실/외곽 경계 모델 |
| P1 | 중정·겹친 루프 오해석 | 포함 관계를 계산하지 않아 내부 루프도 별도 바닥으로 채움 | 외곽/구멍/중첩 판정 및 사용자 구분. 중정을 채우지 않는 테스트 |
| P2 | 회전·원근·비균일 축척 미지원 | 현재 축척 모델은 단일 mm/px. 촬영 사진의 원근 왜곡이나 축별 다른 늘어남을 보정할 수 없음 | 회전/기울기 보정, 사진 원근 보정, 서로 다른 방향 치수 검증 |
| P2 | 도면 의미 정보 부족 | 층·부분 상세·단면/입면·축척이 다른 뷰를 구분하지 않음 | 평면 영역/층 선택, 상세도 제외, 영역별 축척 |
| P2 | 크기 검증과 품질 검증 혼동 | 현재 검증은 파일 용량/페이지 수/좌표 유효성이 중심 | 파일 정상, 읽기 가능, 형상 후보, 실측 검증을 별도 상태로 표시 |

## 실제 도면 검증 매트릭스

- 깨끗한 벡터 PDF, 텍스트가 윤곽선인 PDF, 스캔 PDF, 벡터/스캔 혼합 PDF.
- 저해상도 스캔, 흐린 사진, 낮은 대비, JPEG 압축 흔적, 기울어진 스캔, 원근 촬영.
- 작은 숫자, 회전된 숫자, 연속 치수, 총치수/부분치수, 0/O·1/I·5/S·8/B 혼동, 소수점/쉼표, mm/cm/m 및 피트·인치.
- 벽선 위 숫자, 치수 보조선, 중심선/점선, 구조 그리드, 해칭, 가구, 문 여닫이 호, 창호, 기둥, 계단, 범례/표제란.
- 열린 벽, 이중 벽선, 두꺼운 벽/얇은 가벽, 곡선/사선 벽, T/X접합, 여러 실, 공용벽, 중정, 복층.
- 한 장에 여러 평면과 상세도, 다른 축척의 영역, 페이지 회전, 여백이 큰 도면.

각 사례는 원본과 정답 주석을 함께 보관한다. 정답 주석에는 사용할 평면 영역, 기준 치수와 단위, 벽/개구부/기둥, 제외할 표기, 알 수 없는 정보를 포함한다. 원본에 없는 벽 높이·문 높이를 추정값으로 채우면 반드시 추정임을 표시하고 사용자가 수정할 수 있어야 한다.

## 측정할 결과

1. 입력 보존: 원본 대비 미리보기의 가는 선/숫자 손실, 축척·종횡비 변화 여부.
2. 치수: 값뿐 아니라 단위·대상 구간 연결까지 정답과 비교. OCR confidence를 실제 정확도로 표현하지 않는다.
3. 형상: 벽 누락/과검출, 개구부 누락, 접합 연결, 중정 채움, 전체 폭/깊이 오차.
4. 사용성: 잘못 읽힌 구간 표시, 확대·수정 가능 여부, 수정 소요 시간, Undo/Redo 및 재열기 후 일관성.
5. 불확실성: 읽지 못한 항목을 임의 완성하지 않고 확인 필요로 남기는지.

실제 도면의 축척/해상도와 사용 목적을 확보한 후 허용 오차를 정한다. 현재 단계에서 임의 인식률이나 밀리미터 정확도를 약속하지 않는다.

## 다음 구현 순서

1. 원본 보존 + 도면 전용 입력 + 줌/팬/영역 확대.
2. 입력 품질 안내 + 기준 치수 기록 + 두 번째 치수로 축척 교차 검증.
3. 실제 도면 사례 확보와 정답 주석 작성.
4. 벡터 PDF 구조 추출, 스캔 도면의 OCR/벽 후보 검출을 별도 경로로 구현.
5. 후보를 사용자에게 보여 주고 벽/개구부/외곽을 보정한 뒤 3D 생성.

이미지→PBR/3D 재질 생성은 기존 결정대로 추후 유료 기능이며, 도면 판독·축척·공간 생성과 구분한다.
