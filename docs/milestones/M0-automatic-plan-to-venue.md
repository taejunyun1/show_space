# M0 — 도면 업로드에서 전시장 전체 초안까지 자동 생성

상태: 최우선 · 미완료 (A1 한 페이지 자동 분석·저장 통합 1차 구현)
결정: 2026-09-11 사용자 직접 요구. 기존 개발 순서와 충돌하면 이 문서를 우선한다.

## 제품 목표

사용자는 도면을 올리고 결과를 본다. 회전·영역 선택·OCR 실행·숫자 확인·축척 보정·벽 후보 선택·치수 연결을 각각 실행하거나 모든 항목을 체크하는 것이 기본 흐름이어서는 안 된다. 시스템이 분석과 결합을 수행하고 전시장 전체를 편집 가능한 2D/3D 초안으로 만든다. 판단할 수 없는 핵심 정보만 묶어서 질문한다.

수동 도구는 결과 수정과 예외 복구용이다. 개별 검토 버튼의 수나 선 검출 기능 추가를 이 마일스톤의 성과로 대신하지 않는다. 초안 자동 생성과 최종 실측 검증은 별개이며, 없는 정보를 사실처럼 채우지 않는다.

## 기본 사용자 흐름

1. PDF 또는 이미지를 업로드한다.
2. 자동으로 평면 페이지·영역, 방향, 품질을 분석한다. 명확한 단층 전시장 도면은 사용자의 페이지/영역 선택 없이 진행한다. 여러 층·서로 다른 장소·여러 설계안이 섞여 선택이 불가피할 때만 대상을 한 번 묻는다.
3. 문자/숫자/단위/치수선/벽/개구부/설비를 통합 분석하고, 축척과 벽 연결 관계를 정리해 전시장 전체 모델을 구성한다.
4. 원본과 비교 가능한 2D/3D 초안을 자동으로 보여준다. 기본 예제 벽이 결과에 남거나 기존 사용자 프로젝트를 덮어쓰지 않도록 별도 가져오기 초안으로 생성한다.
5. 중요한 예외만 하나의 요약에서 확인한다. 수정하지 않아도 볼 수 있는 임시 초안과, 핵심 정보가 부족해 생성할 수 없는 상태를 구분한다. 사용자는 필요할 때 상세 근거·수동 도구를 펼친다.
6. 초안 채택을 한 번 선택하면 편집 프로젝트에 반영한다. 취소·재시도·되돌리기·저장/복구를 지원한다.

## 자동 처리 범위

| 영역 | M0에서 지향하는 결과 | 불확실할 때 처리 |
|---|---|---|
| 입력 | 페이지/영역/방향 자동 선택, 저해상도·복잡한 숫자·여러 평면 분리 | 의미가 다른 여러 공간 중 선택이 필요할 때만 묶어서 질문 |
| 치수 | 숫자와 단위, 치수선 연결, 여러 치수의 일관성으로 축척 결정 | 신뢰할 기준이 없으면 알려진 길이 하나만 요청. 단위 없는 값을 임의로 mm로 확정하지 않음 |
| 공간 | 외곽·내부벽·여러 실·복도·중정·기둥·문을 전체 모델로 생성 | 열린 외곽·중복·교차·전체/부분 치수 충돌을 자동 재분석하고 남은 문제만 표시 |
| 벽 속성 | 길이·높이·두께를 근거와 함께 적용 | 높이처럼 평면도에 없는 정보는 미확인 또는 명시된 미리보기 기본값으로 관리. 공통값 입력이 필요하면 한 번만 요청 |
| 설비·제한 | 출입구·에어컨·소화전/소화기·계단을 표시하고 설치 불가 영역을 구분 | 문자 상자를 실체 면적으로 간주하지 않음. 점유 면적과 접근 여유의 근거 부족을 구분하며 임의 규제 거리 생성 금지 |
| 결과 | 편집 가능한 전시장 전체 2D/3D, 원본 비교, 구조 오류 및 핵심 예외 요약 | 실패를 정상 자동 생성으로 집계하지 않으며 부분 생성임을 명시 |

설비 명칭 OCR을 별도 고도화하는 작업은 숫자·전체 자동 생성 흐름보다 후순위다. 필요한 출입구·설비·계단 인식 자체는 목표에서 제외하지 않는다. 사진/2D 이미지 → 3D 재질 생성은 계속 후속 유료 기능이다.

## 실행 순서

- [ ] A1. 자동 가져오기 작업 흐름: 기존 파서·OCR·선 검출을 한 번의 업로드 작업으로 연결. 진행 상태·취소·재시도·원본/분석 결과 보존과 단계별 진단을 공통화한다. 한 페이지의 자동 분석·진단·취소/재실행·분석 결과 저장까지 1차 구현했다. 여러 페이지 자동 선택 및 원본 파일 보존은 남아 있다.
- [ ] A2. 자동 공간 초안: 후보를 한 좌표계로 합치고 축척·벽 연결·외곽/실/문을 구성해 예제 공간을 대체하는 별도 초안을 만든다. 항목별 체크 없이 기본 결과를 제공한다.
- [ ] A3. 일관성 검사와 예외 처리: 숫자/치수 충돌, 중복·열린 경계·끊김을 자동 재분석한다. 필요한 질문을 하나로 묶고 추정/미확인을 모델에 보존한다.
- [ ] A4. 필수 설비·계단·설치 제한 통합: 객체와 점유/접근 범위를 구분해 결과에 연결한다. 수동 표시를 요구하는 빈 도구만 제공해서는 완료가 아니다.
- [ ] A5. 실제 복잡한 도면 묶음으로 업로드부터 결과까지 자동 검증하고 수정 비용을 측정한다. 발견된 실패 유형에 따라 사선·화살표·누락 복원 등의 세부 작업을 우선한다.

A5의 자료 수집·기준선 측정은 A1부터 시작한다. 로그인·공유·결제·장식성 UI·개별 수동 도구 확장은 M0 경로를 직접 막는 경우 외에는 우선순위를 낮춘다. 현재 로컬 처리부터 통합하고 외부 서비스 도입은 필요성과 비용을 별도로 검토한다.

## 완료 기준과 측정

아래 수치는 새 구현의 초기 개발 목표이며 사용자 확정 수치나 실측 성과가 아니다. 기준선 측정 후 근거를 기록해 조정한다.

- 실제 도면 최소 30개를 고정 검증 묶음으로 구성한다. 깨끗한 벡터 PDF, 저해상도 스캔, 치수 밀집, 여러 실/복도, 여러 평면/방향 혼합을 포함한다. 원본 출처·정답 모델·평가 대상 페이지를 기록하고 튜닝용과 별도 검증용을 구분한다.
- 입력을 받은 뒤 항목별 선택/체크 없이 전체 초안을 만드는 비율을 주 지표로 삼는다. 명확한 단층 평면이 있는 지원 입력에서 초기 목표는 80% 이상이다. 전체 30개 결과와 유형별 결과도 함께 공개해 어려운 도면을 사후 제외하지 않는다.
- 사용자 개입 0회, 묶음 질문 1회, 2회 이상, 실패를 별도로 집계한다. 업로드와 최종 초안 채택은 개입 횟수에서 제외하되 중간 페이지/영역/축척 선택과 모든 수동 수정은 포함한다.
- 초안 생성 시간은 같은 장치에서 업로드 완료부터 측정한다. 초기 목표는 지원 입력의 80%에서 3분 이내다. 모델 최초 로드와 재실행 시간을 구분한다.
- 숫자 일치율·축척 오차·벽 길이 오차, 벽/문/설비 누락과 오검출, 외곽/실 연결·중정 오류를 정답과 비교한다. 중요 객체 누락이나 주요 구조 오류가 있는 초안은 자동 완성 성공으로 세지 않는다. 치수 오차 허용치는 정답의 측정 정밀도와 함께 평가 전에 정한다.
- 자동 배치된 계단/출입구/설비 점유 영역과 미확인 영역을 구분한다. 미확인을 설치 가능으로 표시하면 실패다.
- 기존 데이터 유지, 초안 채택·취소·재시도·Undo·저장 복구까지 통과해야 완료다. 합성 도면/단위 테스트 통과만으로 M0 완료를 선언하지 않는다.

## 현재 기준선

기존 도구: PDF/이미지 가져오기, OCR/숫자 후보, 수동 축척/회전/자르기, 벽 후보 선택, 숫자 정정, 수동 치수 적용, 거리/치수선/문자 단절 근거 추천, 2D/3D 편집. 마지막 코드 검증은 자동 테스트 124개 통과다.

미완료: 업로드 단일 작업으로 자동 실행하는 처리 흐름, 사람의 후보 선택 없이 전체 모델 구성, 자동 축척/위상 결합, 필수 설비·설치 제한의 통합 생성, 실제 도면 묶음의 무개입 완성률 측정. 현재 제품은 검토 도구를 연결한 상태이며 M0 달성 상태가 아니다.


## 2026-09-11 — 자동 공간 초안 연결

도면 분석 후 닫힌 경계와 서로 다른 벽 치수 2개(단위·치수선·보조선 근거)를 검사해 축척과 벽/바닥 초안을 자동 생성한다. 결과는 원본 위 미리보기로 표시하고 적용 시 한 번의 실행 취소로 기존 프로젝트를 복원한다. 숫자 단위 누락, OCR 신뢰도 90 미만, 축척 차이 2% 초과, 끊긴/분기된 경계는 적용 보류한다. 높이 3 m와 두께 150 mm는 명시적인 임시값이다.

검증: 136개 테스트 통과. 래스터 선 검출→공간 초안 통합 사례, 축척 충돌, 단위 누락, 중복 근거, 낮은 OCR 신뢰도, 열린 경계, 문자 선 잡음 포함. 실제 복잡 도면 성공률은 아직 측정하지 않았다. 출입구·설비·계단 영역, 이중벽/분기벽 처리, PDF 페이지 자동 선택은 미완료이며 M0 완료로 간주하지 않는다.


## 내부 벽을 포함한 자동 공간 초안

닫힌 외곽에서 열린 가지를 분리하고, 바닥 안에 전부 포함되는 선만 내부 벽 후보로 유지한다. 독립 칸막이와 외곽에서 안으로 뻗은 벽을 지원한다. 미리보기는 외곽 파랑/내부 후보 주황으로 표시한다. 오목한 외곽 밖을 통과하거나 중정을 가로지르는 선, 외부 가지, 외곽 자체가 불명확한 순환 분기는 보류한다. 가구/벽 의미 분류와 출입구·설비 영역은 여전히 미완료다.

검증: 143개 테스트. 기존 축척 검증과 프로젝트 유효성 검사까지 내부 벽을 유지하는 통합 사례 포함. 실제 복잡 도면 성공률은 아직 검증하지 않았다.


## 실도면 검증 및 자체 재분석

공개 도면 2종 3페이지의 로컬 검증은 완전 공간 생성 0/3이었다. `docs/validation/2026-09-11-real-plans.md`에 입력 출처, 재현 방법, 실패 원인을 기록했다. 사용자 체크를 기본 흐름으로 요구하지 않고 3개 선 검출 조건을 자동 실행하며, 최소 두 성공 결과의 구조·축척 일치와 충돌 부재를 확인한다. 빈 PDF 인식 표기는 로컬 OCR로 전환한다. 151개 자동 테스트 통과, 실도면 러너는 별도 실행했다. API는 사용하지 않았으며 M0는 미완료다.


## 공간 복원 1차 — 공유 벽·접합·짧은 연결부

실제 교차점을 분리하고 평면 그래프에서 외곽/내부 벽을 추출한다. 짧은 연결부는 양끝과 긴 구조 네트워크의 연결을 검사해 유지한다. 원래 길이의 치수 근거는 분할 후에도 축척 계산에 사용한다. 160개 테스트와 빌드를 통과했다. 실도면 재검증은 여전히 전체 생성 0/3이며 개구부·이중선·사선 검출은 미완료다. 구체적인 후속 구현은 `docs/implementation/space-reconstruction.md`에 기록했다. 사용자 요청에 따라 이번 변경은 웹에 배포하지 않는다.


## 개구부 경계 모델 및 자동 연결

문/창문을 실제 벽과 분리된 개구부로 저장하고 벽 끝점에 연결했다. 바닥 경계에만 가상 연결을 사용하며, 작품 설치면이나 3D 벽 메시로 생성하지 않는다. 2D/3D는 개구부를 점선으로 표시한다. 벽 수정 시 연결점을 따라가고, 삭제 시 해당 개구부를 제거하며 Undo/Redo로 복원한다. JSON 검증은 잘못된 참조/중복 ID/0 길이를 거부한다.

문·창문 표기와 같은 선상에서 서로 마주 보는 벽 끝점의 틈이 유일하게 연결될 때 자동 후보를 생성한다. OCR 90 미만, 여러 후보 충돌, 다른 선과 교차, 검증 범위 밖 폭은 보류한다. 폭은 문자 상자가 아니라 실제 벽 끝점으로 계산한다. 문짝 회전호·창틀·상인방/창턱 높이는 아직 추론하지 않는다. 문·창문 후보 유형과 위치도 3회 자체 검증 결과 비교에 포함했다.

169개 자동 테스트와 빌드 통과. 별도 로컬 포트의 브라우저에서 개구부 프로젝트 불러오기, 3D의 열린 출입구와 이어진 바닥, 평면 전환 및 오류 없음 확인. 공개 도면 3페이지 재검증은 여전히 완전 생성 0/3이다. `docs/validation/2026-09-11-openings-retest.json` 참조. 웹 배포하지 않음. 전체 다섯 목표는 계속 미완료 상태이며 다음 구현은 이중선·선 후보 유실 처리다.


## 후보 보존·이중선·전체 단위 선언

자동 분석은 최대 500개 선 후보를 보존하고 수동 도구는 기존 100개 기본값을 유지한다. 저장 검증도 500개까지 허용한다. 양끝을 잇는 선이 유일하게 확인되는 평행 이중선만 중심선 후보로 변환한다. 끝이 열린 평행선, 복도 폭의 간격, 경쟁하는 끝단 근거는 합치지 않는다. 이 판정은 구조 후보 판정이며 길쭉한 가구/창틀의 의미 분류까지 해결한 것은 아니다.

페이지 전체의 명시적 단위 선언(예: All measurements in cm, 단위: mm)을 표기로 보존하고 단위 없는 숫자의 자동 축척 계산에 적용한다. 원래 숫자와 개별 명시 단위를 유지하며 서로 충돌하는 전체 단위, 낮은 OCR 점수, 특정 객체 치수 문구는 기본 단위로 사용하지 않는다. Espacio 실제 두 페이지에서 cm 선언 보존을 확인했다.

179개 테스트와 빌드 통과. 동일 공개 도면 재검증은 전체 생성 0/3으로 유지되며, 일부 입력은 500개 상한에도 도달했다. 후보 수 증가는 정확도 개선으로 집계하지 않는다. `docs/validation/2026-09-11-paired-units-retest.json`에 결과를 보존했다. 외부 API와 웹 배포는 사용하지 않았다. 다음은 세로/회전 숫자와 구조선 근거 보완이다.


## 세로·회전 숫자 자동 보완

래스터 OCR 입력을 0° 일반 인식 후 90°/180°/270° 숫자 인식으로 보완한다. 회전·확대 좌표를 원본으로 되돌리고, 겹친 같은 숫자는 중복 제거한다. 다른 값은 원문과 충돌 플래그를 보존하며 자동 축척/치수선 연결에서 제외한다. 낮은 점수의 추가 인식은 채택하지 않는다. 회전별 실패/취소를 처리하고 기존 PDF 문자 근거는 불필요한 회전 OCR로 대체하지 않는다.

185개 테스트 및 빌드 통과. 공개 Espacio 1페이지에서 시각적으로 선택한 세로 치수 7개를 정답 영역으로 기록했으며, 자동 사용 가능한 정확한 값이 기본 OCR 0/7 → 회전 보완 5/7로 증가했다. 60은 반대 방향의 09와 충돌해 제외, 125는 미확보다. 선택한 7개에 대한 결과이지 전체 페이지 정확도가 아니다. 원본 PDF SHA-256과 좌표/정답을 `docs/validation/espacio-selected-numbers.json`에, 결과를 `docs/validation/2026-09-11-rotated-numbers.json`에 보존했다. Node Canvas/Tesseract로 실제 래스터를 검증했으며 브라우저 렌더링 전체 흐름 재검증은 별도다.

전체 공간 생성은 여전히 0/3으로 다섯 목표는 미완료다. 외부 API 및 웹 배포는 사용하지 않았다. 다음은 전체/부분 치수 연결과 구조선 단절 근거 보완이다.


## 전체/부분 치수 연결 및 두꺼운 선 교차점 보정

연속된 여러 벽의 전체 치수, 하나의 벽 중간에 놓인 부분 치수를 치수선 및 양끝 보조선으로 연결한다. 실제 벽이 없는 구간은 연결하지 않는다. 부분 치수가 전체 구간을 빈틈없이 구성할 때 합계를 대조하고 2%를 넘는 불일치를 보류한다. 겹치거나 경쟁하는 부분 치수는 합산하지 않는다. 자동 공간 생성과 축척 검증에 통합했다.

두꺼운 래스터 선 끝의 외곽 픽셀과 수직 벽 중심선 사이 오프셋을 선 두께와 상한 12px로 보정한다. 수평·수직 방향을 유지하고, 경쟁하는 교차점/문 크기의 틈/선분 붕괴는 보정하지 않는다. 고정 4px 근접 연결 전에 처리한다.

193개 테스트와 빌드 통과. 동일한 공개 도면 재검증은 전체 생성 0/3이다. Espacio에서 구조 후보가 늘었지만 정답 구조 재현율이나 성공률 향상으로 집계하지 않는다. 결과는 `docs/validation/2026-09-11-dimension-spans-retest.json`에 보존했다. 다음은 외곽 후보와 가구·범례 선 분리 및 사선 검출이다. 전체 다섯 목표는 미완료이며 외부 API/웹 배포는 사용하지 않는다.
