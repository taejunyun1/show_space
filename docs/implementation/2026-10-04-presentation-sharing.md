# 선택 Scene의 보기 전용 Presentation

현재 배치만 전달하던 공유에 저장 Scene 선택을 추가했다. 공유 창에서 최대 20개를 직접 선택하며 기본 선택은 없다. 현재 배치는 항상 포함한다. 수신자는 로그인 없이 현재 배치와 선택 Scene을 전환하고 작품 이름·작가, 3D 작품의 연도/종류, 공개를 선택한 치수를 열람한다. 이동·회전·삭제·저장은 제공하지 않는다.

## 저장 구조와 공개 범위

- `schemaVersion:1`의 기존 단일 배치에 선택적 `scenes` 배열을 추가한다. 각 Scene은 하나의 공개 공간 스냅샷이며 중첩 Scene·중복 ID를 거부한다. 기존 링크는 그대로 열린다.
- PDF와 공유가 같은 분리된 Scene 투영 함수를 사용한다. 저장된 공간·작품·바닥·전시장 모델·3D 작품·조명·환경·카메라를 사용하고 편집기의 현재 배치를 복원하거나 변경하지 않는다. 구조가 없는 구형 Scene은 저장 작품/벽 표시와 현재 공간을 조합하는 기존 동작을 유지한다.
- 내부 설치 메모·체크/사진·원본 도면·분석 원본·미선택 Scene은 공개 JSON에서 제외한다. 서버도 중첩 스냅샷을 같은 허용 목록으로 다시 만든다. 이름/작가 등 기본 정보는 공개한다. 별도 작품 설명·재료·2D 연도 편집은 이번 범위에 포함하지 않는다.
- 공유 이미지 ID를 전체 배치에서 관리하고 동일 원본 URL을 재사용한다. GLB는 정제된 바이트의 SHA-256으로 재사용하고 Scene마다 독립된 객체/모델 연결과 배치를 유지한다. Scene에만 존재하는 자산도 발행 전 검사하고, 미참조 자산 요청을 차단한다.
- Scene 전환 시 선택·벽면 A/B·임시 측정과 시점을 초기화한다. 새 Scene의 저장 카메라를 적용하고 이전 3D 자원을 해제한다. 링크 중단 검사는 전체 발행에 대해 유지된다.

## 제한

전체 발행은 JSON UTF-8 1,000,000바이트·이미지 자산 1,000개·서로 다른 모델 51개/80MiB 이하이다. 기존 모델 개별 12MiB, 각 이미지 5MB, 배치당 벽 200/이미지 작품 500/3D 작품 50/조명 20 제한을 유지한다. 선택/자산/JSON 제한 실패는 원격 초안 생성 전에 처리한다. 이미지 다운로드/업로드 실패는 기존 초안 정리 경로를 사용한다. 서버는 길이 헤더가 없는 JSON도 스트림 크기를 제한한다.

중단 시 먼저 공개 접근을 막고 1,000개를 넘는 객체도 여러 페이지에 걸쳐 제거한다. 삭제가 중간에 실패해도 같은 링크를 다시 중단하면 정리를 재개한다. 보기 전용은 편집 UI 잠금이며 공개 자산 추출 방지가 아니다. 공유 작성자 인증은 기존 작성자 키이며 계정 인증 전환은 미완료다.

## 검증

- 707개 테스트 통과, 선택 벤치마크 2개 제외. TypeScript/Vite 빌드 통과. 구형 Scene/PDF 호환, 선택 기본 비공개, 중첩 메모 제외, 이미지 재사용·모델 재사용·Scene 전용 자산, 누락 자산 발행 거부, 최대 Scene/전체 이미지/UTF-8 크기, 스트림 취소, 모든 페이지 중단 및 재시도 포함.
- 실제 로컬 R2에서 파일 선택으로 합성 프로젝트를 불러와 Scene 두 개를 발행했다. 치수 공개/비공개 링크 각각 이미지 2개·GLB 2개를 실제 요청하여 공개 정보와 저장 카메라를 확인했다. UI에서 현재 배치/Scene A/전체 전시장+조각 Scene B, 3D·평면·벽면, 작가/연도·임시 줄자·전환 초기화를 검증했다.
- 390×844 브라우저 화면에서 Scene 선택/벽면/작품 정보와 가로 넘침 없음을 확인했다. 모바일 실기기·대형 파일·실제 SketchUp 모델 테스트를 대신하지 않는다.
- 전체 제품은 진행 중이다. 실제 인증 서비스 설정·이메일/Google·두 계정/기기 검증, 고급 작품 Presentation 속성·공유 인증 전환, 고아 자산 청소/버전 기록, 실사용 대형 모델/성능/사용성 검증이 남아 있다.

Cloudflare 버전 `9ddacd5e-3561-44dd-aa55-f206981e745f` 배포 완료. 공개 HTTPS entry `/assets/index-CicGOEWH.js`, 도면/SketchUp 입력 메뉴와 실제 합성 공유 두 Scene의 이미지·GLB 자산 4개/형상·작가/연도·잠금을 확인했다. 생산 R2에서 직접 만든 테스트 링크 하나와 로컬 테스트 링크 둘만 중단했고 모든 스냅샷·이미지·모델 요청이 410이다. 사용자 기존 링크/초안은 수정하지 않았다. 기록: `../validation/2026-10-04-presentation-sharing.json`.
