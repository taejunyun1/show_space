# 현장 설치 모드 — 2026-10-06

문서 2 §58–59에 맞춰 상단에 현장 설치 진입을 추가했다. 평면/벽면에서 작품을 선택하고, 작품·작가·벽 검색, A/B면, 확대·스크롤, 본체/액자 외곽/높이/바닥/벽 끝/인접 간격과 임시 두 점 줄자를 확인할 수 있다. 현장 모드에서 벽·작품의 구조/위치 편집은 제공하지 않는다. 축척 미정이면 길이 표시와 임시 줄자를 제한한다.

출력·액자/마감·운송·설치·조명 확인은 작품별 독립 상태다. 비공개 NoteDetails에 저장해 로컬/프로젝트 JSON·백업·개인 클라우드의 기존 저장 경로를 사용한다. 현재 프로젝트의 벽/바닥/작품/조명 메모 추가 체크를 전체 집계한다. 숨긴·미배치·독립 3D 작품은 목록/진행률에 포함하고 도면 표시 여부를 명시한다. 과거 Scene 작품은 중복 집계하지 않는다. Scene 복원은 최신 메모와 설치 상태를 유지한다. 공개 스냅샷에는 설치 상태와 메모를 넣지 않는다.

브라우저 검증에서 도면 절대 위치가 체크박스 영역을 덮던 오류를 수정했다. 스크롤한 작은 화면에서도 닫기 버튼을 고정하고, 현장 평면의 흰 벽을 어두운 구조선으로 표시한다. 편집/공유의 실제 재질 색은 유지한다. 업로드된 일반 이미지를 공유/현장 벽면에서 중앙 크롭하던 오류도 수정해 전체 이미지를 사용자가 입력한 실제 W/H에 맞춘다. 기존 5점 예제 스프라이트만 해당 패널을 잘라 표시한다.
