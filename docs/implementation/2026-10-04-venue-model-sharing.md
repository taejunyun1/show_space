# 전시장 전체 3D 모델의 보기 전용 공유

상단 **도면·모델 불러오기 → SketchUp / 3D 모델 불러오기**에서 가져온 정적 GLB를 현재 배치의 공유 링크에 포함한다. 모델을 편집 벽으로 변환하지 않아도 원본 형상과 PBR 재질·UV, XYZ 위치(mm), Y 회전과 균일 배율을 전달한다. 표시 중인 모델만 보내고 모델만 있는 배치도 허용한다. `.skp` 직접 입력은 지원하지 않는다.

## 동작

- 전시장 모델과 독립 3D 작품은 같은 SHA-256 자산 업로드·읽기 캐시를 사용한다. 같은 모델 바이트는 한 번만 업로드하고 마지막 사용자 해제 시 geometry/material/texture/ImageBitmap을 정리한다. 공유 뷰어에는 편집 상태나 이동 핸들이 없다.
- 생성 시점 스냅샷을 유지한다. 편집 모델의 위치·회전·배율 변경이나 재입력으로 기존 링크를 갱신하지 않는다. 작성자 키 인증과 발행 전 자산 확인·실패 초안 정리는 기존 공유 절차를 사용한다. 링크 중단 후 스냅샷·모델 요청은 410, 열려 있는 뷰어는 30초 주기 확인으로 내용을 해제한다.
- 3D 카메라·조명 범위에 이동/회전된 전시장 모델을 포함한다. 모델만 멀리 배치한 경우 원점을 바닥 범위로 덧붙이지 않는다. 평면에는 채우지 않은 점선 범위만 그린다. 원본 중정이나 출입구를 채우는 가짜 바닥은 만들지 않는다. 편집 벽이 없으면 벽면도에 안내를 표시하고 면 선택·줄자 도구는 숨긴다.
- 치수 비공개는 숫자 표시와 임시 줄자를 끈다. 잠금은 보기 전용 UI이며 파일 추출 방지/DRM은 아니다. 원본 파일명, 내부 메모, 다른 Scene, GLB 이름/extras/생성기/copyright는 공개 허용 목록에서 제외한다. 내장 이미지 인코딩 메타데이터와 사용하지 않는 BIN 바이트까지 제거하지 않는다.

## 입력과 범위

전시장 입력과 공유 로딩 모두 정적 GLB 예산을 먼저 검사한다. 실제 디코딩 정점으로 크기·기준점을 계산하며 accessor의 min/max를 그대로 신뢰하지 않는다. 저장된 크기와 원본 정점 범위가 다르면 다시 가져오도록 안내한다. 숨긴 참고 모델은 로딩하지 않는다. 평면 모델은 허용하지만 비어 있는 형상은 거절한다.

개별 12MiB, 공개 자산 총합 80MiB, 서로 다른 모델 자산 최대 51개(작품 50개와 전시장 1개). 정점/인덱스/계층/이미지 예산은 기존 정적 작품 입력과 같다. 움직임·스킨·모프·희소 정점·Draco/Meshopt/BasisU·내장 조명은 제외한다. 다운로드는 20초 제한·바이트 크기·해시 검증을 거치며 디코딩은 브라우저에서 실행한다. 복잡한 CAD/원본 SKP와 대형 파일/모바일 성능은 아직 검증하지 않았다.

## 검증

- 자동 테스트 652개 통과, 선택 벤치마크 2개 제외. TypeScript·프로덕션 빌드 통과. Three.js/PDF 큰 청크 경고는 남아 있다.
- 실제 GLTFLoader로 정점 범위, 원본 변환, 정적 입력 거절, 평면 모델과 저장된 기준점 오류를 검사했다. 12×8×3m 합성 전시장(15 mesh 인스턴스/16 node/4 PBR 재질)은 중정 구멍 2×2m, 입구 2m, 내부 가벽, 계단 4개, 설비를 포함한다. 중정 아래 Raycaster hit 0으로 원본 구멍을 확인한다. 실제 SketchUp 파일로 간주하지 않는다.
- 로컬 Wrangler/R2와 실제 파일 선택 UI에서 전시장과 3개 3D 작품을 함께 공유했다. 서로 다른 GLB 3개 중 하나는 체크무늬 이미지/PBR을 포함한다. 첫 스냅샷 pose XYZ [1500,100,-500]mm/Y30°/120%를 유지하고 편집 배치를 변경해도 스냅샷 SHA가 같음을 확인했다.
- 두 번째 모델만 공유한 링크는 XYZ [12000,100,-500]mm/Y-35°/80%, 치수 비공개이며 벽/이미지/3D 작품 없이 실제 전시장만 표시했다. 최종 빌드에서 파일 재입력·12,000×3,000×8,000mm 실제 크기·중정/입구/계단, 공유 선택 잠금·3D 시점 이동, 빈 벽면도 도구 숨김을 확인했다. 편집/공유 콘솔 경고·오류 없음.
- 직접 생성한 로컬 링크 두 개를 중단했고 모든 스냅샷·GLB 자산 요청이 410이었다. 열어 둔 두 뷰어도 자동으로 중단 안내로 바뀌었다. 공개 R2에는 검증용 모델을 발행하지 않는다. Cloudflare 배포와 공개 메뉴 확인은 아래 배포 기록 및 JSON 증거에 추가한다.

기계 판독 기록: [venue-model-sharing.json](../validation/2026-10-04-venue-model-sharing.json). 전체 제품 목표는 진행 중이다. 계정별 프로젝트 저장, 고급 Presentation, 실제 SketchUp 입력·대형 모델·모바일 실기기 검증 등이 남아 있다.
