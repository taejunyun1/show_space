# 같은 전시의 잠긴 공유·Scene 열람·회수와 화면 전환 보호

2026-10-11. [작품 드래그·스냅·회전](2026-10-11-exhibition-artwork-editing-workflow.md)에 이어 같은 전시에서 실제 공유 다이얼로그와 공개 API, 별도 읽기 전용 화면을 연결했다. 도면 인식이나 문·설비 직접 편집 범위는 확장하지 않는다.

## 수정한 동작

공유 링크를 바꾸면 이전 전시·오류·선택·Scene이 새 요청 중에도 남았다. 취소된 초기 요청이 늦게 끝나거나 이전 링크의 회수 확인이 도착하면 새 화면과 문서 제목을 덮어쓸 수 있었다. 이제 링크마다 화면 상태를 새로 만들고, 응답 수신과 JSON 읽기 뒤에 취소 여부를 검사한다. 화면 해제 후의 응답도 무시한다. 중단·만료를 확인하면 전시를 비우고 제목을 바꾸며, 일시적인 서버 오류는 이미 불러온 고정 배치를 유지한다. 기존 30초/화면 복귀 시 회수 확인은 유지한다.

## 같은 전시의 실제 UI와 API 연결

생산용 App의 같은 전시 ID를 유지했다. PDF→축척→바닥 경계/끝점 스냅→Hand→실제 PNG 작품 10점→그룹 드래그/회전→텍스처/내부 Note/야외 시간→Scene A/B→저장·캡처·PDF/ZIP/GLB 흐름 뒤에 다음을 연결했다.

- 실제 공유 다이얼로그에서 치수 공개와 Scene A/B를 선택해 발행한다. 생산용 Worker 처리기를 로컬 SQLite/R2 어댑터에 연결하고 작품 10장·벽 텍스처 1장 업로드, 발행, 목록 조회, 링크 복사를 확인했다.
- 별도 React 읽기 전용 화면에서 Scene B의 500mm 작품과 Scene A의 400mm 작품을 열람한다. 벽면 선택 정보·이미지 10장을 확인하고, 편집 입력/핸들이 없으며 포인터 조작으로 편집기 데이터가 바뀌지 않는지 검사했다. 임시 줄자로 1000mm를 측정해 100cm 표시를 확인했다.
- 공개 이미지 10장의 샘플 RGBA 픽셀을 원본과 비교했다. 비공개 Note·참고 사진·원본 도면은 공개 데이터/업로드에서 제외한다. 익명 공유 삭제 요청은 401로 거절한다.
- 원본 작품 폭을 777mm로 수정해도 공개 배치는 400mm, 두 Scene은 발행 시점 그대로다. 공유 다이얼로그에서 중단한 뒤 공개 화면 복귀 확인으로 열람을 닫으며, 데이터와 이미지 10개 요청은 410으로 차단된다. 편집기의 777mm 수정은 유지하고 undo로 원래 전시를 복원했다.

별도 React/StrictMode 검사 9개는 취소한 초기 응답, 링크 교체/오류 복구/잘못된 주소, 이전 링크의 늦은 회수 확인, 중단 뒤 재등장, 화면 해제 뒤 제목 변경, 일시적 오류 및 읽기 전용 조작을 확인한다. 같은 최종 대상 10개를 이전 SharedViewer에 적용하면 7 실패/3 통과, 수정 후 10 통과다. 전체 1,346 통과/선택 10 제외, 232 파일 통과/10 파일 제외, TypeScript·production build·diff 검사 통과. 기존 큰 청크 안내는 유지한다.

## 검증 범위와 남은 인수

테스트용 작성자 키, 로컬 SQLite/R2와 in-process Worker 요청, jsdom/native Canvas/fake-indexeddb 근거다. 기록의 localhost 공유 주소는 임시 테스트 주소이며 외부에서 사용할 수 없다. 실제 운영 계정 로그인·배포된 공개 URL·두 기기 검증을 완료한 것으로 집계하지 않는다. 공개 3D의 GPU와 클립보드 transport는 어댑터다. 실제 브라우저/GPU·OS 포인터 캡처·디스크 인수, native SVG rasterizer의 내장 image href 픽셀 생략 한계, 실제 SketchUp 수신 및 원문 24단계/사용자 성공 지표도 남긴다. 이번 변경은 배포하지 않는다.

도면·10점·편집·출력·잠긴 공유의 로컬 연속 흐름이 연결됐다. 다음 인수는 대표 실제 전시장/3D 모델의 가져오기·출력 보존과 렌더 부하 확인이며, 실제 계정/공개 URL/기기 검증은 기존 유보 범위를 유지한다. 사진→재질 유료 생성, IES/조도 분석, AI 배치 등 원문 후속 요구를 삭제하거나 이번 완료로 바꾸지 않는다.
