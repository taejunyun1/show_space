# 재질 라이브러리와 텍스처 PDF

원본 문서 2 §27의 벽·건축/작품/바닥/유리/금속/천/사용자 재질 분류를 재질 라이브러리에 추가했다. 벽·작품·바닥의 재질 패널에서 열 수 있으며 기존 15개 프리셋과 저장한 재질을 이름·분류로 검색한다. 현재 색·표면 물성·직접 업로드한 텍스처와 반복 크기를 별도로 저장한다. 썸네일을 만들고 재접속 뒤에도 유지한다.

라이브러리는 현재 브라우저의 독립 IndexedDB다. 계정 동기화는 아직 구현하지 않았다. 200개/32MiB를 보관 항목까지 포함해 제한하며, 문서와 얇은 목록을 원자적으로 저장한다. 보관은 복구 가능하다. JSON 백업은 텍스처를 포함하고, 가져오기는 원본을 덮어쓰지 않고 새 항목을 만든다. 이미지 헤더·크기·용량 검증 후 실제 이미지 디코딩과 썸네일 준비를 완료한 뒤 한 트랜잭션으로 복원한다. 같은 탭/다른 탭의 동시 한도·revision 충돌·저장 실패 롤백을 검증했다.

적용은 한 번의 편집 명령이어서 Undo가 가능하다. 벽·바닥은 색·물성·반복 텍스처를 교체한다. 작품에는 표면 물성만 적용해 작품 이미지·액자·실제 크기를 유지한다. 잠긴 벽/작품, 사라진 객체, 바뀐 프로젝트에는 적용하지 않는다. 도면 인식이나 독립 문·설비 편집, 사진→재질 생성 기능은 확장하지 않았다.

같은 ANCA 프로젝트에서 2×1m 재질의 저장·검색·보관·복구·재접속·백업 파일 다운로드·실제 파일 가져오기를 수행했다. 백업 2개를 새로 복원해 4개가 표시됐으며 콘솔 경고/오류는 없었다. 파일 선택 도구의 전달이 약 17분 51초 지연됐지만 복원은 완료됐다. 앱 내부 이미지 처리 시간이 17분이라는 증거는 아니다. 자동 UI 파일 전달 속도를 제품 업로드 속도로 집계하지 않는다.

자동 벽 2에 적용 전후 길이 5.86481m 유지, 반복 2×1m, Undo로 원래 텍스처 없음 복원을 확인했다. 바닥에도 2×1m가 적용됐다. 작품은 0.4×1.2m를 유지한 채 물성만 적용됐으며 Undo가 원래 프리셋을 복원했다. 모든 적용을 Undo한 뒤 실제 JSON 전체가 이전 출력 `(3).json`과 같았다. 390×844 화면의 dialog 폭/clientWidth/scrollWidth는 349px로 가로 넘침이 없었다. 실제 모바일 기기 인수는 별개다.

텍스처가 포함된 현재 배치와 Scene D를 PDF로 출력했다. A4 가로 12페이지의 두 3D 페이지 모두 텍스처와 작품 이미지를 확인했고 비공개 설치 메모는 추출 텍스트에 없다. 평면·벽면도는 기술 도면용 단색 표현을 유지한다. 이 PDF는 새 라이브러리 적용 전의 같은 프로젝트 출력이며 라이브러리 적용 뒤 PDF를 별도로 재시험했다는 주장은 하지 않는다.

864개 테스트 통과, 선택 벤치마크 2개 제외, 빌드 통과. 저장/복원/충돌/원자성/자산 검증과 실제 크기·이미지·메모 보존, 잠금·프로젝트 교체를 포함한 새 테스트 9개다. [기록 및 해시](../validation/2026-10-07-material-library.json)와 동일 접두사의 desktop/mobile/wall/restored PNG, texture-pdf-current/scene PNG를 보존했다.
