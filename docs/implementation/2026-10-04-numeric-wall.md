# 숫자 길이로 벽 그리기 — 2026-10-04

원본 MVP의 수동 벽 생성과 E2 계획에 남아 있던 “두 점 방향 → 숫자 길이 → Enter” 흐름을 연결했다. 기존에는 두 번째 클릭에서 즉시 생성되어 나중에 Inspector에서 길이를 고쳐야 했다.

W 또는 연필 도구 → 첫 점 클릭 → 두 번째 점으로 방향 지정 → 길이 입력 → Enter/벽 만들기 순서로 생성한다. 수평·수직·대각선 모두 시작점과 정한 방향을 유지하며 숫자 길이를 그대로 적용한다. 소수값도 격자나 가까운 끝점으로 다시 반올림하지 않는다. 다음 벽은 실제 생성된 끝점에서 이어진다. 생성 전 점 선택에는 기존 끝점/축/격자 스냅을 사용한다.

두 번째 클릭 후 입력에 포커스를 주고 기존 값을 선택한다. 입력 변경을 점선 미리보기로 표시하며, 미확정 벽은 저장하지 않는다. 1 미만·비정상 숫자는 거부하고 Esc/취소는 그리기를 종료한다. 도구·축척 보정·프로젝트 구조가 외부에서 바뀌면 남은 초안을 지운다. 생성은 벽마다 단일 Undo이며 자동 저장/JSON에는 최종 좌표를 저장한다. 축척 미정 도면 초안은 px 단위를 사용하고, 실제 mm는 기존 축척 보정 이후 적용한다.

미확정 SVG에는 `data-capture-draft`를 붙여 기존 캡처 처리에서 제거한다. 벽 인식·문/설비 편집·바닥 자동 복원 범위는 확장하지 않았다.

검증: 전체 테스트 804개 통과, 선택 벤치마크 2개 제외, TypeScript/Vite 빌드 통과(기존 큰 청크 경고 유지). 도메인/상태 검증은 소수 대각선 길이, 음의 축 방향, 실제 끝점 연속 생성, 스냅보다 입력 길이 우선, 잘못된 숫자, JSON/Undo/Redo를 포함한다. 실제 로컬 브라우저에서 1,234.5mm 수평벽 → 연결된 2,500mm 대각선, 잘못된 0 입력, Esc, 단일 Undo/Redo, 재접속 보존과 Undo 중 다음 초안 제거를 확인했다. 390px에서 1,800mm 버튼 생성·입력창 190px·가로 넘침 없음, 콘솔 경고/오류 없음, 임시 viewport 복구를 확인했다.
