# 프로젝트 자산 백업 구현

현재 프로젝트 모델 전체와 실제 참조 자산을 ZIP으로 보관하고 빈 브라우저 환경에서 복원한다. glTF 형상 전달과 별개로 현재/숨긴/미배치 작품, 모든 Scene과 구조, 메모·치수·분석·저장된 도면 이미지, 참고 GLB와 변환을 보존한다. 원본 업로드 파일 중 프로젝트에 저장하지 않은 PDF/JPG 바이트, Undo 기록, 공유 링크 관리 토큰과 편집 UI 상태는 포함하지 않는다.

- `manifest.json`: 형식/버전, project.json과 자산의 바이트 수·SHA-256.
- `project.json`: 현재 스키마 그대로, 자산 필드만 내부 포인터로 치환.
- `assets/images/<sha256>.<ext>`, `assets/models/<sha256>.glb`: 바이트 단위 중복 제거. 예제 작품은 원본 픽셀 크기의 해당 패널 PNG로 저장하고 가져온 이미지/모델은 재압축하지 않는다.
- `README.txt`: 복원 방법과 범위, 내부 메모 포함 안내.
- ZIP과 확장 파일 총합 각각 80MiB 이하, 복원 JSON 80MiB 이하, 파일 2,003개/자산 2,000개 이하. ZIP64/분할/암호화 ZIP 미지원. 경로·중복·선언 크기 선검사와 제한 스트림 해제 후 해시 확인. 외부 요청 없이 자산을 data URL로 복원하고 기존 프로젝트 검증기로 최종 검사한다.
- 가져오기 성공 시에만 현재 작업 JSON을 백업하고 교체한다. 비동기 처리 중 다른 프로젝트로 바뀌면 취소하며 검사 실패는 기존 작업을 유지한다. 실제 파일 선택과 복원 진행/오류 안내를 연결한다.

검증: 현재/숨김/미배치·다른 Scene/모델·도면·메모·측정·구조의 왕복, 자산 재사용·원본 바이트·입력 불변, 손상/누락/경로/중복/크기/버전 오류, 실제 브라우저 출력과 다른 빈 로컬 환경의 복원·새로고침·이미지 렌더. 공개 HTTPS에서 새 메뉴와 실제 출력까지 확인한다. 원본 SKP/계정 저장/3D 작품·재질·조명 등 다른 전체 요구사항은 계속 남아 있다.
