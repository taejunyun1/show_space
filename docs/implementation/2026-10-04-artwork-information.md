# 작품 정보와 읽기 전용 공개 범위

날짜: 2026-10-04

작품을 선택하면 이름·작가·연도·작품 종류·설치 형식·재료·공개용 설명을 편집한다. 기존 설치 NOTE와 공개용 설명을 별도로 보관해 메모가 공유 링크에 들어가지 않도록 한다. 원본 Pages 문서는 요구사항 자료로만 읽었다. `전시 시뮬레이터_1.pages` §8 Artwork의 Year/Type/PresentationType와 `전시 시뮬레이터_2.pages` §16 설치 형식·§52 공개 Medium을 참고했다.

## 편집과 저장

- 이미지 작품과 정적 3D 작품이 동일한 정보 필드를 사용한다. 작품 종류는 사진·회화·프린트·영상·프로젝션·조각·설치·오브젝트·기타다.
- 설치 형식은 사진/액자/마운트 프린트·아크릴 마운트·캔버스·스크린·프로젝션·오브젝트·조각·기타다. 구형 2D 작품의 종류를 임의로 사진으로 추정하지 않는다. 3D 작품은 기존 kind를 기본 분류로 유지한다.
- 2D 액자 프린트 선택은 기존 액자 색을 유지하거나 내추럴 액자를 지정한다. 다른 형식과 미지정은 액자를 제거한다. 액자 버튼을 바꾸면 형식도 맞춘다. 3D 설치 형식/재료 텍스트는 원본 GLB 메쉬·UV·PBR을 변경하지 않는다.
- 새 작가/연도 입력은 200자, 재료는 300자, 설명은 2,000자 이하. 기존 2D 작품의 긴 이름/작가 문서는 제한을 추가하지 않고 유지하며 3D 이름은 기존 200자 제한을 따른다. 연도는 제작 기간도 입력 가능한 텍스트다. 그룹 정보 편집은 첫 작품에만 적용하고 잠긴 작품의 여섯 정보 입력을 비활성화한다.
- 입력은 포커스를 옮기거나 텍스트에서 Enter를 눌러 적용한다. 여러 줄 설명의 줄바꿈은 유지한다. Undo/Redo·복제·Scene·미배치 보관·JSON·자산 백업에서 정보를 보존한다. 기존 정보 없는 프로젝트·Scene·공유 스키마는 호환된다.

## 공유

**작품 상세 정보 공개**는 기본으로 꺼져 있다. 이름·작가·연도는 기본 공개한다. 상세 공개를 켠 새 링크는 재료·공개용 설명·작품 종류·설치 형식을 현재 배치와 선택한 모든 Scene에 포함한다. 3D의 기존 kind는 기존 공유 형상 분류이며 기본 링크에도 유지된다. 내부 설치 NOTE/체크/사진·원본 도면·미선택 Scene은 포함하지 않는다. 치수 표시는 기존 선택을 따른다.

클라이언트와 Worker가 필드를 명시적으로 허용한다. Worker가 루트 공개 선택을 모든 Scene에 동일하게 적용하므로 중첩 Scene의 플래그로 우회할 수 없다. 옵션을 바꾸고 새 링크를 만들어야 공개 범위가 달라진다. 이미 만들어진 링크는 변경되지 않는다. 공유 목록은 상세 공개 여부를 표시한다. 뷰어의 설명은 React 텍스트로 출력해 HTML을 실행하지 않고 줄바꿈과 긴 단어를 처리한다. 전체 공개 JSON 1MB/Scene 20개 등 기존 제한을 유지한다.

## 검증

717개 테스트 통과, 선택 벤치마크 2개 제외, TypeScript·Vite 빌드 통과. 새 테스트는 구형 문서·유효성·길이 제한·잠금·Undo/Scene/미배치/백업·두 공개 범위·중첩 우회 차단·HTML 이스케이프를 검증한다.

실제 로컬 UI에서 두 종류 작품을 편집하고 재로드/Scene 복원했다. JSON과 `.gonggan.zip`을 실제로 다운로드해 신규 정보·잠금을 확인했고 ZIP 1,414,072바이트/파일 7개 CRC와 앱 가져오기 모듈의 모든 해시/자산/스키마 검사를 통과했다. 이번 증거의 복원은 패키지 모듈 왕복이며 새 브라우저에 ZIP을 재업로드한 검증은 아니다. 기본/상세 링크를 UI에서 생성했고 390px에서 줄바꿈·가로 넘침 없음을 확인했다.

Cloudflare 최종 버전 `426a78b5-3a7b-48f6-bd79-25dc731e1019`로 배포했다. 생산 R2에 합성 작품만 담은 두 링크를 만들고 2D/3D 정보·Scene·이미지/GLB 자산 3개씩과 실제 HTTPS 화면을 확인했다. 새 링크는 모두 중단해 스냅샷/자산 410을 확인했다. 사용자 기존 링크/초안은 수정하지 않았다. 증거: `../validation/2026-10-04-artwork-information.json`.

## 남은 범위

설치 형식 분류가 영상 재생·프로젝션 투사·실물 캔버스/마운트 모양·고급 액자 폭/깊이/매트/유리 구현을 의미하지 않는다. 이름/작가/연도/재료/설명은 이번 단계에서 PDF 작품 목록이나 GLB extras로 추가 출력하지 않는다. 실제 SketchUp/SKP·대형 모델·모바일 실기기 성능, 표준 인증의 실제 설정/메일/Google/두 계정·기기 및 최종 사용성 검증이 남아 있다. 전체 제품 목표는 계속 진행 중이다.
