# 2026-10-04 작품 스냅과 벽면 설치 치수

원본 MVP §11 Object Edge/Object Center Snap과 §13 WallElevation 설치 치수를 벽 부착 이미지 작품에 연결했다. 무거운 도면 인식 범위는 늘리지 않는다. 상단 입력은 기존 통합 도면·모델 불러오기(JPG/PNG/PDF, SketchUp 내보내기 GLB, 프로젝트 JSON/ZIP)를 유지한다. .skp 직접 변환은 미지원이다.

## 동작

- 3D와 벽면도에서 같은 벽·같은 면의 보이는 작품 모서리/중심, 벽 끝/바닥/중앙으로 붙인다. 액자·매트와 회전 외곽을 포함하며, 잠긴 타깃은 참조 가능하나 이동하는 그룹에 잠긴 작품이 있으면 이동을 막는다.
- 화면 약 12 CSS px의 범위에서 가까운 축을 우선한다. 3D는 현재 위치에서의 투영 미분 근사이며 축별 최대 500mm다. 사선·원근 시점에서 정확한 픽셀 반경을 보장하지 않는다. 스냅이 없으면 10mm 격자를 사용한다.
- 자석 버튼 또는 Alt로 스냅/격자를 해제한다. 벽 안에 전체 작품/그룹이 들어가는 경계는 계속 지킨다. 드래그는 한 번의 Undo 단위이며 Escape·취소·시점 전환에서 초안을 버린다. 이동 없는 클릭은 기록을 추가하지 않는다.
- 선택 작품의 가까운 가로/세로 외곽 간격을 중복 없이 표시한다. 단일 선택은 바닥과 화면 기준 왼쪽/오른쪽 벽 끝 거리도 표시한다. 회전 외곽의 축 방향 거리이며 비스듬한 다각형 사이의 최단 거리가 아니다. 교차축 범위가 겹치지 않는 대각 작품은 간격을 표시하지 않는다.
- 벽면 PNG의 치수 포함/제외 옵션과 연동한다. 선택 핸들·스냅 초안 안내선은 출력하지 않는다. 다중 선택의 간격 라벨은 짧게 표시한다.

## 검증

776개 테스트 통과, 선택 벤치마크 2개 제외. TypeScript/Vite 빌드 통과(기존 큰 청크 경고 유지). 합성 로컬 전시장만 사용했다.

실제 포인터로 A면 벽면도와 3D 정면에서 along 2820 / 중심 1600mm, 90° B면에서 along 4530 / 중심 1600mm를 확인했다. 자석 해제 자유 이동은 2434.81 / 1466.67mm로 격자에 붙지 않았다. Undo/Redo, 10개 그룹 이동의 9개 250mm 간격과 단일 Undo, 저장 JSON의 크기/액자/원래 위치 보존을 확인했다. 1920×980 PNG에서 설치 치수 포함/제외 및 편집 핸들 제거를 시각적으로 검증했다. 390px에서 가로 넘침 없이 도구막대를 가로 스크롤해 자석 버튼을 조작했다. 콘솔 경고/오류 0.

Alt와 Escape의 중간 드래그는 상태 테스트와 코드 경로로 검증했으며 실제 네이티브 드래그 도중 키 입력은 검증하지 않았다. 실제 모바일 하드웨어·큰 장면의 포인터 지연도 미검증이다.

## 남은 범위

독립 GLB 작품의 오브젝트 스냅, 새 자동 간격 치수의 PDF/공유 뷰어 연결, 실제 인증 및 실제 SketchUp/대형 모델·모바일 실기기 검증은 남아 있다. 전체 구현 완료로 집계하지 않는다.
