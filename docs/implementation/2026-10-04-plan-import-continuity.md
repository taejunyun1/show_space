# 도면 가져오기 연속성 — 2026-10-04

실제 연속 인수의 도면 가져오기 단계에서 프로젝트 교체와 반복 OCR 지연을 확인했다. 전체 24단계 인수를 통과했다는 뜻은 아니다.

새 이름/전시장/m 단위 프로젝트에 [ANCA 공식 PDF](https://www.anca.net.au/s/ANCA_floor-plan.pdf)를 올리고 벽 초안을 적용했을 때, 기존에는 id가 partial-venue로 바뀌면서 이름과 전시장까지 덮어썼다. 목록에도 원래 프로젝트와 별도의 초안 프로젝트가 남았다. 이제 공간 내용은 교체하되 기존 id/이름/전시장/단위/프로젝트 메모·첨부는 유지한다. 기존 공간과 작품을 교체하는 동작과 Undo는 그대로다. 이전 잘못 생성된 초안 데이터를 자동 삭제하거나 합치지는 않는다.

자동 OCR은 하나의 45초 예산을 공유하고 각 시도는 최대 12초다. PDF 문자는 보존하며 시간 초과한 OCR worker를 중단하고 확보한 표기·구조 선으로 후속 판단을 계속한다. 예산이 끝나면 새 OCR worker를 만들지 않는다. PDF 렌더·페이지 선택/선 검출/동기 기하 계산까지 전체 가져오기가 45초라는 보장은 아니며, 고급 도구의 직접 실행 OCR 제한은 변경하지 않는다. API는 추가하지 않았다.

836개 테스트 통과, 선택 벤치마크 2개 제외, 빌드 통과. 테스트는 여러 멈춘 OCR 작업의 누적 제한/즉시 취소/worker 종료, PDF 숫자·선 근거 보존, 프로젝트 동일성/단위/메모/Undo·Redo를 검증한다.

실제 브라우저: 숫자22개, 원시 선 후보500개, 편집 벽 후보17개를 보존했다. 이름·전시장·m 설정 유지, Undo로 원래4벽 복원, Redo, 저장 완료 후 재접속에서 초안 유지와 콘솔 경고/오류 없음 확인. 해당 도면에는 Not to scale 표기가 있고 전체 구조 검증은 보류됐으며 축척은 px 미정이다. 실제 벽 치수나 3D 공간 복원 성공을 주장하지 않는다.

저장 중 즉시 재접속하면 마지막 debounce 변경을 잃을 수 있는 별도 관찰이 남았다. 이번 재접속 증거는 로컬 저장 완료 후 확인한 결과다. 실제 인증, 축척/배치부터 PDF·공유까지 같은 프로젝트의 24단계 연속 인수는 계속 남는다.
