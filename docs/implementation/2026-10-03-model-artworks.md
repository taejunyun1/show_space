# 3D 작품 가져오기·편집 (T5 일부)

상단 도면·모델 불러오기는 전시장 참고 모델 입력이며, 왼쪽 **3D 작품 추가**는 독립적으로 배치할 조각·설치 작품 입력이다. 실제 GLB/glTF 형상과 UV/PBR 재질을 유지한다. 원본 .skp는 입력하지 않으며 SketchUp에서 GLB로 내보낸 파일을 사용한다.

## 사용

- GLB, 자산이 포함된 glTF, glTF와 BIN/PNG/JPG/WebP를 동시 선택, 폴더 경로를 유지한 glTF ZIP을 선택한다. glTF 진입 파일은 하나여야 한다.
- 등록 직후 원본의 실제 폭·높이·깊이를 mm로 표시하고 바닥 중앙을 배치 기준점으로 정규화한다. W/H/D는 숫자로만 바꾸며 화면 핸들은 이동·회전만 한다.
- 3D 축 화살표로 XYZ 이동, 회전 도구의 원으로 회전한다. 평면도에서 드래그하거나 오른쪽 XYZ 위치/각도를 입력할 수 있다. 바닥에 놓기는 기울어진 모델의 전체 바운딩 박스 최하단을 기준으로 한다.
- Shift 선택과 그룹 만들기, 복제·삭제·표시·잠금·Undo/Redo 지원. 그룹 이동·회전은 간격을 유지하며 숫자 크기는 첫 작품에 적용한다. 벽/2D 작품과 혼합 그룹은 없다.
- JSON·IndexedDB·Scene·프로젝트 자산 백업에 모델과 원본 GLB 바이트, 작품 정보/메모/변환을 보존한다. 중복 모델은 백업 자산을 재사용한다. 새 Scene의 빈 모델 목록도 복원하며 옛 Scene에는 현재 모델을 유지한다.
- PNG·PDF 3D와 GLB/glTF에 실제 형상을 포함한다. PDF 평면은 전체 형상의 바운딩 박스 투영/볼록 경계이며 상세 단면도는 아니다. 치수 목록에는 W/H/D와 XYZ 위치/회전을 출력한다. 내부 메모는 공개 출력에서 제외한다. 교환 출력 텍스처는 긴 변 최대 1024px이다.

## 지원 조건

모델/자산/ZIP 압축 해제 총합 12MiB 이하, 작품 50개 이하, 모델 정점·인덱스/반복 형상 수 약 20만 삼각형 이하. 텍스처 한 변 8192px·총 64,000,000픽셀 이하를 디코딩 전에 검사한다. 모델 계층·외부 참조·자산 누락·ZIP 경로/크기·GLB 버퍼를 검사하고 실패하면 기존 작업을 유지한다.

정적 glTF 2.0을 지원한다. 애니메이션·스킨·모프·희소 정점·Draco/Meshopt/BasisU 압축·GPU 인스턴스·내장 조명은 초기 범위에서 제외한다. 원본 모델의 단위를 임의 추정하지 않으며 실제 숫자 크기를 확인/입력할 수 있다. 동일 모델의 GPU 자원은 재사용하고 마지막 표시가 끝나면 geometry/material/texture/ImageBitmap을 해제한다.

## 검증과 남은 범위

합성 3개 mesh 모델로 멀리 이동된 원본 피벗, 비균일 크기, 3축 회전, 실제 exporter→loader 형상/재질/치수 왕복을 검증했다. 브라우저에서 실제 GLB와 체크무늬 glTF ZIP, 3D 축 이동·회전/Undo, 평면 드래그, 그룹/잠금, Scene 복원/새로고침, PNG/ZIP/GLB/glTF/PDF 다운로드를 검증한다. 자세한 증거는 `../validation/2026-10-03-model-artworks.json`에 기록한다.

3D 작품을 포함한 링크 공유는 미완료이며 모델을 조용히 누락하지 않고 공유 생성을 막아 지원 범위를 알린다. 실제 사용자 SketchUp 모델, 압축 모델 디코더, 대형 모델/50작품/모바일 실기기 성능과 계정 저장도 남아 있다. 입력 크기 제한은 성능 예산 통과를 뜻하지 않는다. 전체 T5/MVP/제품 목표를 완료로 집계하지 않는다.
