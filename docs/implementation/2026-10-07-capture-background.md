# 투명 배경·환경 포함 캡처 · 2026-10-07

문서 2 §48의 빠진 Transparent Background/Environment 포함 옵션을 기존 화면 캡처에 추가했다. 해상도/비율/치수/격자/원본 도면 설정과 함께 사용한다.

## 동작

- 3D·평면도·벽면도에서 **투명 배경 PNG** 선택. 기존 기본값은 불투명이며 기존 Scene 썸네일 등의 호출에는 새 옵션을 요구하지 않는다.
- 3D의 **환경 배경·반사 포함**은 기본으로 켜져 있다. 끄면 Scene 배경과 환경 반사를 제외하며, 스팟·면 조명·태양 등 기존 조명은 그대로 남긴다. 불투명 PNG의 제외 배경은 흰색이다.
- 투명 배경 + 환경 포함은 배경만 투명하게 만들고 환경 반사는 유지한다. 투명 배경 + 환경 제외는 둘 다 제외한다.
- 실제 WebGL renderer의 alpha를 명시하고 캡처에 맞춰 clear alpha를 0/1로 설정한다. 합성 Canvas는 기존 픽셀을 먼저 지우며 투명 PNG에는 배경/비율 여백을 채우지 않는다.
- 평면도에서 격자 제외를 선택하면 투명일 때 grid rect를 none으로, 불투명일 때 흰색으로 만든다. 격자를 남긴 투명 PNG는 격자 선만 남는다. 원본 도면·벽/바닥·작품·치수의 불투명 픽셀은 실제 표시 객체이므로 별도로 지우지 않는다.
- 캡처 자원/품질 준비 뒤 일시적으로 배경·환경만 바꾼다. 성공·실패 모두 원래 Scene background/environment 참조와 renderer clear color/alpha, pixel ratio, 격자/캡처 상태를 복원한다. 환경 Texture를 폐기하거나 프로젝트/시점/저장 Scene을 변경하지 않는다.

## 증거와 한계

새 일반 회귀 **5개**, 관련 캡처 검증 **20개** 통과:

- 실제 Three Scene/Color/Texture/SpotLight의 배경 두 종류 × 투명 여부 × 환경 여부 8조합. renderer clear adapter 및 Scene 참조/광원/환경 강도 불변·반복 cleanup·출력 실패 경로 복원 확인. renderer 초기 설정이 실패한 경우도 Scene 복원.
- 실제 `@napi-rs/canvas` PNG 인코딩/다시 디코딩. 200×100 비율 여백, 빈 source 픽셀, 불투명 빨강, 반투명 파랑의 alpha가 투명/불투명 옵션에 맞게 보존되는지 검사. 이전 녹색 Canvas 잔여 픽셀 없음.
- 실제 SVG 래스터 픽셀에서 투명 격자 여백/격자 선 및 기존 불투명 기본값 확인.
- 캡처 UI 정적 렌더에서 세 보기 모두 투명 PNG, 3D에만 환경 옵션, 현재 출력 크기/저장 제어 확인.

전체 **1,098 통과 / 선택 실행 10 제외**, TypeScript/Vite 빌드와 `git diff --check` 통과. Scene 상태 및 실제 합성/PNG 픽셀은 확인했으나 fake renderer clear adapter는 실제 WebGL GPU 렌더러가 아니다. 실제 브라우저 체크박스/다운로드와 3D 환경 반사·프로젝터 투사 픽셀은 아직 보류된 브라우저 인수 항목이다. 전체 24단계 전시 흐름/실계정·실기기/운영 배포 완료로 집계하지 않는다.
