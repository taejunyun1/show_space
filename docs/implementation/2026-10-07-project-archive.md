# 전시 아카이브 탐색과 재사용

사용자의 2026-10-07 결정에 따라 인증 설정·브라우저 연결 대기는 보류하고 제품 계획 1.2 및 문서 2 §74를 구현했다. 기존 프로젝트 보관·복구를 유지하면서 전체 전시 기록의 탐색·열람·복사본 재사용 화면을 추가했다.

## 사용 흐름

상단 **프로젝트 → 전시 아카이브**에서 **이 브라우저 / 내 계정**을 선택한다. 전시·전시장·수정 연도로 검색하고 보관 상태·수정 연도·최근 수정순/이름순으로 좁힌다. 연도는 Asia/Seoul 기준 수정 연도이며 실제 전시 개최 연도로 간주하지 않는다.

목록은 작은 프로젝트 요약만 읽는다. 선택한 전시 한 건의 전체 기록을 읽고, 보관된 프로젝트도 복구하거나 편집기에 열지 않고 열람한다. 계정 목록은 기존 계정 세션·서버 소유권·ZIP 해시 검증 경로를 사용한다. 운영 계정 연결이 준비 중이어도 로컬 아카이브를 사용할 수 있다.

일곱 항목을 제공한다.

- **공간**: 벽 길이·높이·두께·좌표·상태, 개구부/저장 치수 개수, 바닥 외곽선, 도면 축척 및 참고 공간 원본 크기·배율·위치·회전.
- **작품 배치**: 설치/미배치 벽면 작품과 3D 작품의 크기·벽/면·위치·회전·그룹·표시/잠금, 액자 포함 외곽·액자/매트·원본 이미지.
- **재질**: 바닥·벽·이미지 작품의 저장 PBR 속성, 텍스처/노멀 반복 크기·강도. 가져온 모델의 내부 재질은 원본 모델 및 읽기 전용 3D에 보존한다.
- **조명**: 환경광·Spot/Area/프로젝터 기본 배치·색온도·강도·빔·상태, 야외 날짜·시간대·위치·방향. 실제 Lux 계측으로 해석하지 않는다.
- **메모**: 비공개 텍스트·체크리스트·설치 단계·참고 사진. 읽기 전용이다.
- **Scene**: 저장 이름·시점 유무·저장 썸네일과 해당 기록으로 이동. 썸네일이 없으면 새로 생성하지 않고 없음으로 표시한다.
- **참고 사진**: 현재 및 모든 Scene의 메모 사진을 같은 이미지 URL 기준으로 중복 제거하고 출처를 함께 표시한다. 현재 배치에서 삭제한 객체의 Scene 전용 사진도 포함한다.

**기록 배치**로 현재 배치 또는 저장 Scene을 고르면 해당 배치의 구조·작품·재질·조명·개체 메모를 확인한다. 프로젝트/바닥 메모는 공통 기록이다. 분리한 Scene을 사용하며 편집 Scene을 복원하지 않는다. **읽기 전용 3D 보기**는 기존 로컬 발표 화면을 지연 로딩해 재사용하고 편집 기능과 공개 발행은 실행하지 않는다. 3D용 정보 allowlist에는 내부 메모·참고 사진을 넣지 않는다.

**새 프로젝트로 재사용**은 현재 편집의 저장을 먼저 확인하고, 새로운 프로젝트 ID에 현재 배치·모든 Scene·자산·메모를 복사한다. 원본 프로젝트의 ID·보관 상태·버전은 유지한다. 이름은 1~200자이며 계정 자동 저장 연결은 복사하지 않는다. 복사본 저장 실패 시 원자적으로 롤백한다. 먼저 비활성 로컬 복사본을 저장한 뒤 편집기에 연다. 저장 후 취소/프로젝트 전환이 발생하면 별도 복사본이 로컬 목록에 남을 수 있지만 원본을 대체하지 않는다.

계정/저장 위치가 바뀌면 기존 목록·상세·3D 데이터는 새 컨텍스트에 표시하지 않는다. 비동기 계정 읽기는 AbortController·현재 계정 확인으로 취소하고 ZIP 파싱 및 미디어 검증 후에도 확인한다. 재사용 중 현재 편집 프로젝트가 바뀌면 이전 작업을 편집기로 덮어쓰지 않는다. 로컬 기록은 브라우저 소유 데이터이며 계정 전환 시에도 별도 로컬 범위로 유지한다.

## 검증 및 제한

신규 회귀 11개를 추가했다. 실제 fake-indexeddb 트랜잭션으로 보관 원본 및 활성 프로젝트 유지, 완전한 복사본 데이터, 저장 공간 실패 롤백, 오래된 버전/메타데이터 불일치 거절을 검증했다. 실제 ZIP 생성/파싱 및 클라우드 클라이언트의 해시·크기·버전 검증을 호출했고 계정 변경/미디어 검증 실패의 반환 차단을 확인했다. 클라우드 응답과 이미지 디코딩은 명시적 테스트 대역이며 실제 로그인이나 기기 왕복이 아니다.

순수 데이터 검사로 Scene 전용 비공개 사진·출처·중복 제거·분리된 Scene을 확인했다. React 정적 렌더로 7개 항목·cm 치수·읽기 전용 기록·설치 상태·검색/필터 제어를 확인했다. 이는 실제 클릭/포커스/3D 렌더/390px 인수가 아니다.

전체 **1,032개 통과 / 선택 통합 검사 7개 제외**, TypeScript·Vite 빌드 통과. 브라우저 연결 및 실제 인증 인수는 사용자 결정대로 보류했고 아직 운영 배포하지 않았다. 협업 Comment, 별도 전시 큐레이션/개최일 메타데이터, 계정 기기 인수 및 전체 제품 인수는 완료로 집계하지 않는다.
