# 3D 작품의 보기 전용 링크 공유 — 2026-10-04

상단 공유가 독립 3D 작품을 포함한 배치를 발행한다. 기존 링크는 생성 시점의 스냅샷이며 이후 편집으로 바뀌지 않는다. 원본 전시장 참고 모델은 여전히 공유 대상에서 제외한다.

## 사용자 동작

1. 왼쪽 **3D 작품 추가**에서 정적 GLB·glTF·glTF ZIP을 가져와 배치한다.
2. **공유**에서 기존 작성자 키를 입력하고 치수 표시 여부를 선택한다.
3. **링크 만들기**가 이미지와 3D 모델을 모두 업로드한 뒤 발행한다. 실패하면 미발행 초안을 정리한다.
4. 링크 수신자는 형상·UV·PBR 재질을 3D로 보고, 평면에서는 기울임과 회전을 포함한 투영 외곽을 본다. 선택하면 작품명·작가·연도·종류와 배치 잠금 정보를 표시한다. 치수를 허용한 경우 크기와 임시 줄자가 표시된다. 이동·회전·삭제 입력과 편집 저장소는 없다.
5. **공유 중단**은 스냅샷과 모델·이미지 자산 접근을 함께 410으로 막는다. 이미 열린 뷰어는 기존 30초 상태 확인에서 화면을 해제한다.

상단 **도면·모델 불러오기**는 공간 도면 JPG·PNG·PDF, SketchUp에서 내보낸 GLB, 저장 전시 JSON·ZIP을 구분한다. 독립 3D 작품 추가와 전시장 참고 모델 입력을 구분한다. SKP 원본 직접 입력은 미지원이다. SketchUp 내보내기 경로는 [공식 안내](https://help.sketchup.com/en/sketchup/working-gltf-files)와 대조했다.

## 자산 전달·제한

- 실제 GLB 바이너리를 전달하며 원본 정점·노드 변환·UV·PBR·텍스처를 유지한다. 공개 스냅샷은 원본 파일명·dataUrl·메모·그룹·편집 잠금 상태·다른 Scene을 포함하지 않는다.
- GLB 의미 필드 허용 목록을 브라우저와 Worker에서 적용해 이름·extras·generator·copyright·사용자 정의 JSON 필드를 제외한다. SHA-256 콘텐츠 주소로 같은 자산을 한 번만 올리고 다운로드 시 해시를 확인한다. 모델 자산은 공개 스냅샷에 실제 참조된 해시만 열람 가능하다.
- 정적 모델 12MiB·최대 50개·공유 모델 자산 총합 80MiB. Worker는 선언 크기와 실제 스트림 크기를 제한하고, 모든 참조 모델이 존재해야 발행한다. 기존 모델 계층·정점·이미지 크기·외부 자산 거절 검사를 그대로 적용한다.
- 같은 파일은 GPU 자산을 공유하며 뷰어 전환·종료 시 로더 중단과 geometry/material/texture/ImageBitmap 해제를 연결했다. fetch 시간 제한은 20초이며 파서 자체를 별도 Worker에서 강제 중단하는 기능은 없다.
- 잠금은 뷰어의 편집을 막으며 공개 모델 다운로드를 방지하는 DRM이 아니다. 치수 비공개는 UI의 숫자 표시를 끄며 모델 복원에 필요한 물리 크기는 공개 데이터에 존재한다.
- 임베드 이미지의 인코딩 메타데이터와 사용하지 않는 BIN 영역은 보존한다. 모든 바이너리 메타데이터를 제거했다고 주장하지 않는다.

## 검증

- 전체 637개 테스트 통과, 선택 벤치마크 2개 제외. TypeScript·Vite 프로덕션 빌드 통과. 500kB 초과 Three.js/PDF 청크 경고는 남는다.
- 테스트: 형상과 실제 물리 크기·회전, 임베드 PNG/UV/PBR 보존, 공개 JSON 허용 목록, 해시·중복 자산, 잘못된 포즈·ID·자산 거절, 인증·초안·발행 후 변경 차단, 크기 제한, 실패 정리·중단, 큰 위치의 기울어진 평면과 공유 카메라 경계.
- 실제 로컬 Wrangler/R2/UI: 이전에 실제 파일 입력으로 가져온 3개 작품을 링크로 생성했다. 2개 모델 자산만 업로드했고 3-mesh 형상·체크무늬 텍스처·작가·크기·배치 잠금을 확인했다. 시점 드래그와 평면 전환, 치수 표시를 끈 두 번째 링크, 콘솔 경고·오류 없음을 확인했다. 원본 합성 모델의 겹친 면은 그대로 보존하며 사용자 실제 모델의 정확도를 검증한 결과가 아니다.
- 모델 응답 SHA-256·MIME·no-store, 미참조 모델 404, 공개 PUT 405를 확인했다. 직접 생성한 두 로컬 링크는 중단 후 스냅샷·각 모델 요청 모두 410이었다. 원래 사용자의 localhost:5173 편집 초안은 변경하지 않았다.
