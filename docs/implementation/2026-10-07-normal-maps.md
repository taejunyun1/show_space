# 2026-10-07 — 수동 노멀 맵과 강도

요구 문서 2 §28의 Normal Strength를 기존 재질 편집에 연결한다. 벽·바닥·이미지 작품의 고급 설정에서 사용자가 가진 노멀 맵을 불러오고 강도(0–500%)와 한 반복의 실제 폭·높이를 조절한다. 색상 이미지와 독립적으로 반복하며 실제 구조 치수·작품 이미지·실루엣은 바꾸지 않는다. 사진에서 노멀/PBR 재질을 생성하는 기능은 유료 후속 범위다.

## 데이터와 렌더링

- PNG/JPG/WebP 20MiB 이하, 6천만 픽셀 이하를 입력하고 긴 변 1,024px 이하의 불투명 PNG로 저장한다. 저장 데이터는 PNG 헤더·치수·5MB 한도와 유한한 강도/실제 크기를 검사한다.
- OpenGL(+Y)는 픽셀을 유지한다. DirectX(-Y)는 불러올 때 녹색 채널만 반전해 +Y로 저장한다. 이후 강도 변경·저장·출력에서는 재반전하지 않는다. 투명 영역은 오류로 안내한다.
- 노멀은 `NoColorSpace`, 색상은 기존 sRGB 경로를 사용한다. 각 표면은 독립 텍스처 복제본과 반복 UV를 사용한다. 작품의 정규화 UV는 실제 W/H를 반영한다.
- 제거 시 `normalMap=null`을 명시해 기존 GPU 슬롯을 비운다. 교체·제거·타임아웃·언마운트에서 텍스처를 해제하며 프로젝트 전환/잠금 후 오래된 업로드 콜백은 적용하지 않는다.

## 보존 경로

재질 프리셋/마감·Undo/Redo·Scene·JSON·프로젝트 자산 ZIP·로컬 재질/작품 Library에 노멀 맵을 보존한다. Library를 이미지 작품에 적용할 때 작품 색상 이미지는 유지하고 노멀만 적용할 수 있다. private cloud package는 같은 ZIP 자산 슬롯을 사용한다. 실제 계정 클라우드 왕복은 이번에 검증하지 않았다.

공유 allowlist에는 이미지 ID·강도·반복 크기만 저장하고 원래 data URL/메모는 넣지 않는다. Scene 간 자산 ID 재매핑, 누락 자산의 publish 거부, 강도 범위 검사, 숨겨진 표면 제외와 링크 중단을 테스트했다. 실제 로컬 발표 모드에서 읽기 전용 렌더를 확인했다. 생산의 새 노멀 맵 링크 발행은 이번 UI 검증 범위가 아니다.

캡처·PDF·GLB/glTF는 같은 표면 표현을 사용한다. GLB 출력에서는 노멀을 사진용 JPEG로 재압축하지 않고 강도와 `KHR_texture_transform` 반복을 보존한다. 실제 SketchUp 수신 호환성은 미검증이다.

## 검증

- 최종 소스 전체 테스트 **906 통과 / 선택 벤치마크 2 제외**, TypeScript/Vite 빌드 통과.
- 합성 128×128 수학적 노멀 맵을 실제 파일 선택기로 벽/OpenGL 200%, 바닥/DirectX 150%, 작품/OpenGL 100%에 입력했다. JSON의 16,384 픽셀 모두 OpenGL 원본 또는 정확한 녹색 반전과 일치한다.
- 실제 GLB 761,236바이트에서 세 normalTexture 강도 2/1.5/1, 반복 [2,2]/[1,2]/[1.8,2.4]와 PNG 픽셀(출력의 수직 반전 포함)을 확인했다. 다운로드 GLB 해시와 상세 결과는 validation JSON에 기록한다.
- 실제 PDF 1페이지의 Scene 3D에서 바닥·벽 요철을 확인했다. 발표 모드도 같은 맵을 렌더한다.
- 재접속 후 벽 강도 200% 유지, 강도 0→Undo 200%, 바닥 맵 제거 후 실제 표면이 평평해짐과 Undo 150% 복원을 확인했다.
- 실제 자산 ZIP 744,985바이트/4자산의 해시, 현재·Scene의 노멀 슬롯 6개를 대조했다. 파일 선택기로 새 프로젝트에 복원하고 강도/Scene 미리보기 보존을 확인했다.
- 노멀만 있는 재질 Library 저장·재접속·다른 표면 적용·백업의 픽셀/강도/반복 보존을 확인했다. 원래 Library 항목은 유지했다.
- 390×844 바닥 dialog 폭351px, 내부 client/scroll 폭349px로 가로 넘침이 없다. 이는 데스크톱 viewport 검증이며 실제 모바일 GPU 검증은 아니다.
- 직접 만든 검증 프로젝트 2개와 Library 항목 1개만 복구 가능한 보관으로 정리했다. 원래 ANCA 전시와 기존 프로젝트는 유지했다.
