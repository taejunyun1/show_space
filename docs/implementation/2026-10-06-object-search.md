문서 2 §71의 Outliner 검색을 구현했다. 작품 제목·객체 이름·작가/재료·설치 벽/면·재질 프리셋과 액자/보호 재료를 로컬 문자열로 찾는다. 한글 NFC 정규화, 영문 대소문자 무시, 여러 단어 모두 포함을 적용한다. 역사 Scene·비공개 메모·이미지/모델 base64는 검색 대상으로 쓰지 않는다. 외부 API 요청은 없다.

공간 탭은 벽·바닥·조명·벽 작품·미배치·독립 3D 작품·전시장 참고 모델, 작품 탭은 작품 종류만 검색한다. 숨김과 잠금 객체도 결과에 유지한다. 결과는 기존 행에서 선택·Shift 다중 선택·잠금·표시 토글을 그대로 제공하며 검색만으로 표시/위치/크기를 바꾸지 않는다. 바닥은 재질 편집, 참고 모델은 기존 참고 모델 설정으로 연결한다. 미배치 작품은 원래 명시적 배치 버튼을 유지해 자동 배치하지 않는다. 원래 작품 번호와 전체 작품 수를 유지하고 검색 중 결과 수를 별도로 표시한다. Esc/지우기로 전체 목록에 돌아가며, 프로젝트를 바꾸면 이전 검색어를 초기화한다.
