# 변환된 전시장에 기존 작품 재설치와 잠금 보호

2026-10-11. [전체 전시장 원본 보존](2026-10-11-whole-venue-workflow.md)에 이어 변환 가능한 모델에서 원래 작품을 다시 설치하고 치수·Scene·백업·공유 데이터·GLB까지 연결했다. 원문 1 §6–10/12–18/24–35 및 원문 2 §9–18/43/46/48–55/67–70의 부분 연결이다. 자동 벽 인식 범위를 확대하지 않는다.

## 제품 변경

미배치 작품의 단일 배치는 시리즈와 달리 잠금·축척 미정 검사가 없었다. 이제 잠긴 작품이나 축척 미정인 편집 초안의 실제 크기 배치를 거절하며 원래 프로젝트·Undo/Redo·선택을 유지한다. 미배치 목록에 잠금/해제 버튼과 상태를 추가하고 잠금/축척 미정이면 배치를 비활성화한다. 잠금 변경도 한 번의 Undo로 복원한다.

이동/회전 진행 중 배치나 잠금 변경이 preview를 지우지 않게 보호한다. 배치 성공 후 선택 도구로 전환하고 기존 줄자 초안은 닫으며 선택 작품과 대상 벽을 맞춘다. 작품의 ID·이미지·숫자 W/H/D·액자·메모 데이터는 유지하고 기존 외곽 기준 위치 보정은 그대로 사용한다. 잘못된 잠금 대상은 history에 넣지 않는다.

실제 React/jsdom 목록의 잠금 해제→배치→두 번 Undo와 유효한 축척 미정 초안의 배치 비활성화를 확인했다. 이는 실제 서비스 브라우저 화면의 검증을 대신하지 않는다.

## 실제 변환 후 같은 작품을 전달

소유한 합성 GLB를 실제 File/GLTFLoader/벽 추출로 읽고 [1000,0,-2000]mm/30°/1.25배에서 직선 벽 4개와 바닥을 변환했다. 입력 바닥의 이론 면적은 75m², 기존 정수 mm 좌표로 둥근 결과는 74.9967m²다. 원본 네 모서리의 독립 변환 수식과 0.8mm 미만 오차를 확인했다. 임의 사용자 모델의 자동 복원이나 숫자 전체의 무오차로 확대하지 않는다.

- 기존 5점의 서로 다른 32×48 PNG·400/500/600/700/800mm 너비·600mm 높이·비공개 Note를 보존한다. 변환 뒤 미배치 목록과 숨긴 원본 모델, 기존 공간 Scene, Undo/Redo를 실제 store에서 확인했다.
- 같은 5점을 A면 간격 200mm/중심 높이 1500mm, B면 300mm/1800mm에 배열한다. 독립 숫자 계산으로 위치를 비교하고 외곽 치수 4곳의 간격과 약 9999.78mm의 벽 줄자 연결을 확인했다.
- 각 Scene을 저장한 뒤 높이를 바꾸고 복원해 작품·벽 연결·줄자 치수가 되돌아오는지 확인했다. JSON 직렬화 결과와 ZIP 복원 결과가 동일하고 ZIP CRC·원본 모델 1개/PNG 5개의 6자산도 확인했다.
- 공개 데이터는 선택한 새 Scene 2개·이미지 5개·참고 모델 0개다. 내부 Note·미배치/원본 data URL을 제외한다. 운영 URL 발행으로 집계하지 않는다.
- 실제 GLB 두 파일을 다시 읽고 각 작품의 XYZ 설치 위치와 이미지 전체 RGBA 픽셀, 숨긴 참고 모델의 출력 제외를 확인한다. 원본 입력/편집 프로젝트는 변하지 않는다.

위의 연속 흐름은 실제 domain/store/loader/Scene/ZIP/public/export 경로이며 FileReader·PNG만 native transport다. 시리즈 성공을 DOM 마우스 조작이나 전체 브라우저 인수로 바꾸지 않는다. 초기 잘못된 도면 초안 fixture, 정수 mm 면적 기대값, undefined JSON 필드, 공유 이미지 목록 형태 및 glTF의 중복 이미지 node 이름에 대한 검사 작성 오류는 제품 오류 근거에서 제외한다.

## 검증과 독립 수신

새 검사 9개. 같은 최종 3개 workflow 파일 20개를 이전 제품 코드 `87e1dbe`에 적용하면 8 실패/12 통과, 변경 후 모두 통과다. 기존 작품 외곽·editor 검사를 합친 대상 73개/5파일 통과, 전체 1,391 통과/선택 10 제외·239파일 통과/10 제외, TypeScript/production build 통과. 큰 청크 안내는 유지한다.

Blender 4.4.1로 실제 GLB 두 파일을 별도로 읽어 벽 4개·바닥·작품 5점의 총 15 Mesh와 packed 이미지 5장을 확인했다. 저장 좌표에서 독립 계산한 XYZ·실제 image 정점의 너비/높이·A/B 간격 및 바닥 top 삼각형 면적을 비교했다. 기대 설치 위치만 100mm 바꾼 실패 대조를 같은 importer 이후 거절했다. 파일 SHA가 workflow와 receiver에 모두 일치한다.

CPU/16 samples/1000×700의 두 벽면 미리보기를 생성해 5점 모두를 확인했다. 처음 전시장 밖의 시점에서 가벽이 작품을 가린 미리보기는 벽면 가까운 시점으로 교체했다. 모델 형상은 바꾸지 않는다. 브라우저 캡처나 측광 근거가 아니다.
