# 전시안 PDF 페이지 구성

문서 2 §49의 선택 Scene 순서와 Cover/Floor Plan/Perspective/Elevation/Detail 보기 지정에 대응했다. 기존 일괄 구성을 유지하며 **내보내기 → 전시안 PDF → 페이지 직접 구성**에서 페이지마다 현재 배치 또는 저장 Scene, 보기 종류, 제목과 순서를 지정한다. 페이지 추가·삭제·위/아래 이동을 지원한다. 직접 구성은 일괄 설정의 기존 순서로 시작하며, 치수 목록도 필요한 위치에 놓는다. 대화상자를 닫으면 구성은 초기화하며 프로젝트 영구 History로 저장했다고 주장하지 않는다.

3D는 현재/Scene 저장 시점, 버드아이뷰·정면·좌/우측면·사시 투시를 선택한다. 새 출력 사시 프리셋만 실제 geometry bounds로 맞추며 현재/저장 perspective는 그대로 사용한다. 벽면도는 선택 배치의 표시 벽과 A/B면을 고른다. 상세는 표시된 이미지 작품의 액자·매트를 정면으로, 독립 3D 작품을 주변 전시장 없이 실제 크기/회전으로 출력한다. 작품 이름·작가·연도·크기·분류·설치 형식·재료·설명을 포함한다. 긴 정보와 치수 목록은 순서를 유지하며 다음 페이지로 이어진다.

모든 페이지는 동일한 배치별 detached snapshot을 공유한다. Scene의 원래 구조·작품·재질·조명·야외 시간을 사용하며 편집 프로젝트/카메라/Undo는 복원하지 않는다. 내부 메모, 체크리스트, 참고 사진 및 원본 도면은 출력하지 않는다. 3D 미리보기는 Scene 썸네일·시간 비교와 같은 임시 GPU 큐를 사용한다. PDF Blob은 application/pdf다.

## 검증

- 전체 테스트 897개 통과 / 선택 벤치마크 2개 제외, 168 파일 통과 / 2개 제외. 모델 상세 화면 맞춤의 마지막 조정 후 관련 14개를 다시 통과했다. 최종 TypeScript/Vite 빌드 통과. 기존 큰 chunk 경고는 유지된다.
- 테스트는 Scene 혼합 순서·반복 선택·구조 보존·없는/숨긴 타깃 거절·일괄 구성을 직접 구성으로 바꾸기·선택된 작품만의 모델 preview·PDF에서 검색 가능한 한글/긴 설명 전체·페이지 경계·메모 제외·사시 projection의 모든 8개 모서리 포함을 확인한다.
- 실제 기존 ANCA에서 UI로 10개 항목을 구성하고 위로 이동해 순서를 바꿨다. 다운로드한 A4 가로 PDF는 12페이지이며, 표지→Scene D 평면→Scene D 사시→현재 A면→Scene A 이미지 상세→현재 치수 목록 3페이지→정면→좌측면→우측면→버드아이뷰 순서를 pdftotext로 확인했다. 3D 프리셋과 액자 이미지 상세를 렌더해 눈으로 확인했다. 비공개 설치 메모는 없었다.
- 별도 로컬 검증 복제본에 기존 합성 arch.glb를 업로드하고 1200×2100×900mm/Y30°와 작가·연도·재료·긴 설명을 넣었다. 두 상세 항목은 3페이지 PDF로 생성됐다. 전시장 없이 3D 모델이 보이고, 정보 계속 페이지의 마지막 문장까지 확인했다. 그 다음 Scene A 이미지 상세가 이어진다. 문장 끝의 3/D는 줄바꿈으로 나뉘므로 공백 정규화 후 전체 보존을 대조했다.
- 390×844 UI의 대화상자 351px, 내부 scrollWidth/clientWidth 349px로 가로 넘침이 없다. 실제 모바일 기기 검증은 아니다. 콘솔 경고·오류 없음.
- 원래 ANCA 작업에는 네 Scene과 16:30 환경을 보존했다. 이번 검증 복제본만 복구 가능한 보관으로 정리했고 PDF 파일은 Downloads에 남겼다.

증거: `../validation/2026-10-07-pdf-presentation.json`, 실제 UI 입력 JSON 및 `2026-10-07-pdf-page-local.png`, `pdf-page-mobile.png`, `pdf-perspective.png`, `pdf-detail.png`, `pdf-model-detail.png`.

ANCA는 not-to-scale 원본의 기존 가벼운 벽 초안이며 바닥 경계가 닫히지 않았다. PDF 출력이 정확한 전시장 재구성을 증명하지 않는다. 도면 인식·문/설비 직접 편집 범위는 늘리지 않았다. 전체 제품 목표는 진행 중이며 실계정·실기기·라이브러리 동기화·공동 작업/댓글·미디어/프로젝션·고급 조명/영구 History·실제 SketchUp 수신과 전체 사용자 인수는 별도 미완료다. 로컬 작품 정보 중복은 별도 미해결 관찰이다.

현재 배포 및 공개 확인을 이어간다.
