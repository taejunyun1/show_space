# 시간대 비교

원본 문서 2 §37의 네 시간대 비교를 구현했다. 3D의 `기타 시점 → 시간대 비교`에서 현재 배치 또는 저장 Scene을 기준으로 같은 시점의 09/13/17/20시 이미지를 한 화면에 표시한다. 날짜와 각 시간을 바꿀 수 있다. 기준 배치의 위치·시간대·북쪽·날씨 프리셋·개별 조명·작품·텍스처는 유지하고 비교 이미지에 야외 태양광과 해당 현지 시간을 적용한다. 위치 설정이 없는 프로젝트는 서울 예시임을 표시한다. 실내 원본을 선택한 경우에도 비교 이미지만 야외이며 현재 편집 환경을 바꾸지 않는다.

비교는 독립된 고정 이미지 렌더로 live 편집 Canvas나 카메라, 선택, Undo를 바꾸지 않는다. 기존 PDF 3D의 정적 형상/텍스처/조명 렌더러를 재사용하며 출력 긴 변은 1024px다. 편집 시점의 방향·벽 자동 숨김을 고정해 네 이미지가 같은 시점을 갖는다. 정투영은 원본 zoom을 그대로 축소하지 않고 각 칸에 공간 전체를 맞춰 1024×640으로 만든다. 원근 시점은 원래 카메라와 화면 비율을 유지한다. 원본 도면/편집 안내선/메모는 이미지에 표시하지 않는다. 태양 위치와 직사광은 기존 근사 계산이며 실제 날씨·지형·주변 건물 분석은 아니다.

모든 시간과 날짜를 먼저 검증해 서머타임의 존재하지 않는 시간은 렌더 전에 거절한다. 중복 시간은 첫 번째/두 번째 발생을 선택할 수 있다. 한 번에 하나의 임시 WebGL 렌더러를 실행하고 취소 뒤 새 작업도 기존 렌더의 자원 해제가 끝나기를 기다린다. 작업 변경/닫기 시 오래된 콜백과 다음 프레임을 중단하며 Blob URL을 회수한다. GPU 작업 도중 강제 인터럽트하는 방식은 아니다.

완성된 네 화면은 `네 시간대 Scene 저장`으로 원본 형상·재질·작품·조명·야외 시간·카메라를 포함한 Scene 네 개로 저장한다. 기존 Scene ID를 침범하지 않으며 현재 배치의 새로운 편집은 덮어쓰지 않는다. 프로젝트가 바뀌면 저장을 거절한다. 하나의 commit이라 한 번의 Undo로 네 Scene을 되돌린다. JSON/프로젝트 백업과 기존 Scene 복원 경로를 사용한다.

같은 ANCA 프로젝트에서 네 이미지가 실제 생성됐고 1001×1024px로 디코딩됐다. 2026-07-21 서울의 태양 높이 40.2/72.5/31.6/−2.5°를 표시하며 20시는 직사광 꺼짐이었다. 현재 배치와 저장된 `배치 D · 직접 텍스처 2×1m`을 각각 비교했다. Scene 4→8 저장 뒤 17시 Scene을 복원해 17:00을 확인했고 두 번 Undo로 원래 16:30과 Scene 네 개를 복구했다. 별도 저장/재접속 검사에서 여덟 Scene이 유지됐다. 이후 검증 과정에서 직접 만든 네 시간대 Scene만 삭제해 기존 네 Scene을 보존했다.

1280×900 dialog의 client/scroll 크기는 폭 1098px, 높이 808px로 네 이미지와 조작부가 한 화면에 들어갔다. 390×844에서는 세로 목록이며 dialog clientWidth/scrollWidth 349px로 가로 넘침이 없다. 콘솔 경고·오류는 없었다. 이번 범위에서 전체 native JSON의 전후 equality를 검증한 것은 아니다. 비변경·원본 보존의 전체 필드 검사는 도메인 테스트, 시간/Scene/이미지/실행취소는 실제 UI 증거로 구분한다.

873개 테스트 통과, 선택 벤치마크 두 개 제외, 빌드 통과. 새 여섯 테스트는 원본 프로젝트/재질/메모 보존, 저장 Scene 투영, 전체 배치 날짜/DST 검증, 원자적 네 Scene 저장·충돌 없는 ID·현재 편집/전체 필드 보존·직렬화, 고정 카메라/직렬 렌더/취소 교체의 동시 자원 한도를 검증한다. [기록](../validation/2026-10-07-time-comparison.json)과 동일 접두사의 scene/mobile/persisted PNG를 보존한다.

실제 모바일 기기·대형 장면의 성능 및 다른 원문 기능/실제 인증/전체 제품 인수는 계속 남아 있다. 이 기능을 전체 최종 구현 완료로 집계하지 않는다.

Cloudflare 배포 `ab3ea649-06c0-4d6c-8f65-a72a31167833`, 공개 엔트리 `/assets/index-CfPlGPCf.js`를 확인했다. 공개 기본 배치에서 네 이미지(1024×810)가 실제 생성됐고 콘솔 경고·오류가 없었다. 운영 프로젝트/공유 데이터 저장은 하지 않았다.

첫 공개 확인에서 칸 안의 공간이 작게 보여 정투영의 방향을 유지한 공간 맞춤과 설명 접기를 추가했다. 개선한 ANCA 네 이미지가 1024×640으로 생성되는 것을 로컬에서 확인했다. 이미지 출력의 framing만 바꾸며 live 카메라나 저장 Scene의 원래 카메라 값은 바꾸지 않는다. 기본 PDF 출력은 fit 옵션을 사용하지 않아 기존 화면 비율/zoom 경로를 유지한다.
