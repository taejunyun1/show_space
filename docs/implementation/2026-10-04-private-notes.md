# 2026-10-04 설치 메모·체크리스트·참고 사진

원래 구현 계획의 T9에 따라 프로젝트·바닥·전시장 참고 모델·벽·이미지 작품·3D 작품·조명에 설치 정보를 기록한다. 상단 메모는 프로젝트 전체, 바닥 재질 창은 바닥, 전시장 모델의 펼침 항목은 참고 모델, 속성 패널 NOTE는 선택 객체에 적용된다.

- 텍스트 20,000자, 체크 항목 100개(항목당 1,000자), 참고 사진 8개. JPG·PNG·WebP 원본 20MiB/6천만 픽셀 제한, 긴 변 2,048px로 저장하며 한 장 2MiB·한 메모 8MiB·프로젝트의 서로 다른 메모 사진 32MiB 제한이다. 저장 데이터의 실제 형식·픽셀 헤더를 검증하며 외부 URL/SVG는 받지 않는다.
- 로컬 자동 저장·Undo/Redo·JSON·자산 백업에 연결한다. 사진의 같은 바이트는 백업에서 SHA-256 자산 하나로 묶는다. 객체 형상 잠금 상태에서도 설치 메모는 수정할 수 있다. 이미지 처리 중 프로젝트·대상 모델을 바꾸면 이전 작업 결과를 적용하지 않는다.
- Scene은 배치를 전환한다. 현재와 복원 Scene에 같은 ID로 존재하는 객체의 최신 메모를 유지하고 프로젝트/바닥 메모도 유지한다. 현재 없는 객체를 과거 Scene에서 되살릴 때는 그 Scene의 기존 메모를 복원한다. 참고 모델은 같은 GLB에만 현재 메모를 유지한다. 기존 전체 구조 Scene 저장 방식을 새 버전 관리 방식으로 바꾼 것은 아니다.
- 공개 공유·PDF·GLB/glTF에 메모/체크 항목/사진을 넣지 않는다. 공개 조명 정보를 명시적 허용 목록으로 생성하며 Worker는 입력에 비공개 필드가 섞여도 이를 제거한다. 공유 파일에 참고 사진을 업로드하지 않는다.

## 검증

자동 테스트 659개 통과·선택 벤치마크 2개 제외, TypeScript·프로덕션 빌드 통과. 모든 메모 대상과 기존 파일 호환·잠금/복제/삭제·Undo·Scene·저장·ZIP 복원·공유 경계 및 잘못된 이미지/체크 구조를 검증했다.

실제 로컬 브라우저에서 작품/프로젝트/바닥/조명 메모를 입력하고 체크 상태·사진 표시·Undo/Redo·새로고침·Scene 전환 유지 및 공유 취소 후 뷰어 내용 제거를 확인했다. 사진은 직접 만든 320×180px 합성 PNG이며 원본 비율이 유지됐다. 편집기 콘솔 경고/오류는 없었다. 로컬 공유 JSON에 비공개 필드가 없고 공개 모델 SHA-256가 일치하며 취소 후 JSON/GLB 모두 410을 반환한다.

실제 내려받은 백업은 3,556,276바이트/자산 9개다. ZIP CRC 및 모든 자산의 해시/크기를 검사했고 프로젝트·작품·조명의 같은 사진이 하나의 자산을 참조한다. 앱의 실제 패키지 가져오기 모듈로 복원해 메모·체크 상태·내장 사진을 확인했다. 이번 사진 포함 백업을 별도 브라우저에 다시 업로드한 검증은 수행하지 않았다. 다운로드 이벤트 관찰은 처리 중 시간 초과됐지만 이후 생성 완료 ZIP을 확보했다. SSR 검증 도구의 샌드박스 WebSocket 경고는 패키지 복원 완료와 구분한다.
