# 액자·매트·앞면 보호와 실제 외곽 치수

2026-10-04. 원본 요구 문서 2의 §17 액자 폭·깊이·재질·매트·유리/아크릴 및 문서 1의 실제 치수·작품 간격을 구현했다. 도면 자동화/문·설비 직접 편집의 범위는 늘리지 않는다. 이 기록은 단계 완료이며 최종 제품 전체 완료를 뜻하지 않는다.

## 동작

오른쪽 액자·매트에서 기존 블랙·내추럴·화이트·없음, 슬림/갤러리 매트/깊은 액자 프리셋, 폭 1–200mm·깊이 1–5,000mm·목재/금속/도장, 매트 여백 0–500mm/색, 유리/아크릴/없음을 선택한다. 입력 W/H/D는 이미지·본체 치수다. 프레임을 끄면 설정을 보존하고 외곽 계산에서 제외한다. 깊이는 본체/액자 중 큰 값이다.

외곽 폭·높이 = 이미지 폭·높이 + 2×(액자 폭+매트 여백). 회전 시 이 외곽을 회전한 범위로 간격 정렬·벽 경계·바닥 하단·3D 드래그 이동 제한·미배치 재설치·계단 후보와의 겹침을 계산한다. 새 작품은 액자 끝에서 벽 안쪽으로 시작하며, 너무 짧은 벽이면 중앙에 배치하고 경고한다. 벽면 앞뒤 오프셋에는 액자 깊이를 쓴다. 저장·잠금·Undo/Redo·Scene·미배치·JSON/백업 및 서버의 공개 허용 목록에 포함한다. 작품 정보와 액자 패널의 React 키 충돌로 프로젝트 전환 시 정보가 누적되던 문제도 실제 UI 검증에서 수정했다.

## 형상·반사·비용

공통 도메인 치수로 편집/공유 3D, 평면 외곽, SVG 벽면, PDF, GLB/glTF를 만든다. 테두리는 속이 빈 사각 링이며 96개 이하 위치 정점이다. 이미지·매트·뒷판·앞면 보호를 별도 표면으로 둔다. 유리/아크릴은 고정 2/3mm, 얕은 액자는 깊이의 1/4까지 제한한다. 프레임 없는 본체와 이미지가 같은 깊이에서 깜빡이지 않도록 이미지 표면에 0.01mm 렌더 오프셋을 쓴다.

유리는 MeshPhysicalMaterial의 transmission=1, opacity=1과 기존 로컬 환경 반사를 사용한다. 실제 광학/실제 목재 결·금속 가공색을 재현한 인증 재질은 아니다. 반사 모양과 내보낸 GLB의 밝기는 수신 프로그램의 조명·환경에 달린다. 공식 근거: [Three.js MeshPhysicalMaterial](https://threejs.org/docs/pages/MeshPhysicalMaterial.html), [GLTFExporter](https://threejs.org/docs/pages/GLTFExporter.html). SVG/PDF 벽면은 외곽·매트·약한 유리색만 표현하며 실제 반사 시뮬레이션은 아니다. 투과 렌더링 비용은 앞면 보호를 켠 작품에만 적용하며 끄면 보호 형상·재질을 생성하지 않는다. 원본 3D 작품 형상은 변경하지 않는다.
