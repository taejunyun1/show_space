# 프로젝트 치수 표시·입력 단위 — 2026-10-04

상태: 구현·개별 검증 완료. 실제 인증/전체 인수와는 별도다.

원문 1 §5의 내부 millimeter/UI mm·cm·m 분리와 문서 2 §5의 Unit 설정을 연결한다. 기존 프로젝트는 mm 기본값으로 열리고, 상태바 단위 선택과 새 프로젝트 생성 단위 설정을 제공한다. 단위 변경은 프로젝트 설정 한 번의 Undo 대상이다. 새 도면 초안을 적용할 때도 현재 단위 설정을 유지한다.

`Project.displayUnit`은 선택적 메타데이터이며 스키마 1을 유지한다. 길이·좌표·측정 앵커·자산 크기는 mm를 그대로 저장한다. 숫자 입력만 mm로 환산하고 min/max/step도 같은 비율로 표시한다. 초기 반올림 문자열을 그대로 둔 포커스·blur는 원본 정밀한 값을 수정하지 않는다. 기존 각도·%·K·무단위 입력은 변환하지 않는다. 도면 축척 미정의 길이·X/Z·줄자는 px를 유지한다.

벽·작품 크기/설치 위치, 3D 작품·모델 위치, 액자/매트, 재질/Texture 실제 크기, 조명 길이, 벽면 설치 치수/줄자/평면·3D 라벨을 같은 프로젝트 단위로 표시한다. PNG/SVG의 화면 치수도 적용된다. 공개 스냅샷은 검증된 displayUnit만 추가하고 선택정보·Scene의 표시를 일치시킨다. 치수 비공개 링크는 계속 숫자/치수선을 숨긴다. GLB 기하 미터 규격과 PDF 설치 문서의 mm 숫자 기준은 유지한다.

830개 테스트/선택 2개 제외·빌드 통과. 변환/음수/소수/범위/잘못된 단위, 기존 프로젝트 기본값, 원본 정밀도 보호, 저장·복사·공개 스냅샷, Undo/Redo/Scene 설정 유지, NumberField의 비길이 값/px, 공개 SVG 단위·치수 비공개를 검증했다.

실제 브라우저 두 로컬 주소에서 다음을 확인했다: 1.25m 입력→1250mm 후 Undo1200mm, cm 설정 재접속 유지, 회전 Z30° 보존; 이미지 0.91234m→912.34mm 후 Undo900mm, 거칠기90% 유지; 새 전시장9.123m→9123mm; 두 점으로 1.23456m 새 벽→1234.56mm; 벽면도 0.945m×1.245m 액자 외곽; 모바일390px 선택기 접근/가로 넘침 없음. 1920×1519 PNG에서 9.123m·6m 치수도 실제 다운로드 파일로 확인했다. 다운로드 이벤트 관찰은 시간 초과됐으나 파일은 생성되어 중복 저장하지 않았다.

한 read-only 브라우저 로그 요청은 자동 승인 확인 시간 초과(위험 판정 아님)가 있었고 다음 페이지 상태 요청은 성공했다. localhost 콘솔 경고/오류는 없었다. 새 단위로 실제 공유 수신 브라우저와 실제 px 도면을 다시 올리는 시나리오는 이번 단계에서 하지 않았으며, 공개 허용 목록/SSR 및 px SVG 테스트가 해당 근거다.
