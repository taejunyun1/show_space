# 선택 객체 화면 맞춤 · 2026-10-07

문서 2 §43의 선택 Object Frame/Focus와 §67의 Focus 단축키를 기존 편집기에 연결했다. 인증 설정과 브라우저 연결 대기는 사용자의 결정대로 별도 보류한다.

## 사용과 범위

- 벽·이미지/영상 작품·3D 작품·조명을 선택하고 상단의 **선택 항목 화면 맞춤** 또는 **F**를 사용한다. Shift 선택 및 기존 그룹이 확장한 선택 목록도 함께 맞춘다.
- 3D: 현재 정면/측면/버드아이/임의 방향과 직교/원근 방식을 유지하며 선택 형상을 중심에 맞춘다. 액자·매트·깊이와 면내 회전, 3D 작품의 세 축 회전을 포함한다. 원근에서는 저장 화각을 유지하고 거리로 맞춘다. 실제 표시 조명·프로젝터 기기 마커의 크기도 포함한다.
- 평면도: 선택 객체의 수평 범위로 맞춘다. 축척 미정 도면 좌표는 px 그대로 사용하며 보정하거나 3D로 전환하지 않는다. 맞춘 뒤 확대/축소는 화면 비율과 중심을 유지한다.
- 벽면도: 선택한 첫 작품의 벽과 A/B면으로 맞춘다. 해당 면의 선택 작품만 포함하며 선택 벽이 있으면 벽 전체도 포함한다. 다른 벽/반대 면을 하나의 벽면도로 합치지 않는다. 3D 작품·조명만 선택된 경우 벽/작품을 선택하라는 안내를 표시한다.
- 숨기거나 삭제한 객체는 범위에서 제외한다. 숨김·잠금을 바꾸거나 객체/치수/내부 Note를 수정하지 않는다. 참조 공간 모델·바닥은 기존 객체 선택 모델에 없으므로 새 선택 대상으로 만들지 않았다.
- 이동·회전 중에는 요청을 거절하여 진행 중인 배치를 보존한다. 입력란·편집 가능한 글·대화상자에서 F는 편집기 단축키로 처리하지 않는다. 길게 누름/IME 입력도 Focus를 반복하지 않는다.
- Focus 요청은 프로젝트 ID와 현재 보기, 선택 ID 복사본을 포함하는 메모리 상태다. 다른 프로젝트/화면에서 오래된 요청을 재생하지 않으며 프로젝트 저장 및 Undo/Redo에는 넣지 않는다. 시점은 기존 Scene 저장/캡처 경로로 사용할 수 있다.

## 검증

새 회귀 9개 통과:

1. 실제 `buildExportScene`의 회전 벽/액자+매트+B면+37° 작품 월드 경계와 비교.
2. 기울어진 3D 작품/벽/조명의 혼합 선택, 숨김/삭제 제외.
3. px 좌표·화면 비율·입력 불변.
4. B면 90° 작품의 벽면 좌표 및 다른 면 제외.
5. 실제 Three.js OrthographicCamera/PerspectiveCamera에 선택 모서리를 투영. 세 화면 비율 × 두 투영 × 세 방향의 18조합에서 화면 안과 clip 범위 확인, 시점 방향 불변.
6. 좁은 원근 화면에서 프로젝터 기기 마커의 모서리를 투영하여 범위 안 확인. 단일 조명 좌표, camera/target 동일 좌표에서도 유한하고 controls zoom 범위 유지.
7. 반복 요청의 token/view, 선택 복사와 프로젝트/히스토리 불변.
8. 빈 선택·진행 중 transform 보호.

최종 전체 **1,087 통과 / 선택 실행 10 제외**, TypeScript/Vite 빌드와 `git diff --check` 통과. 선택 제외 테스트는 기존 native/fixture opt-in 항목이다. 실제 브라우저 F 입력·클릭·드래그·화면 픽셀 인수는 연결 복구 후 수행할 항목으로 남긴다. 독립 카메라 투영 검증을 실제 사용자 UI 인수 완료로 집계하지 않는다.

## 원문과 남은 항목

§43/67의 이번 누락은 구현했고, 원문 MVP 전체 24단계 흐름/실제 계정·두 기기/실기기 성능/프로젝터 투사 픽셀/운영 배포 인수는 별도다. §62 IES/Lux와 AI·사진 생성/결제는 기존 MVP 이후 및 유료 후속 범위를 유지한다. 문·설비·설치 제외 영역 직접 편집 또는 도면 정밀 복원을 확대하지 않는다.
