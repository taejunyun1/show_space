# 복수 작품 정렬·간격

2026-10-04. 원본 Pages 1 §12(MVP Alignment)와 Pages 2 §23을 대조해 영상 재생 확장보다 먼저 구현했다. 사용자 후속 결정에 따라 도면 자동 인식·문/설비 직접 편집 범위는 확대하지 않았다.

## 동작

같은 벽·같은 면의 이미지 작품을 Shift로 두 개 이상 선택하면 오른쪽 **작품 정렬·간격** 패널이 나타난다. 왼쪽/오른쪽/상단/하단과 가로/세로 중앙을 선택 범위의 외곽 또는 중심에 맞춘다. 액자 폭·매트·면내 회전을 포함한 물리 외곽을 사용하며 본체 W/H/D·이미지·액자 설정을 바꾸지 않는다. B면의 좌우와 순서는 벽면도에서 보는 방향을 따른다.

**가로 등간격 / 세로 등간격**은 선택 범위 양 끝을 유지하고 각 작품 외곽 사이 거리를 동일하게 만든다. 합산 작품 크기보다 범위가 작으면 거부한다. 숫자로 지정한 **작품 사이 간격**은 가로 왼쪽 또는 세로 위쪽 외곽에서 시작해 정확한 mm 간격으로 재배치한다. 가로는 보이는 왼쪽부터, 세로는 위부터 현재 순서를 유지한다. **선택 범위를 벽 중앙으로**는 전체를 평행 이동한다. **중심 높이 맞춤**은 모두 같은 바닥 기준 높이로 배치한다.

잠긴 작품·축척 미정 도면·다른 벽/면·일부만 선택된 그룹은 배치하지 않는다. 한 작품이라도 벽 밖으로 나가면 전체 변경과 Undo 기록을 만들지 않는다. 정상 배치는 한 번의 Undo이며 선택은 유지한다. 반복 적용으로 위치가 달라지지 않으면 빈 Undo를 만들지 않는다. 그룹 이동은 기존처럼 상대 간격을 유지하지만 정렬·간격 명령은 그룹을 유지하면서 개별 위치를 바꾼다. 3D 작품은 이 벽면 정렬에 포함하지 않는다.

## 검증

- 도메인 6개와 편집 상태 3개 신규 테스트. 전체 760개 통과·선택 벤치마크 2개 제외, TypeScript/Vite 빌드 통과. 기존 큰 청크 경고는 남는다.
- 실제 파일 선택으로 16,000×9,000mm 합성 전시장에 작품 10개 입력. 각 이미지 400×500mm, 액자 30mm·매트 60mm·깊이 70mm·유리, 외곽 580×680mm를 유지한 250mm 간격/벽 중앙 배치. JSON 다운로드에서 첫 외곽 3,975mm·마지막 12,025mm, 간격 9개 각 250mm, 중심 높이 1,450mm와 모든 디자인 필드 보존을 확인했다.
- B면의 200/400/600mm 폭 작품 중 하나를 33° 회전해 실제 SVG 외곽을 계산하고 여섯 방향 정렬을 비교했다. 모두 오차 0.000001mm 이내였다. 자동 가로/세로 간격과 지정 세로 간격 두 개 각 250mm, B면 가로 250mm·중앙 8,000mm·중심 높이 1,450mm를 확인했다. JSON 다운로드에서도 회전/치수/이미지/액자 설정 보존.
- 50,000mm 간격 전체 거부와 위치 불변, 잠금/다른 벽/다른 면에서 버튼 비활성, Undo/Redo·그룹·Scene 복원·재접속 후 위치 보존을 확인했다. 공유 출력의 위치는 자동 테스트로 확인했으며 이 단계에서 새 공개 테스트 링크는 발행하지 않았다.
- 390px 실제 UI에서 정렬 버튼 클릭/Undo와 폭을 확인했다. 발견한 기존 상단 버튼/두 열 속성 패널 가로 넘침은 작은 화면의 상단 두 줄·속성 한 열로 수정했다. 최종 문서 폭 390px, 정렬 패널 346px·좌우 22/368px·scrollWidth 346px. 모바일 실기기 성능을 의미하지 않는다. 로컬 검증 탭 콘솔 경고/오류 0.

## 남은 범위

원본 §13/§14의 벽면 치수·작품 사이 측정 표시 확대, Object Edge/Center snap, 최종 제품 요구 대조와 사용성 검증이 남아 있다. 실제 Supabase 인증·두 계정/기기와 사용자 SketchUp·대형 모델·모바일 실기기 검증은 별도 미완료다. 영상 재생/프로젝션은 후속 확장이고 원본 SKP 직접 입력은 미지원이다. 전체 제품 목표는 계속 진행 중이다.
