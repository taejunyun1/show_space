# 야외 전시 환경 — 2026-10-03

문서 1의 Outdoor Environment와 계획 T8에 따라 야외 태양·시간·환경을 편집 데이터에 연결했다. 기존 실내 모드는 유지하며 개별 Spot·Area 조명을 함께 사용할 수 있다.

## 사용

공간 목록 → 야외 환경 · 태양과 시간 → 환경을 야외로 선택한다. 위도·경도, 프로젝트 IANA 시간대, 날짜·현지 시간, 평면도에서의 북쪽 방향을 입력한다. 기본 위치는 서울의 예시 좌표이며 위치 권한이나 외부 API를 요청하지 않는다. 날짜 범위는 1901–2099년, 시간은 00:00–23:59이다. 북쪽 0°는 평면도 위쪽(−Z), 시계 방향 90°는 오른쪽(+X)이다.

3D 아래 시간 슬라이더로 태양·그림자·밝기를 확인한다. 드래그·키보드 조절은 한 번의 Undo로 되돌아가며 Esc·포인터 취소·보기 전환은 미확정 미리보기를 취소한다. 줄자 측정 중에는 시간 바를 숨긴다.

맑음·흐림은 연출이며 실제 기상 정보가 아니다. 일몰은 그날 해당 장소의 오후 태양 높이 약 4°인 15분 단위 시간을 선택하고, 야간은 태양이 −6° 이하인 시간 중 22시에 가까운 시간을 선택한다. 백야 등 해당 시간이 없는 경우 기존 설정을 유지하고 이유를 표시한다. 프리셋 선택 후 시간을 직접 바꾸면 계산된 태양 높이를 따른다.

## 계산·렌더링

[NOAA General Solar Position Calculations](https://gml.noaa.gov/grad/solcalc/solareqns.PDF)의 fractional-year·균시차·태양 적위 식을 사용한다. 프로젝트 현지 날짜를 실제 UTC 순간으로 변환한 뒤 계산하므로 실행 기기의 시간대를 사용하지 않는다. 서머타임 공백은 거절하고, 반복 시간은 첫 번째/두 번째를 선택할 수 있다. 대기 굴절·지형·주변 건물·기상 측정값을 반영한 정밀 일조 해석은 아니다.

Three.js DirectionalLight의 position → target 방향으로 태양을 조준한다. 그림자 범위는 이동된 전시장·바닥·참고 모델의 실제 경계와 벽/작품 여유 범위에 맞춘다. 태양을 포함한 그림자 광원은 최대 4개이며 나머지 Spot은 빛만 비춘다. 지평선 아래에서는 직사 태양을 만들지 않고 주변광·반사 밝기를 낮춘다. 개별 실내 광원은 밤에도 유지한다.

배경은 시간·날씨에 맞춘 색이며, 재질 반사가 필요한 경우 Three.js Sky의 PMREM 환경맵을 로컬에서 생성한다. 실내 RoomEnvironment와 분리하고 GPU 자원은 해제한다. 실제 기상 하늘이나 주변 전시장 오브젝트의 실시간 거울 반사는 아니다. 야외 기본 밝기는 자동 환경 설정을 따르므로 실내 기본 조명 대화상자는 야외에서 편집을 비활성화한다.

## 저장·공유·출력

- Project/Scene 구조에 outdoor를 저장하고 새 실내 Scene도 명시적인 indoor 설정을 저장한다. 이전 파일/Scene에 필드가 없으면 기존 방식으로 읽는다.
- JSON·자산 백업 ZIP에 전체 환경과 각 Scene 시간을 보존한다. PDF는 Scene의 태양·반사·시간을 적용하고 날짜·현지 시간·시간대·북쪽을 머리글에 표시한다. PNG에는 화면의 조명과 배경을 담는다.
- 읽기 전용 공유에 현재 환경을 포함하고 서버에서 날짜·시간대·범위를 다시 검사한다. 공유 창에 좌표/시간 포함을 표시한다. 임의 메타데이터·내부 Note는 허용 목록에서 제외한다.
- GLB/glTF에는 낮의 태양을 KHR_lights_punctual directional로 저장한다. 실제 파일의 조준 방향을 다시 읽어 검증한다. 환경맵·날짜/위치/시간·그림자 설정과 Area 광원은 이 표준 교환 파일에 들어가지 않으며 전체 편집 복원에는 자산 백업을 사용한다.

## 확인한 범위

전체 자동 테스트 605개 통과·선택 벤치마크 2개 제외. 서머타임 공백/반복, 45분 시간대, 윤년, 극지, 동일 UTC 순간, 북쪽 회전, 일몰/백야 처리, Undo, 구버전 Scene, 백업 왕복, PDF Scene 상태, 공유 API의 검증/개인 필드 제거, 이동된 40m 공간의 그림자 경계, 낮/밤의 총 4개 그림자, 실제 GLB/glTF의 방향 검증을 포함한다.

브라우저: 서울 2026-06-21의 07:41/17:20 그림자 변경, 00:00 직사광 꺼짐, 일몰 19:30·북쪽90°, 드래그 한 번 Undo, 새로고침 후 오전/일몰 Scene 복원, 좌표 소수 넷째 자리, 잘못된 시간대 거절, 스테인리스 표면의 야외 환경맵, 로컬 읽기 전용 공유와 서버 응답을 확인했다.

실제 PNG 1920×1519와 오전/일몰 2쪽 PDF를 다운로드해 렌더링과 한글 머리글을 확인했다. 실제 자산 백업 ZIP은 이미지 5개와 각 Scene의 날짜·시간·북쪽을 보존하며 CRC·파일 크기·SHA-256을 확인했다. 실제 GLB는 directional 태양을 포함한다. 브라우저 다운로드 이벤트 감지는 타임아웃했지만 Downloads의 새 파일 자체를 확인했다. PDF/PNG를 단순 완료 알림만으로 통과 처리하지 않았다.

최종 제품 완료는 아니다. 원본 SKP 변환, 3D 작품, 계정 저장, 추가 스냅·메모 형식, 공유 Scene 탐색, 대형 전시장·모바일 실기기 검증 등이 남아 있다. 이 단계의 위치/날씨는 입력과 계산 기반이며 자동 GPS·지도·기상 API는 제공하지 않는다.
