# 전시장 직접 편집 우선 구현 계획

결정일: 2026-09-27. 상태: E1 실제 포인터 이동·회전/저장 복구 검증, 정밀 각도 입력은 남음. E2 구조 수정 1차(두 점 벽 그리기·끝점/축/격자 스냅·다중 벽 이동/회전/복제/잠금·연결/분리)와 줄자·저장 치수선·세 뷰 1920/3840px 캡처 1차 구현. E3 부분 도면의 축척 미정 편집 진입·재분석 수정 보존을 구현하고 브라우저에서 검증함. S1 공유 링크 생성·별도 읽기 전용 뷰어·중단을 1차 구현함. Three.js의 유휴 렌더링 중단과 벽 가시성 계산 경량화를 적용함. E4는 같은 벽 내 3D 작품 드래그 1차 구현. E2의 3D 정밀 스냅·상세 측정 보조와 E4의 다른 벽으로 직접 이동·회전·미배치 보관·설비 편집, E5는 남음.
근거: 사용자 요청 — 벽 인식은 어느 정도의 초안을 제공하고, 클릭·이동·삭제·회전 등 직접 편집을 핵심 기능으로 추가한다.

## 1. 목표와 우선순위 변경

기존의 완전 자동 공간 복원은 장기 목표로 유지한다. 당장의 최우선 출시 조건은 **도면 불러오기 → 인식 가능한 벽 초안 표시 → 마우스로 수정 → 작품 배치 → 저장/복구**다. 자동 인식 정확도 향상이 편집기 출시를 계속 막지 않도록 한다.

자동 인식 실행 자체는 계속 자동화한다. 사용자가 OCR·벽 후보·치수를 항목별로 확인해야 편집 화면에 들어가는 흐름은 만들지 않는다. 불확실한 부분은 편집 가능한 초안과 상태 표시로 제공한다. 부분 초안을 전체 복원 성공으로 집계하지 않는다.

계획 작성 시 확인 기준: 9240d72. 이후 E1의 벽 이동·회전 코드와 편집 도구를 별도 구현했다.

## 2. 기존 기능과 실제 공백

- Gallery3D: 벽/작품 클릭·Shift 선택, 벽 이동·회전 핸들 및 OrbitControls 카메라 조작. 작품 자유 이동은 없음.
- PlanView: 벽 전체 이동·회전·끝점 드래그와 두 점 벽 그리기. 2D 박스 선택은 남음.
- App/editor: 삭제·실행 취소/다시 실행·다중 선택 복제·잠금·자동 저장 기반 존재.
- Workspace: 선택·이동·회전·벽 그리기·줄자 도구 전환. 현재 뷰 캡처와 출력 옵션이 있다. 촬영 시점 저장과 미리보기는 남음.
- EntitySelection: wall/artwork만 지원. Opening은 벽 끝점/공통 접점에 연결된 경계 모델이고 설비는 주로 도면 표기이므로, 독립 편집 객체로 확장 필요.
- Scene: 작품과 벽 표시 상태만 저장. 이동한 벽 구조를 배치안별로 복구할 수 있도록 확장 필요.

## 3. 기본 화면과 조작 계약

상단 도구: 선택 / 이동 / 회전 / 벽 그리기 / 줄자 / 치수 표시 / 캡처 / 복제 / 삭제. 왼쪽은 객체 목록·잠금·숨김, 오른쪽은 선택 객체의 길이·높이·두께·위치·각도. 하단은 현재 조작 안내와 거리/각도 입력. 2D·3D·벽면도는 같은 모델을 사용한다.

| 행동 | 구현할 동작 |
| --- | --- |
| 선택 | 클릭 단일 선택, Shift+클릭 선택 추가/해제, 빈 곳 클릭 해제. 잠긴 객체는 확인 가능하지만 변형 불가 |
| 범위 선택 | 2D에서 드래그 박스, 기본은 상자 안에 완전히 들어온 객체. 3D 박스 선택은 후속 단계이며 뒤쪽 객체를 몰래 선택하지 않음 |
| 이동 | 선택 도구에서 선택 객체 드래그 또는 M 이동 도구. 이동 도구는 기준점 클릭→목표점 클릭도 지원. 바닥 평면 이동이 기본 |
| 회전 | Q 또는 회전 버튼, 중심점·끝점·사용자 지정점을 기준으로 수평 회전. 원형 핸들 및 각도 입력 |
| 치수 | 벽 끝점으로 길이 조정, 3D 상단 핸들로 높이 조정, 속성 입력으로 길이·높이·두께 설정 |
| 정밀 입력 | 이동 중 500mm/0.5m, 회전 중 30° 등 입력 후 Enter. 기본 단위 mm, 잘못된 값은 적용하지 않음 |
| 스냅 | 끝점·중점·축·격자 표시, 회전 15° 간격 옵션. 단축키와 화면 버튼으로 일시 해제 가능 |
| 삭제/복제 | Delete/Backspace 및 버튼, Cmd/Ctrl+D 복제. 여러 선택을 한 번에 처리하고 한 번의 실행 취소로 복구 |
| 취소 | Esc는 진행 중 조작 취소, 다음 Esc는 선택 해제. 뷰 변경·포인터 취소 시 미리보기 취소 |
| 카메라 | O 궤도 회전/H 화면 이동 도구, 휠 확대, 중간 버튼 궤도 회전·Shift+중간 버튼 화면 이동. 트랙패드용 도구 버튼 제공 |

객체 드래그 중 카메라 조작을 중지하고 완료/취소 시 복구한다. 클릭과 드래그는 화면 픽셀 이동량으로 구분한다. 도구와 조작 핸들은 확대 수준과 무관하게 클릭 가능한 크기를 유지한다. 텍스트 입력/대화상자에서는 편집 단축키를 가로채지 않는다. SketchUp의 선택·기준점 이동·축 제한·각도 입력 방식을 참고하되 위 조작 계약은 이 제품의 설계다.

## 4. 객체별 편집과 연결 규칙

### 벽

- 초기 범위: 수직인 벽을 바닥 평면에서 자유 이동·수평 회전한다. 벽을 기울이는 자유 3축 변형은 후순위다.
- 기본은 선택한 벽만 이동한다. 인접 벽을 자동으로 늘리거나 다른 방 전체를 당기지 않는다.
- 별도의 연결 유지 옵션은 공유 끝점에 연결된 이웃 벽의 끝점을 함께 이동한다. 영향받는 벽을 미리 강조하며 잠긴 이웃 때문에 불가능하면 적용하지 않는다.
- 여러 벽 선택 시 공통 이동량/회전 중심으로 변형하고 내부 길이·상대 위치를 유지한다.
- 스냅은 위치 정렬이다. 접합 관계를 변경하는 연결/분리 작업과 구분한다.
- 벽 삭제 또는 이동으로 외곽이 열려도 편집은 가능하다. 닫힌 영역만 바닥을 생성하고 열린 부분을 표시하며 가짜 바닥을 자동 생성하지 않는다.
- 벽 그리기는 시작/끝 두 점, 연속 그리기, 길이 입력을 지원한다. 이후 벽 분할·병합과 연결/분리를 추가한다.

### 작품

벽 이동·회전 시 부착된 작품은 벽 기준 거리와 설치 높이를 유지한다. 벽면 위 직접 드래그, 다른 벽으로 드래그하여 부착 대상 변경, 액자 면내 회전을 지원한다. 벽 길이/높이를 줄여 작품이 벗어나면 표시하고 조정할 수 있게 한다. 벽 삭제 시 작품을 조용히 소실시키지 않고 미배치 목록으로 옮긴다. 실행 취소는 부착 관계까지 복원한다.

구현 기록(2026-09-27, E4 1차): 3D에서 작품을 눌러 같은 벽의 가로 위치와 높이를 직접 드래그한다. 커서 광선을 벽 앞 작품 면에 투영해 잡은 지점을 유지하며 10mm 단위로 맞추고, 벽 범위 안에 머물도록 제한한다. 드래그 미리보기는 저장하지 않고 놓을 때 한 번만 기록한다. Esc·포인터 취소·뷰 전환 시 미리보기를 버린다. 잠긴 작품 위에서 벽 드래그가 시작되지 않게 막는다. 다른 벽 이동은 기존 속성 패널의 설치 벽 선택을 사용하며 3D 직접 벽 넘기기·면내 회전·미배치 보관은 미구현이다.

### 문·창문

벽에 부착된 문·창과 경계 사이 통로를 구분한다. 벽 부착형은 벽 기준 위치·폭·높이를 저장하여 벽을 따라가고, 서로 다른 벽에 걸친 통로는 참조 양끝으로 계산한다. 한쪽 벽만 움직일 때 통로를 다른 위치로 강제 재부착하지 않는다. 유효하지 않은 관계는 연결 미확정 상태로 보존하여 다시 연결하거나 삭제할 수 있게 한다. 자유 접점도 다중 선택 이동 시 한 번만 변형한다.

### 기둥·계단·에어컨·소화전·설치 제외 영역

실제 모델 객체로 추가/선택/이동/회전/삭제할 수 있게 한다. 도면의 글자 상자는 객체의 실제 크기와 별개로 유지한다. 설치 제외 영역은 별도 편집 가능한 도형으로 저장하며 표시/숨김과 삭제를 구분한다. 설비/계단에 연결된 영역은 함께 이동하고, 독립 지정 영역은 제자리에 남는다. 실제 안전거리의 자동 확정은 하지 않는다.

## 4A. 캡처와 치수 측정 — 핵심 편집 범위 추가

추가 요청일: 2026-09-27. 여기서 촬영은 편집 중인 전시장의 화면 캡처이며 기기 카메라 촬영이 아니다. 두 기능 모두 첫 핵심 마일스톤에 포함한다.

### 캡처

현재 ExportDialog/Gallery3D에 현재 3D 카메라의 PNG 저장이 있다. 이를 툴바의 카메라 버튼과 촬영 미리보기로 확장한다.

구현 기록(2026-09-27): 평면도·벽면도 SVG 재렌더와 3D WebGL 재렌더로 긴 변 1920/3840px PNG를 저장한다. 치수·격자·원본 도면 옵션, 선택 표시 제거, 벽면 작품 이미지 합성을 브라우저에서 확인했다. 3D 뷰 전환 직후 작품 텍스처가 늦게 뜨는 경우 캡처가 이를 기다리며, 준비되지 않으면 오류를 표시한다. 촬영 전 미리보기, 설비/설치 제외 영역 독립 옵션, 원근 시점 저장은 아직 없다.

- 현재 시점을 한 번에 PNG 저장한다. 사이드바·툴바·선택 강조·조작 핸들은 기본 제외한다.
- 3D뿐 아니라 평면도·벽면도도 현재 뷰를 유지하여 저장한다. 평면도 캡처가 강제로 3D로 전환되어서는 안 된다.
- 기본 보기 이미지와 치수 포함 이미지를 선택한다. 치수선·숫자·단위, 설비/설치 제외 영역, 격자, 원본 도면은 별도 표시 옵션을 제공하며 미리보기와 저장 결과가 같아야 한다.
- 기본 해상도와 고해상도(긴 변 3840px 목표)를 제공한다. 비율을 유지하고 브라우저 메모리/최대 렌더 크기에 따른 실패 시 축소 저장을 안내한다.
- 고해상도 출력은 현재 모델과 카메라 상태로 다시 렌더링한다. 화면 PNG를 단순 확대하지 않는다. 내보내기 후 카메라·선택·표시 상태를 복원한다.
- 3D의 HTML 치수 라벨은 WebGL 캔버스만 저장하면 누락되므로, 2D/SVG 및 3D 주석을 출력에 합성하는 경로를 설계한다. 이미지/폰트 준비 후 캡처하며 외부 이미지 로딩·CORS 실패를 빈 그림 성공으로 처리하지 않는다.
- E5에서 시점 저장/불러오기와 관람객 눈높이의 원근 카메라 촬영을 추가한다. 초기 캡처는 기존 카메라에서 시작한다.

### 줄자 및 치수선

현재의 자동 치수 표시 및 원본 도면 축척 보정과 별도로, **T 또는 줄자 버튼 → 첫 점 → 두 번째 점**으로 실제 모델 거리를 측정한다.

구현 기록(2026-09-27): 세 뷰 두 점 거리 측정, 프로젝트 저장 치수선, 라벨 간격 입력·삭제·Undo/Redo, 벽 상대 앵커 이동 추종과 연결 끊김 표시를 구현했다. 평면 3/4/5m, 벽면 높이 차, 3D 바닥 거리, 저장 후 재열기를 확인했다. 3D 끝점/작품 테두리 스냅, 수평·수직 성분 분리, 포인터 드래그 라벨 이동은 남았다.

- 평면도: 바닥 위 두 점의 거리. 벽면도: 벽면 위 거리·설치 높이. 3D: 클릭한 면/끝점의 두 3차원 좌표 사이 직선거리.
- 3D에서 두 점이 놓일 면을 미리 표시하고, 표면을 못 잡으면 임의 깊이의 값을 만들지 않는다. 기본 직선거리와 수평/수직 성분을 명확히 구분한다.
- 벽 끝점·모서리·중점·작품 테두리에 스냅한다. 벽 길이/높이/두께, 작품 사이 간격, 바닥에서 작품까지 높이, 통로 폭을 측정할 수 있다. 평행 면 사이 수직거리 보조는 E4에서 확장한다.
- 임시 측정 후 ‘치수선 남기기’로 저장한다. 치수선 위치/라벨을 옮기고 선택·삭제하며 Undo/Redo를 지원한다. 읽기만 하는 측정이 모델 크기나 축척을 바꾸지 않는다.
- 측정 끝점은 객체 참조+로컬 위치 또는 고정 좌표로 저장한다. 객체에 붙인 치수는 이동·회전·크기 변경 시 갱신한다. 객체 삭제 시 연결 끊김을 표시하고 재연결/삭제 가능하게 하며 Undo로 참조까지 복구한다.
- 내부 단위 mm, 화면 mm/cm/m 전환과 적절한 반올림을 지원한다. 축척 미정 초안에서는 px 또는 축척 미정으로 표시하고 실제 거리인 것처럼 내보내지 않는다. 기본 높이 등 추정 치수를 측정하면 추정 상태도 표시한다.
- 저장한 치수선은 프로젝트 재열기와 치수 포함 캡처에서 유지한다. 캡처는 모델의 치수이지 현장 실측을 검증했다는 뜻이 아니다.

완료 검증: 알려진 3000mm 벽과 3000/4000/5000mm 삼각형 측정, 3D 높이·직선/투영 구분, 줌/시점 변경 시 거리 불변, 벽 변경에 따른 참조 갱신, 저장 왕복, 축척 미정 표시. 캡처는 세 뷰에서 UI 제외·치수 포함/제외·해상도·카메라 비율을 이미지로 직접 확인한다.

## 4B. 보기 전용 공유 링크 — 필수 공유 마일스톤 S1

추가 요청일: 2026-09-27. 작성자가 링크를 만들면 상대방이 설치나 로그인 없이 전시장을 열어볼 수 있다. 공유 뷰어에서는 모든 오브젝트의 배치·속성을 잠그고 카메라 탐색만 허용한다. 편집기의 개별 locked 속성과 별개인 문서 전체 읽기 전용 권한이다.

### 작성자 흐름

1. 공유 버튼에서 현재 배치의 공유용 미리보기를 연다.
2. 포함 항목을 확인한다. 기본은 벽·작품·설비·현재 공개 배치이며 원본 도면, 내부 메모, 분석 기록, 다른 배치안, 편집 이력은 제외한다. 치수 공개는 별도 옵션이다.
3. ‘링크 만들기’로 현재 상태의 스냅샷을 서버에 저장하고 링크를 복사한다. 이 동작이 최초 서버 업로드이며 기존 로컬 자동 저장을 자동 업로드로 바꾸지 않는다.
4. 공유 목록에서 링크 복사·새 버전 링크 생성·공유 중단을 할 수 있다. 작성자가 이후 원본을 편집해도 이미 보낸 링크는 바뀌지 않는다. 새 배치는 새 링크로 보내고 이전 링크는 필요하면 중단한다.

### 받는 사람의 화면

- 3D 회전·화면 이동·확대/축소·기본 시점 복귀와 평면도/벽면도 보기 지원. ‘보기 전용’ 상태 표시.
- 객체 선택은 이름·공개 속성 확인 용도로만 허용한다. 이동·회전·크기 변경·삭제·추가·복제·편집 핸들·원본 내보내기·프로젝트 저장 기능은 제공하지 않는다.
- 치수 옵션을 끈 링크에서는 저장 치수선뿐 아니라 숫자 속성 및 줄자 도구도 제공하지 않는다. 옵션을 켠 링크는 임시 측정만 허용하고 공유 스냅샷에 기록하지 않는다.
- 기본 카메라는 링크 생성 당시 시점을 사용한다. 원본 프로젝트나 작성자의 카메라 상태에는 영향을 주지 않는다.
- 만료/중단된 링크는 전용 안내를 보여준다. 열람자가 실제로 받아 본 화면의 캡처나 내려받은 데이터까지 회수할 수 있다는 의미는 아니다.

### 저장·권한 설계

현재는 정적 Cloudflare 배포와 브라우저 저장만 있으므로 실제 공유에는 서버 API·공유 스냅샷 저장소·작품 이미지 저장소가 필요하다. 제품 선택/요금/용량 제한은 구현 시 확인한다. 프로젝트 전체 JSON을 URL에 넣지 않는다.

- 작성자 인증 및 소유권 검사 후 공유 생성·중단 가능. 열람 링크는 추측하기 어려운 토큰을 사용하며 읽기 전용이다. 토큰을 가진 사람은 열 수 있음을 공유 창에서 안내한다. 비밀번호·지정 사용자 공유는 후속 범위.
- 편집용 Project와 별개인 공개 스키마를 허용 목록으로 직렬화한다. 내부 메모와 원본 도면을 단순 UI 숨김으로 처리하지 않고 서버 공개 응답에서 제외한다.
- 뷰어 경로는 편집 store·키보드 명령·자동 저장을 실행하지 않는다. 편집 단축키나 직접 API 호출로 공유 원본을 변경할 수 없도록 서버도 수정 요청을 거부한다.
- 공유된 작품 이미지가 작성자의 로컬 blob URL/브라우저 캐시에 의존하지 않게 저장한다. 외부 리소스가 없어도 다른 기기에서 같은 결과가 나오는지 검증한다.
- 공유 중단은 스냅샷과 이미지 요청 모두에서 검사한다. 원본 저장소의 영구 공개 주소로 우회되지 않도록 하며 캐시 정책도 맞춘다. 이미 열린 화면은 재검증 시 중단을 반영하고 과거 수신 데이터 회수는 보장하지 않는다.
- 업로드 용량·이미지 형식·프로젝트 스키마 검사, 중복 요청 처리, 부분 업로드 실패 정리, 객체 참조 수명 관리를 구현한다. 링크 중단이 원본 프로젝트나 다른 유효 링크의 파일을 삭제하지 않게 한다.

### 구현 순서와 완료 기준

## 5. 자동 초안과 직접 수정의 공존

1. 검출 벽을 한 번에 편집 가능한 초안으로 가져온다. 닫힌 경계가 없어도 벽 편집은 시작할 수 있다.
2. 축척이 불확실하면 원본 좌표 기반의 축척 미정 초안으로 편집한다. 실제 mm 치수와 작품 크기 비교는 기준 길이가 정해진 뒤 활성화한다. 픽셀을 mm로 가장하지 않는다.
3. 높이·두께 기본값은 추정값 표시를 유지하며 한 번에 변경할 수 있다.
4. 원본 도면은 잠긴 참조 레이어로 두고 투명도·표시를 조정한다.
5. 사용자 수정·추가·삭제 기록을 자동 분석 결과와 구분한다. 재분석은 별도 후보로 제시하고 기존 편집 내용을 자동 덮어쓰지 않는다.
6. 이 단계의 목표는 편집 가능한 초안과 완성 경로다. 인식률 100%를 요구하지 않되, 잘못된 확신이나 임의의 정확한 치수는 제공하지 않는다.

구현 기록(2026-09-27): 완전한 공간 복원 검증이 실패해도 구조선 후보가 있으면 바닥 경계를 꾸며내지 않는 내부벽 편집 초안을 제공한다. 도면 px 좌표와 축척 미정 상태, 자동 후보 원본 벽 스냅샷을 저장해 사용자 추가·수정·삭제 수를 구분한다. 같은 도면의 재분석은 분석 근거만 갱신하고 편집한 벽·작품·축척은 유지한다. 두 점 또는 벽 후보 길이 보정은 도면과 현재 벽·치수 좌표를 함께 변환한다. 축척 전에는 실제 mm 작품 배치와 3D·벽면도를 비활성화하며, 저장 후 재열기에서도 평면도로 진입한다. 새로운 도면으로 바꾸거나 원본 레이어를 제거해 px 벽을 mm로 오인하는 경로는 축척 전 보류한다.

합성 열린 L자 도면의 구조선 2개 → 편집 초안 → 벽 길이 변경 → 같은 도면 재분석 → 수정 유지 → 새로고침 복구 → 두 점 축척 보정 → 3D 진입을 로컬 브라우저에서 확인했다. 구조선의 실제 벽 여부, 닫힌 경계/바닥, 문·설비 인식 정확도는 이 검증으로 확인되지 않는다.

- src/domain: 불변 이동/회전 계산, 공유 참조 중복 변형 방지, 연결 관계 정책, 단위 파싱과 스냅 계산을 뷰 독립 함수로 구현.
- src/components/PlanView.tsx 및 Gallery3D.tsx: 공통 변형 명령을 호출. 렌더링 메쉬만 바꾸고 모델 좌표는 그대로 두는 구현 금지. 3D 조작기는 기존 의존성 지원 범위를 확인 후 적용.
- src/components/Workspace.tsx, Inspector.tsx, Outliner.tsx, src/App.tsx: 도구 버튼, 속성·다중 선택, 단축키, 목록 선택과 캔버스 선택 동기화.
- src/domain/types.ts 및 저장 검증: 미배치 작품·문/창·설비·그룹·Scene·축척 상태 등 필요한 모델 확장. schemaVersion과 구버전 마이그레이션을 함께 설계하며 기존 프로젝트를 즉시 파괴하지 않음.
- 공유: 전용 공개 스키마·인증/소유권 API·저장소 및 읽기 전용 뷰어 경로를 추가한다. 편집기 잠금 상태에만 의존하지 않는다.
- 캡처/측정: ExportDialog와 캡처 콜백을 뷰 공통 출력 계약으로 확장한다. 측정 앵커·치수선 저장 스키마와 2D/3D 오버레이를 추가하고, 이미지 출력에 주석을 합성한다.
- 가져오기: analyzePlan/초안 생성의 확정 모델과 편집용 부분 후보를 구분. 미완성 후보가 기존 엄격 검증을 우회해 검증 완료 모델로 저장되지 않게 함.
- 검증: 변형 역연산·다중 선택·잠금·관계 보존·한 번의 Undo, UI 입력 충돌, 저장 왕복, 실제 도면 업로드에서 직접 수정까지 확인.

## 8. 첫 출시에서 미루는 범위

임의 면을 밀고 당기는 일반 CAD 모델링, 곡면/솔리드 연산, 벽의 자유 3축 기울이기, SKP 파일 호환, 2D 이미지→3D 재질 및 결제는 후순위다. 사용자가 요청한 이동·회전·삭제·치수 수정·추가·복제는 핵심 범위에 포함한다.

## 9. 측정 기준

- 자동화: 전체 무개입 복원률은 기존대로 별도 측정한다. 부분 초안은 성공으로 합산하지 않는다.
- 편집: 도면 업로드→첫 편집 가능 시점, 기준 과제 완료 시간, 클릭 수, 수정 후 좌표 오차, 저장/취소 시 데이터 손실을 측정한다.
- 첫 브라우저 검증 과제: 잘못된 벽 1개 삭제, 벽 1개 이동/회전, 누락 벽 추가, 길이 입력, 작품 재배치, 거리·높이 측정, 치수선 저장, 치수 포함/제외 캡처, 전체 Undo/Redo, 저장 후 재열기. 기준 도면/브라우저/장비와 결과를 기록한다.
- 사용자 수정 없이 완료하는 자동화 목표와, 사용자에게 수정 자유를 제공하는 편집기 목표를 각각 보고한다.
