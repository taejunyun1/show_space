# 재질 기본·고급 편집

문서 2 §28의 기본 편집과 고급 물성을 분리했다. 벽·바닥은 기본 화면에서 색, 프리셋, 무광/새틴/유광 마감, 투명 표현, 직접 이미지 텍스처와 실제 반복 크기를 조절한다. 작품은 원본 이미지를 유지하고 마감·투명 표현만 조절한다. 기존 거칠기·금속성·불투명도·투과율·재질 두께·굴절률과 추가 코팅/섬유 광택은 기본적으로 접힌 고급 설정에서 편집한다.

마감은 거칠기·코팅 광택만 바꾸며 기존 프리셋, 색, 텍스처와 투과·금속 값을 보존한다. 정확히 일치하지 않는 기존 값은 `프리셋 / 직접 설정`으로 표시하고 열기만으로 정규화하지 않는다. 불투명·반투명·유리 표현은 opacity/transmission의 서로 다른 의미를 구분한다. 유리 선택은 불투명도 100%와 빛 투과를 사용하고, 반투명은 투과율 0%와 opacity를 사용한다. 투명도 0%에서 불투명으로 돌아온다. 세부 값을 조절하면 기본 표시도 즉시 반영된다. 유리의 실제 외관은 색·반사·두께 등에도 의존하므로 숫자 100%를 완전히 보이지 않는 표면이라고 안내하지 않는다.

같은 ANCA 로컬 프로젝트의 자동 벽 1에서 유광(거칠기 12%, 코팅 50%) 적용과 Undo(92%/0%)를 확인했고 2×1m 텍스처가 유지됐다. 고급 펼침/접힘은 변경 이력을 만들지 않았다. 기본 유리 투명도 65%는 실제 고급 투과율 65%/불투명도 100%로 표시됐으며 고급 불투명도 40%로 바꾸면 투과율 0%가 됐다. 모든 재질 변경과 잠금 검사를 Undo했고 편집 가능한 원래 값으로 복원했다. 잠긴 벽의 기본·고급 재질 조절은 모두 disabled였다.
