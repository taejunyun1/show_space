# 3D 작품에 연결된 측정점 — 2026-10-04

원본 1 §14의 작품 측정과 기존 3D 줄자를 연결했다. 정적 GLB 작품에서 찍은 점을 작품의 로컬 좌표/실제 폭·높이·깊이 비율로 저장한다. 이동·XYZ 회전·숫자 크기 변경과 드래그 미리보기를 따라가고, 모델의 클릭한 면 가까운 모서리에 12 CSS px 이내로 스냅한다. Alt는 기존 벽/이미지 줄자와 같은 해제 경로다. 정밀 크기 대신 렌더링 픽셀 거리를 저장하지 않는다.

기존 fixed/wall 치수와 JSON 스키마 1을 유지한다. 새 kind=modelArtwork는 ID·localRatio·fallback을 갖는다. 모델 삭제 시 마지막 계산 위치를 fallback으로 고정하고 연결 끊김을 표시한다. 삭제된 ID를 현재/저장 Scene 치수가 참조하면 새 모델 및 복제의 ID로 재사용하지 않아 다른 모델에 잘못 붙지 않는다. 삭제 시 미완성 측정을 초기화하며 Undo는 원래 연결을 복원한다.

공유는 보이는 모델을 참조한 치수만 고정된 공개 월드 좌표로 변환한다. 내부 연결 비율은 공개하지 않고 기존 공유 API 스키마를 유지한다. 벽 걸이 이미지는 기존 벽 기준 측정점을 계속 사용한다. 이 단계에서 도면 인식이나 임의 메시 자동 복원은 확장하지 않는다.

## 검증

- 전체 테스트 799개 통과·선택 벤치마크 2개 제외. TypeScript/Vite 빌드 통과.
- 새 기하/저장 6개와 상태 1개: XYZ/크기 추적, 마지막 위치/삭제, 새 모델 및 복제 ID 보존, Scene/JSON/Undo, 잘못된 비율 거부, 숨긴 모델 공유 제외.
- 별도 127.0.0.1:5184에서 실제 파일 선택으로 합성 다중 파트 GLB를 입력했다. 위/아래 모서리 클릭은 직선 2100mm, 수평 0/높이 2100mm다. 치수 저장 후 H=3000, X=700/Y=300, Z회전=30° 편집은 직선 3000mm·수평 1500mm·높이차 2598mm를 표시한다. 실제 삭제/Undo/재접속에서 마지막 위치 및 연결 복원을 확인했다.
- 다운로드 JSON 5886바이트의 두 modelArtwork 앵커·localRatio·숫자 크기와 변환을 확인했다. 회전 30°는 부동소수점 29.999999999999996으로 저장되며 근사 비교한다.
- 실제 PNG 1920×1080, 3000mm 치수선은 기울어진 조각을 따라가며 선택 표시/핸들은 제외된다. 390px에서 문서/스크롤 폭 390, 측정 패널 190px. 콘솔 경고/오류 없음.
- Alt 물리 드래그·모바일 실기기·사용자 대형 모델은 이번에 검증하지 않았다. 실제 Supabase 공개 설정값이 없는 로그인/두 실계정·기기 왕복, 원본 요구의 최종 종합 검증은 남아 있다. 전체 최종 구현 목표는 진행 중이다.
