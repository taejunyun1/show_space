# Scene 자동 미리보기 — 구현 / 화면 검증 대기

문서 2 §46의 Scene Thumbnail 자동 생성을 연결했다. 새 Scene 저장은 누르는 순간의 배치와 시점을 복사해 320×200 JPEG 미리보기를 함께 기록한다. 평면도·벽면도는 그 순간의 SVG를 먼저 복사해 축소하고, 3D는 독립 렌더러로 같은 시점과 벽 자동 숨김을 사용한다. 기존 Scene은 미리보기 없음 아이콘으로 계속 열 수 있다.

생성 중 편집한 현재 배치는 유지하며 캡처 당시의 구조·작품·재질·조명·야외 환경을 새 Scene에 저장한다. 프로젝트 전환·취소·화면 해제는 작업을 취소한다. 이미지 생성 실패 시 배치 자체는 저장하고 미리보기 실패를 알린다. 저장은 미리보기까지 한 Undo 단계다. 시간대 비교에서는 이미 만든 PNG를 축소해 네 Scene에 넣으며 다시 3D 렌더하지 않는다. 두 작업의 임시 GPU 렌더는 같은 직렬 큐를 사용한다.

미리보기는 긴 변 320px, 이미지 한 장 64KiB 이하의 내장 PNG/JPEG로 검증한다. 헤더의 실제 치수와 메타데이터를 비교한 뒤 프로젝트를 로드한다. JSON, ZIP 및 기존 private cloud package 자산 목록에 포함하며 ZIP의 해시·누락 검사와 복원을 따른다. 썸네일은 도면 이미지가 포함될 수 있으므로 공개 공유의 허용 필드에 추가하지 않았다. 공개 공유는 기존 정제된 배치/자산만 사용한다.

## 검증

- 전체 테스트 889개 통과, 선택 벤치마크 2개 제외. 166 test files 통과 / 2개 제외.
- TypeScript 및 Vite 빌드 통과. 기존 큰 chunk 경고는 유지된다.
- 테스트는 캡처와 동시에 이루어진 현재 편집 보존, ID 충돌 방지, 다른 프로젝트 저장 거절, 한 번의 Undo/Redo, PNG/JPEG 헤더 제한, 예전 Scene 호환, JSON/ZIP 자산 왕복, 공개 미리보기 제외, 시간대 네 이미지의 저장 및 불완전 배치 거절, 취소 시 콜백 차단 및 임시 GPU 작업 직렬화를 확인한다.
- 실제 WebGL 썸네일 생성·목록 이미지·재접속·모바일·실제 ZIP 다운로드/재입력은 **아직 확인하지 못했다**. 테스트의 1px PNG와 주입 렌더러는 실제 브라우저 이미지 생성 증거가 아니다.
- localhost:8806의 기존 ANCA 프로젝트는 원래 Scene 4개가 보였으나 Scene 메뉴 열기, 평면도 전환, 상단 가져오기 클릭 모두 화면 변화가 없었다. 새 127.0.0.1:8806 기본 프로젝트와 8810 Vite 화면도 Scene 메뉴 반응을 관찰하지 못했다. 키보드 초점은 관찰됐고 브라우저 콘솔 오류/경고는 없었다. 특정 제품 코드 결함이라고 판정하지 않는다. 사용자 프로젝트를 주입하거나 앱 상태/스토리지/이벤트 핸들러를 강제로 실행하지 않았다.
- 로컬 Worker session 17285는 도구로 live 확인했으며 재시작하지 않았다. 별도 Vite 확인 서버는 이번 검증 후 종료한다. 기존 ANCA Scene을 생성하거나 삭제하지 못했다.

## 전달 상태와 남은 작업

화면 인수가 확인되지 않아 이 변경은 배포하지 않는다. 현재 공개 웹은 이전 발표 모드 배포 e76f28e9-6ca3-4571-b9c4-33825adfcc79이다. 다음 작업은 실제 UI 입력 확인 후 새 Scene 이미지 생성→복원→Undo→재접속 및 네 시간대 썸네일, ZIP 왕복을 확인하는 것이다. 그 뒤 배포 및 공개 검증한다.
