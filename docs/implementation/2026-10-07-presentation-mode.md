# 2026-10-07 발표 모드

요구 문서 2 §47의 별도 발표 화면을 상단 `발표`에 연결했다. 편집 패널을 숨기고 현재 배치와 저장한 Scene을 차례로 보여주며, 전체 화면 진입·종료, 드래그 Orbit/확대/이동·시점 초기화, 작품 선택과 공개용 작품 정보를 제공한다. 사용자의 시점 기능 축소 결정에 따라 Walk와 자유 카메라 배치 기능은 추가하지 않았다.

발표를 연 시점의 프로젝트·카메라를 복제한다. Scene 선택은 `sceneProject`의 독립 투영이며 편집기 Scene 복원, 프로젝트 쓰기, Undo 변경 또는 공유 발행을 하지 않는다. 프로젝트 수신 완료 전에 예제 배치가 잡히지 않도록 발표 진입을 비활성화한다. 발표 안의 키 입력은 편집기 단축키로 전파되지 않는다. 전체 화면은 dialog 자체가 아닌 내부 화면 요소에서 요청한다. 지원하지 않는 브라우저에는 안내를 표시하고 같은 발표 화면을 유지한다.

공유 3D 렌더러에 로컬 이미지·반복 텍스처·정적 GLB 자산 컨텍스트를 추가했다. 로컬 자산이 없으면 공개 API로 대체 요청하지 않는다. 로컬 GLB는 제한된 내장 파일 검사 후 직접 디코딩하며 원본 크기/기준점 검사를 유지한다. 로컬/공개 모델 캐시는 구분하고 해제 시 모델 리소스를 폐기한다. 공개 모델의 응답 바이트 제한·SHA-256 검사와 서버 공개 allowlist는 유지했다.

`createReadonlyLayout`은 이미 검증된 프로젝트의 표시 데이터만 구성하며, 공개 발행의 `createPublicShare`는 기존의 `parsePublicShare`를 항상 거친다. 따라서 로컬 발표에는 공개 링크의 Scene 20개/스냅샷 1MB 예산을 적용하지 않는다. 저장 Scene 30개와 500개 작품의 유효한 2,000자 설명을 데이터 단계에서 확인했다. 이는 대형 장면 GPU 성능 검증이 아니다. 설치 NOTE·체크리스트·원본 도면은 발표 화면의 정보 패널에 넣지 않는다. 원본 GLB는 로컬 자산으로만 남으며 공개 파일로 발행하지 않는다.
