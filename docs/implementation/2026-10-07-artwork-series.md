# 시리즈 자동 배열

사용자의 2026-10-07 결정에 따라 운영 인증 설정과 브라우저 검증 연결 대기를 별도로 보류하고 후속 구현을 계속한다. 제품 계획 1.1 및 원문 문서 2 §24의 작품 선택 → 작품 수 → 간격 → 자동 배열을 구현했다.

## 사용 흐름

왼쪽 ARTWORK 목록의 **시리즈 자동 배열**을 연다. 기존 선택이 있으면 그 작품을 초기 목록으로 사용하고, 없으면 표시 중인 잠기지 않은 작품을 최대 7점 제안한다. 이미 설치한 작품과 미배치 작품을 함께 선택하고 화살표로 순서를 바꿀 수 있다.

앞 N점을 배열할 수량으로 지정하고 설치 벽·A/B면·가로/세로·간격·배열 중심 높이를 입력한다. 가로 배열은 같은 작품 중심 높이, 세로 배열은 전체 배열의 중심 높이로 계산한다. 벽의 가로 중앙에 배치하며, B면도 보는 방향의 왼쪽부터 선택 순서를 따른다. 작품은 현재 전시의 기존 벽면형 작품이며, 추가 수량을 위해 원본을 임의 복제하지 않는다. 독립 3D 조각·참고 모델 표면 자동 배치는 이 도구의 범위가 아니다.

미리보기는 회전·액자·매트를 포함한 실제 외곽이다. 변경하지 않는 기존 작품은 회색으로 보여주고, 같은 벽·면의 기존 작품과 외곽이 겹치면 경고한다. 외곽 중첩은 참고 경고이며 임의 메시의 정밀 충돌 계산은 아니다. 잠김·숨김·축척 미정·누락/중복 작품·잘못된 수량·부분 그룹·벽 밖 배열은 적용 전에 차단한다. 기존 그룹 전체를 포함하면 다른 벽·면에도 함께 배치할 수 있다.

적용하면 미배치 작품을 설치하고 기존 선택 작품의 위치를 변경한다. 기본 옵션은 배치한 작품을 함께 움직이는 기존 작품 그룹으로 묶는다. 기존의 완전한 단일 그룹이면 그룹 ID를 유지한다. 전체 배열은 단일 Undo 작업이며 같은 배치를 반복 적용하면 이력을 추가하지 않는다. 적용 후 배열한 작품을 선택하고 벽면도로 이동한다.

작품 ID·이미지·실제 크기·회전·액자·표면·메모·영상 데이터 등은 기존 작품 레코드에서 보존한다. 별도 영속 Series 엔티티를 추가하지 않고 기존 Artwork·groupId·Scene 스키마를 사용한다. 시리즈별 별도 라이브러리/상품 컬렉션 UI를 구현한 것으로 확대하지 않는다.

## 검증과 남은 확인

- 자체 7점 중 3점은 미배치였다. 400×600mm, 250mm 간격을 12m 벽에 배열해 전체 외곽 4,300×600mm, 첫/마지막 중심 4,050/7,950mm를 확인했다.
- 선택 순서와 앞 N점만 적용, B면 시각 순서, 미선택 작품 보존, 액자·매트·90° 회전 및 세로 배열 외곽·간격을 검증했다.
- 잘못된 수량/숫자/벽/면/방향, 누락/중복, 잠김/숨김, 부분 그룹, 축척 미정, 벽 초과의 원자적 거절을 검증했다.
- 상태 명령의 단일 Undo/Redo·반복 무변경·프로젝트 전환 차단·실패 시 redo와 선택 보존을 확인했다.
- Scene 저장/복원, JSON, 실제 ZIP 생성/파싱, 현재 및 선택 Scene의 공개 스냅샷에서 배치와 원본 자산 데이터를 대조했다. ZIP 검사에서 이미지 디코딩은 명시적 테스트 대역이며 실브라우저 복원은 아니다.
- 정적 React 렌더로 선택/수량/벽/면/간격/그룹/미리보기 제어와 cm 표시, 부분 그룹 오류·적용 비활성화를 확인했다. 실제 클릭·포커스·390px 렌더 검증을 완료했다고 주장하지 않는다.
- 새 회귀 11개 포함 전체 **1,021개 통과 / 선택 통합 검사 7개 제외**, TypeScript·Vite 빌드 통과.

브라우저 연결 검증은 사용자 결정대로 보류했다. 이 변경은 아직 운영 배포하지 않았다. 실제 인증/기기/사용자 성공 지표 및 전체 인수는 미완료로 유지한다. 후속 프로젝트 Archive·협업 Comment 및 IES/Lux·AI 확장은 기존 계획에 남아 있다.
