# 작품 배치 경고 · 2026-10-07

원문 문서 2 §68/69의 바닥 아래/벽 침범/작품 Bounding Box 겹침 안내를 기존 자유 편집에 보완했다. 기존 이미지 작품은 벽 경계·높이·계단 추정 경고만 있었고, 3D 작품은 위치 숫자와 바닥에 놓기만 있었다.

## 구현

- 실제 mm 치수와 XYZ 회전, 벽 방향/두께, 액자·매트·면내 회전을 반영한 회전 외곽 상자(OBB)로 비교한다. 월드 축 사각 상자만으로 비스듬한 벽 사이 빈 공간을 채우지 않는다.
- 3D 작품: 기준 Y=0 바닥 아래, 유한한 벽 몸체와의 겹침, 다른 3D/이미지/영상 작품과의 겹침, 원본 치수 대비 극단적 변형 안내.
- 이미지/영상 작품: 기존 Inspector에 다른 벽/3D/이미지/영상 작품의 외곽 겹침을 추가한다. 서로 다른 타입 사이도 양쪽에서 확인할 수 있다.
- 1mm의 접촉 허용 범위를 두어 바닥/벽에 닿은 상태를 침범으로 표시하지 않는다. 벽의 시작/끝·높이를 사용하므로 떨어진 벽 사이 출입구를 장애물로 만들지 않는다. 숨김 객체와 삭제 객체는 제외한다.
- 같은 그룹의 겹침은 숨기지 않으며 작업자가 의도한 겹침이면 그대로 유지할 수 있다. 세 이름까지 표시하고 나머지는 개수로 모은다.
- Scale 경고는 원본 축별 치수의 0.01배 미만/100배 초과 또는 축별 배율 차이 100배 초과를 안내하는 기준이다. 새 입력 금지나 자동 단위 변경을 추가하지 않는다.
- 드래그 미리보기에서 계산해 오른쪽 경고와 3D 선택 외곽의 주황색/경고 개수로 표시한다. 3D Inspector 최하단 수치도 같은 미리보기에서 읽는다. 실제 위치/크기/잠금/그룹/Note/Scene을 변경하거나 이동을 막지 않는다.
- 캡처 중에는 선택 경고·외곽을 표시하지 않는다. 경고는 프로젝트에 저장하거나 공개 공유에 추가하지 않는다. 선택하지 않은 모델/캡처 화면에서는 추가 경고 index 계산을 생략한다.

## 범위

외곽 상자의 겹침 안내이며 메시도/물리엔진/정확한 충돌 검출은 아니다. 조각이나 설치물 안의 빈 공간을 판별하지 않으므로 의도한 조합에서 경고가 있을 수 있다. 기준 바닥은 Y=0이며 참고 전시장 GLB의 여러 층/계단 높이를 추정하지 않는다. 전시장 참고 모델의 거대한 외곽 상자를 채운 장애물로 취급하지 않는다. 축척 미정 px 도면에서는 물리 경고를 만들지 않는다. 문·설비·설치 제외 영역 직접 편집과 정밀 도면 복원을 확대하지 않는다.

이미지/표면 텍스처 로딩 실패의 기존 화면 안내와 모델 형상 로딩 오류는 유지한다. 이번 구현을 GLB 내부의 모든 텍스처 decode 실패·사용자 임의 모델·전체 §68 인수 완료로 확대하지 않는다.

## 검증

새 일반 회귀 **9개** 통과:

- 기울인 작품의 바닥 아래 모서리와 정상 접촉, 숨김 제외.
- 실제 벽 높이/시작/끝/두께, 출입구 빈 공간, 벽 접촉, 숨긴 벽.
- AABB는 겹치지만 실제 회전 상자는 떨어진 평행 작품 및 대각선 벽 비교.
- XYZ 회전 모델과 회전 이미지 작품의 상호 겹침, 자기 자신/숨김/분리 제외.
- 큰 Scale 변형·그룹·다섯 대상 집계.
- 원본 layout/잠금/Note/Scene 불변 및 저장 데이터 parse, px 도면 제외.
- 실제 Inspector 정적 렌더의 3D 미리보기 경고/최하단 수치와 이미지 작품 겹침 안내. SSR용 상태 selector를 명시적으로 현재 fixture에 연결했으며 실제 브라우저 입력 검증이 아니다.

최종 전체 **1,107 통과 / 선택 실행 10 제외**, TypeScript/Vite 빌드와 `git diff --check` 통과. 실제 새 경고의 브라우저 드래그/색/모바일 인수·운영 배포, 임의 사용자 복잡 모델·전체 전시 흐름 인수는 여전히 남는다. 인증과 브라우저 연결 대기는 사용자 결정대로 별도 보류한다.
