# 3D 작품 스냅 — 2026-10-04

바닥에 놓는 GLB 작품의 평면도 드래그와 3D 축 핸들 이동에 벽면·바닥·다른 보이는 3D 작품 외곽/중심 스냅을 연결했다. 회전한 작품은 실제 크기의 여덟 모서리로 계산한다. 벽은 길이와 높이 범위 안에서 두께 양쪽 면을 사용한다. 그룹에는 같은 이동 보정을 적용하며 잠긴 구성원은 거부한다.

평면도는 X/Z만 이동하고 높이를 유지한다. 3D는 Drei가 제공하는 핸들의 실제 월드 방향을 따라 보정해 회전한 로컬 축 밖으로 튀지 않는다. 후보가 없으면 10mm 격자, Alt 또는 자석 버튼 해제 시 원래 소수점 좌표다. 숫자 위치·회전 입력에는 스냅을 적용하지 않는다. 회전 도구도 기존 회전을 유지한다. 임시 초록 안내는 드래그 동안만 표시하며 프로젝트 자산/공유에 저장되지 않는다. SVG 캡처의 기존 data-capture-draft 제거와 3D captureClean 숨김을 사용한다.

## 검증

- 전체 792개 테스트 통과, 선택 벤치마크 2개 제외. TypeScript/Vite 빌드 통과.
- 새 도메인 7개: 모서리/중심, 회전 외곽, 기울어진 그룹 최하단, 사선 핸들 방향, 사선 유한 벽, 숨김/잠금/해제, 입력 오류/원본 보존. 화면 축척 2개와 상태/Undo 2개 추가.
- 별도 127.0.0.1:5183의 합성 다중 파트 GLB 두 개를 파일 선택으로 입력했다. 실제 평면도 드래그에서 X=1600/Z=1000으로 모서리 접촉, 해제 시 X=1548.51/Z=1095.39 표시와 Undo 복원을 확인했다.
- 정면 3D X 핸들 드래그 X=1600/Y=0/Z=1000, 45° 모델의 실제 Z 핸들 드래그 X=1312.13/Y=0/Z=1312.13 표시로 해당 사선 방향 보존을 확인했다. W/H/D=400/500/200과 회전 45° 유지, 콘솔 경고·오류 없음.
- 390px 화면 문서/스크롤 폭 모두 390, 평면도 모델 선택 시 자석 버튼 활성, 완료 후 임시 안내 0개.
- Alt를 누른 채 물리적 드래그와 모바일 터치/실기기는 이번 UI 검증에 포함하지 않았다. bypass 계산과 자석 해제는 각각 테스트/실제 UI로 확인했다.

## 범위와 남은 작업

이것은 모델의 경계 상자와 유한 벽을 기준으로 한 배치 추론이며 충돌 방지나 삼각형 표면에 붙이는 기능은 아니다. 벽 걸이 이미지의 스냅은 기존 벽면 기능을 사용하고, 공간 참조 모델의 임의 메시는 후보로 쓰지 않는다. 도면 인식을 확장하지 않는다. 실제 계정 인증·두 계정/기기, 사용자 SketchUp 대형 모델·모바일 실기기, 원본 요구 전체의 최종 검증은 여전히 남아 있으며 최종 구현 목표는 진행 중이다.
