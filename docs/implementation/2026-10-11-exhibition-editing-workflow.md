# 전시의 벽 경계 일괄 지정·끝점 스냅·Hand·바닥 표시

2026-10-11. 이전 [같은 전시의 텍스처·메모·야외 시간·GLB](2026-10-11-exhibition-extended-workflow.md)에서 이어지는 편집 동작을 구현·검증했다. 도면 전체의 정확한 자동 재구성, 문·설비·제외 영역의 독립 직접 편집, 유료 사진→재질 생성은 추가하지 않는다.

## 제품 변경

평면도는 기존에 가져온 모델의 바닥만 표시했다. 이제 3D와 GLB가 사용하는 `floorWithOpenings`를 평면도에도 사용해 닫힌 바닥 경계를 표시한다. 중정은 비우고, 가벽은 경계 계산에서 제외한다. 기존 문 개구부가 연결한 경계와 가져온 모델 바닥의 우선순위를 유지한다. 숨긴 경계 벽으로 바닥을 없애지 않는다. 연결되지 않았거나 교차하는 경계에 임의 사각형 바닥을 채우지 않는다.

Shift로 벽 여러 개를 선택하면 Inspector에서 **바닥 경계로 지정 / 가벽으로 지정**을 한 번에 적용한다. 선택 밖의 벽과 다른 속성은 그대로 보존하며 한 번의 실행 취소로 되돌린다. 잠긴 벽이 포함되면 전체 변경을 거절한다. 혼합 선택은 벽 전용 명령에서 거절하며 같은 용도로 반복 지정하면 저장 이력을 추가하지 않는다. 단일 벽의 기존 용도 선택도 유지한다.

## 실제 연결한 동작과 근거

실제 App/Header/PlanView/Outliner/Inspector/Workspace와 기본 저장 동작을 하나의 전시 ID로 유지했다. 실제 2페이지 PDF에서 선택한 도면·축척 보정 뒤, 네 가벽 초안을 한 번에 바닥 경계로 지정했다. 각 모서리는 실제 SVG pointer 이벤트로 선택·드래그해 이웃 끝점에 스냅했다. 바닥 생성 후 undo로 열린 경계와 바닥 없음, redo로 닫힌 경계와 표시를 확인했다. 도면 확대→Hand 드래그→전체 맞춤에서는 프로젝트 객체와 undo 개수가 바뀌지 않았다.

이 같은 프로젝트에 작품 PNG 10점·치수/시리즈 배열, 직접 벽 텍스처, 비공개 메모·참고 사진, Spot/Kelvin·야외 시간, Scene A/B·복원, 벽면 캡처, 별도 저장소 재읽기, 12페이지 한글 PDF, ZIP 완전 복원과 공개 payload 준비를 계속 연결했다. 최종 GLB를 GLTFLoader로 실제 다시 읽어 바닥 약 7.842857×6.006855m와 두께 0.16m를 확인했다. 벽·작품 이미지 11장의 내장 픽셀과 텍스처 반복/치수 검증도 유지했다. 이번 GLB에 대한 새 Blender 수신/렌더는 실행하지 않았다.

별도 PlanView/Inspector 테스트 9개는 닫힌 경계, 중정·가벽·숨김, 열린/교차 경계, 기존 문 개구부 연결, 연결된 벽 이동 미리보기·취소·확정·undo/redo, 모델 바닥 우선순위, 일괄 지정·잠금·혼합 선택·무변경 이력을 확인한다. 실제 SVG 경로를 native Canvas에서 evenodd로 채워 바닥 내부 색·외부/중정 투명 픽셀을 확인했다. 이 경로 검사는 브라우저 화면 전체의 픽셀 인수가 아니다.

동일 최종 테스트 10개를 이전 제품 코드에 적용하면 8 실패/2 통과, 변경 후 모두 통과했다. 이 중 평면도 바닥 표시 누락을 다루는 4개는 기존 동작 수정이며, 3개는 새 일괄 지정 요구의 검증이다. 나머지 1개는 같은 전시의 연속 흐름이다. 전체 1,323 통과/선택 10 제외, 230 파일 통과/10 파일 제외, TypeScript·production build·diff 검사 통과. 기존 큰 청크 안내는 유지한다.
