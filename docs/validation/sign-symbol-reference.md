# 호스 릴 표지 기호 대조 기준

`src/domain/fireHoseTemplate.ts`는 Paragon 공개 도면에 포함된 호스 릴 캐비닛 표지의 위쪽 정사각형 기호를32×32 밝은 픽셀 특징으로 축약한 기준이다. 원본 하단 문자는 육안으로 FIRE HOSE REEL CABINET으로 읽히며 OCR은 안정적으로 판독하지 못했다. 이 특징을 OCR 문자열이나 확률 점수로 제시하지 않는다.

출처는 `plan-corpus.json`의 `paragon-fire.pdf`,1페이지다. 원본 문서의 SHA-256은 같은 manifest로 고정한다. 제공처: https://www.paragonhall.com/en/download-center/operation-file . 원본 비트맵은 저장소에 복사하지 않았다.

현재 인식 범위는 세로형 호스 릴 캐비닛 표지의 한 기호 계열이다. 작은 컬러 PDF 이미지 중 페이지에서 실제로 보이는 것으로 검증된 이미지에만 적용한다. 가로세로 비율, 붉은 바탕, 캐비닛과 호스 기호 내부의 밝은 픽셀 겹침을 확인한다. 다른 형태의 소화전·소화기·회전된 표지·일반 이미지 도면 전체에는 일반화되지 않았다. 표지 위치를 설비 점유 범위나 법정 접근 여유 공간으로 사용하지 않는다.

`paragon-hose-signs.json`은 렌더링된1696×2400페이지에서 육안으로 확인한 큰 붉은 호스 릴 표지12개의 상자다. 검출 중심이 상자 안에 있는지를 재현율의 근거로 사용한다. 기준 기호와 검사 도면의 출처가 같으므로 이 결과는 알려진 기호의 전체 처리 경로 검증이며 독립적인 일반화 정확도가 아니다. 다른 출처의 양성·음성 표지를 추가해야 한다.
