# 공개 도면 검증 — 2026-09-11

## 입력과 재현

- [ANCA Gallery](https://www.anca.net.au/s/ANCA_floor-plan.pdf): 1페이지, PDF 문자 레이어.
- [Espacio Gallery](https://www.espaciogallery.com/uploads/5/9/7/6/5976484/1_espacio_gallery_floor_plans_1-2.pdf): 2페이지, 스캔/로컬 OCR.

원본 PDF와 렌더 이미지는 저장소에 재배포하지 않는다. PDF를 로컬 폴더에 저장한 후 `PLAN_CORPUS_DIR=/absolute/corpus npx vitest run scripts/benchmark-plans.test.ts`로 실행한다. 외부 인식 API는 사용하지 않는다. PDF.js와 로컬 eng+kor Tesseract 모델, 제품의 숫자 파서·선 검출·공간 생성 함수를 사용한다. 브라우저 Worker/Canvas 대신 Node Canvas를 사용하므로 런타임 차이가 있다. 보고서 시간은 로컬 실행값이며 사용자 기기 성능 예측이 아니다.

## 결과

| 입력 | 숫자 표기 후보 | 125 / 155 / 190 밝기 기준 공간 생성 |
|---|---:|---|
| ANCA 1 | 22 | 모두 보류 |
| Espacio 1 | 13 | 모두 보류 |
| Espacio 2 | 16 | 모두 보류 |

완전 공간 초안 생성은 **0/3 페이지**. 숫자 후보 수는 정답률이나 재현율이 아니다. 도면별 정답 좌표 주석은 아직 없다. 단순 합성 도면의 테스트 통과를 실제 도면 정확도로 보고하지 않는다.

Espacio 1 렌더를 직접 확인했다. 도면 상단에 전체 단위 cm가 한 번 선언되어 있고, 세로 치수, 계단, 문, 창문, 소켓 범례가 있다. 현재 파이프라인은 단위 없는 숫자에 페이지 단위를 상속하지 않으며 문·창문의 빈 구간을 닫힌 경계로 구성하지 못한다. 모든 실행이 선 후보 100개 상한에 도달했다. 선 개수/밝기 변경만으로 의미상 벽을 확정할 수 없다.

## 반영한 자체 검증

제품에서 기본 분석 후 125/190 두 조건으로 자동 재분석한다. 최소 2개 성공 결과의 벽 개수·용도·좌표·축척이 일치해야 초안을 제공하고, 성공 결과 중 하나라도 충돌하면 보류한다. 실패한 조건도 3회 기록에 포함한다. 원본/문자/선 근거를 보존하며 사용자에게 밝기나 개별 요소 점검을 요구하지 않는다. PDF 문자 레이어가 있어도 인식 표기가 비어 있으면 로컬 OCR을 실행한다.

이 검증은 구조의 반복 검출 안정성만 검사한다. 같은 가구를 반복해서 벽으로 오인하는 경우를 판별하는 의미 검증은 아니다. 출입구/설비/설치 불가 구역과 완전 자동화 M0는 미완료다.
