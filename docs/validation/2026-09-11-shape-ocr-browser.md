# 국소 OCR 브라우저 검증


## 국소 OCR 브라우저 검증과 보류 안내 수정

로컬 http://127.0.0.1:5180/ 에서 실제 Espacio 2페이지 렌더 PNG(2400×1696)를 도면 불러오기로 입력했다. 자동 분석 후 숫자 표기30개, 구조 선 후보500개가 표시됐고 공간 자동 적용은 보류됐다. 참고 도면 배치 후 표기 목록에서33번째 가구 Bar와 OCR 점수96/100을 확인했다. 콘솔 오류·경고는 없었다. 이는 이미지 입력의 브라우저 검증이며 PDF 다중 페이지 선택·전체 자동 공간 생성 성공을 뜻하지 않는다.

보류된 도면 저장 후 ‘두 점 축척 보정 후 벽을 맞춰 주세요’라고 요구하던 알림을 ‘도면과 인식 결과를 저장했습니다. 공간 자동 생성은 아직 보류 상태입니다.’로 바꿨다. 가져오기 대화상자도 직접 보정 유도 대신 인식 결과 저장을 안내한다. 자동 생성 성공으로 표현하거나 백그라운드 재처리를 약속하지 않는다. 수정 후 동일 브라우저에서 다시 가져오기·저장해 새 안내를 확인했다.

두 적용 모두 실행 취소로 이전 테스트 프로젝트(벽5개·작품1개·기존 계단 표기1개)를 복원했다. 변경 후 빌드 통과. 문구 변경이므로 추가 단위 테스트는 만들지 않았으며 직전304개 테스트를 이번에 재실행했다고 주장하지 않는다. 웹 배포 없이 커밋·푸시한다. 전체 평면도 자동 생성0/3 상태와 목표는 유지된다.
