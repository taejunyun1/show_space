# 공간 전시 편집기

소스 저장소: [taejunyun1/show_space](https://github.com/taejunyun1/show_space) · 기본 브랜치: `main`

[검증용 웹사이트 열기](https://gonggan-exhibition-preview.taejunyun.workers.dev) · [배포 기록](docs/deployment/cloudflare.md)

현재 우선 구현은 **도면의 대략적인 벽·치수 초안에서 공간을 직접 수정하고 작품을 배치하는 흐름**입니다. 문·주요 설비의 위치 후보까지만 자동 표시 대상으로 두고, 계단·설치 제외 면적의 정밀 생성과 독립 직접 편집은 보류합니다. 페이지·OCR·벽·치수를 항목별로 확인해야 편집이 시작되는 흐름은 피합니다.

[자동 초안 마일스톤 M0](docs/milestones/M0-automatic-plan-to-venue.md) · 상태: 미완료. [직접 편집 단계 계획](docs/implementation/2026-09-27-direct-space-editing-plan.md)의 E2 핵심 도구, E3 부분 도면 편집 진입, S1 보기 전용 공유, E4 작품 조작을 1차 구현했습니다. 3D 벽 이동은 연결된 끝점을 유지하고 끝점·100mm 격자로 맞춥니다. 전체 도면 자동 복원을 출시 조건으로 삼지 않습니다.

## 실행

Node.js 22.12 이상 또는 24를 권장합니다. 이 작업에서는 Node.js 24.14.0으로 검증했습니다.

```sh
npm ci
npm run dev
```

브라우저에서 http://127.0.0.1:5173 을 엽니다.

```sh
npm test
npm run build
npm run preview
```

## 지금 가능한 작업

- 8,000 × 6,000mm 예제 전시장을 3D, 평면도, 벽면도로 확인
- 벽 추가·복제·삭제, 연결된 끝점 이동, 길이·높이·두께 입력
- 평면도 두 점 벽 그리기(W), 끝점·축·격자 스냅, 벽 전체 이동(M)·회전(Q), Shift 다중 벽 선택과 일괄 복제·잠금
- 작품 이미지 업로드, 실제 W/H/D, 설치 벽·중심 높이·벽 기준 거리 입력
- 벽면도 작품 드래그, Shift 다중 선택, 가장자리 기준 간격 정렬
- 손 도구(H)로 3D·평면도·벽면도 시점 이동, 3D 회전·휠 확대
- 작품과 벽 표시·잠금, 프레임 색상, 메모
- Undo/Redo, Scene 저장·복원, IndexedDB 자동 저장
- 프로젝트 JSON 불러오기·내보내기, 3D·평면도·벽면도 1920/3840px PNG 캡처
- 고정된 현재 배치를 읽기 전용 링크로 공유, 3D·평면·벽면 열람, 링크 중단
- PDF/이미지 도면 자동 분석, 검증된 공간 초안 또는 축척 미정 벽 후보 편집 초안 적용, 원본 오버레이와 같은 도면 재분석 시 사용자 수정 보존

기본 프로젝트의 치수는 mm로 저장하고 3D 렌더링에서 meter로 변환합니다. 축척 미정 벽 초안의 평면 좌표·길이는 px로 유지하다가 보정 시 mm 좌표로 변환합니다. H 또는 손 버튼을 누른 뒤 드래그하면 세 화면의 시점이 이동하며 벽·작품은 움직이지 않습니다. V로 선택 도구에 돌아옵니다. 빈 3D 공간을 드래그하면 카메라가 회전하고 벽을 드래그하면 벽이 이동합니다. 작품은 3D·벽면도에서 배치하거나 숫자로 위치를 입력할 수 있습니다. 숫자는 Enter 또는 포커스를 옮길 때, 메모는 포커스를 옮길 때 적용됩니다. 적용 후 상단의 로컬 저장 완료 표시를 확인하세요. 단축키: Cmd/Ctrl+Z 되돌리기, Shift+Z 다시 실행, Cmd/Ctrl+D 선택 복제, Delete 삭제, Cmd/Ctrl+S 내보내기.

평면도에서 W를 누르고 시작점·끝점을 클릭하면 벽을 그립니다. 연속해서 다음 점을 선택하거나 Esc로 종료합니다. 벽을 Shift+클릭해 여러 개 선택한 후 함께 끌거나 Q로 회전합니다. 오른쪽 **연결된 벽 함께 수정**이 켜져 있으면 벽 전체 이동·회전에도 맞닿은 끝점을 유지합니다. 끄면 해당 벽만 움직입니다. 3D 벽 이동은 가까운 다른 벽 끝점 또는 100mm 격자에 맞춥니다. 예제 공간의 바닥이 사라진 경우 **기본 공간 배치 복원**으로 네 외곽 벽을 원래 위치로 되돌릴 수 있으며 작품 편집과 실행 취소 이력은 유지됩니다. 3D에서 작품을 드래그하면 가로 위치와 설치 높이가 10mm 단위로 바뀌고, 다른 벽 위에 놓으면 설치 벽도 바뀝니다. 선택 작품의 파란 점을 3D·벽면도에서 드래그하면 15° 간격으로 회전합니다. 오른쪽에서 각도를 직접 입력하거나 90° 버튼으로 돌릴 수도 있습니다. 벽을 삭제하면 그 벽의 작품은 왼쪽 **미배치 작품**에 보관됩니다. 배치할 벽을 고른 뒤 **배치**를 누르면 복원됩니다. 잠긴 작품이 붙은 벽은 잠금을 풀어야 삭제할 수 있습니다. T 또는 줄자 버튼으로 두 점을 클릭해 mm 거리를 재고 치수선을 남깁니다. 카메라 버튼으로 현재 3D·평면도·벽면도를 1920/3840px PNG로 저장합니다. 치수·격자·원본 도면 표시를 선택할 수 있습니다.

## 현재 범위와 한계

- 편집 프로젝트는 브라우저의 단일 로컬 초안에만 보존되며 다른 기기로 자동 동기화되지 않습니다. 공유 버튼은 현재 공개 배치와 작품 이미지만 Cloudflare R2에 업로드합니다. 작성자 키를 가진 사람만 링크를 만들거나 중단할 수 있으며, 링크를 가진 사람은 로그인 없이 열람할 수 있습니다. 장기 편집 보관에는 JSON 백업을 사용하세요.
- 공유 링크는 생성 시점의 스냅샷입니다. 원본 도면·내부 메모·다른 Scene은 보내지 않으며, 기존 링크는 이후 편집에 따라 갱신되지 않습니다. 치수 공개 링크에서는 3D·평면·벽면의 **임시 줄자**를 사용할 수 있고 측정값은 저장되지 않습니다. 비밀번호·대상자 제한·작성자별 계정 관리는 아직 없습니다.
- 새 파일을 불러오기 전 현재 작업을 JSON으로 다운로드합니다. 업로드 이미지는 축소된 WebP로 JSON에 포함됩니다. 예제 이미지 경로는 앱에 포함된 자산을 참조합니다.
- 도면 입력은 PDF 페이지 선택과 PNG/JPG/WebP 이미지를 지원합니다. 두 점 축척 보정과 일부 자동 인식·공간 초안 생성이 가능하지만, 복잡한 실도면을 무개입으로 완성하는 정확도는 아직 검증되지 않았습니다. 축척 미보정 도면의 픽셀을 실측 mm로 취급하지 마세요.
- 닫힌 바닥 경계는 비정형 외곽과 중정 구멍으로 생성할 수 있습니다. 열린 벽이나 교차하는 잘못된 외곽에 가짜 바닥을 채우지 않습니다.
- 새 Scene은 벽 구조·문 개구부·작품과 미배치 작품·저장 치수선을 함께 보관합니다. 벽을 추가하거나 삭제한 뒤에도 Scene을 다시 열면 당시 구조가 복원되며, 한 번의 Undo로 되돌릴 수 있습니다. 3D에서 저장한 Scene은 카메라 위치·방향·확대율도 기억하고 다시 열 때 3D 화면으로 전환합니다. 이전 버전의 Scene은 기존 방식대로 작품과 벽 표시 상태만 복원합니다. 조명 상태 저장은 아직 없습니다.
- PNG 캡처는 긴 변 1920/3840px 옵션을 제공합니다. PDF, GLB/glTF와 고급 Presentation은 후속 작업입니다.
- 고급 재질·사용자 조명·야외 태양·스냅 도구 전체·3D 모델 입력은 후속 작업입니다.
- 모바일에서는 편집 패널이 캔버스 아래로 이어집니다. 전체 편집 UX는 데스크톱을 우선합니다.
- 시작 시 예제 이미지가 표시되며 이는 생성된 샘플 작품입니다. 사용자의 실제 작품으로 교체할 수 있습니다.

## 제품 범위 결정

도면을 인식·보정해 3D 전시장으로 만드는 기능은 핵심 개발 범위입니다. 사진·2D 이미지에서 3D용 재질을 생성하는 Photo to Material은 MVP 이후 유료 기능으로 구현합니다. 작품 이미지의 기본 업로드·실제 크기 배치와 기본 재질 프리셋은 유지합니다. 구독/건별 과금, 요금, 결제 제공자는 아직 결정하지 않았으며 현재 코드에 결제 기능은 없습니다.

## 다음 개발 단위

다음은 관람객 눈높이 촬영, 공유 뷰어의 모바일 실기기·대형 전시장 성능 점검, 치수 측정 보조입니다. 도면 인식은 문·주요 설비 후보까지 가볍게 연결하고, 실제 도면 몇 종에서 초안 생성과 수정 비용을 확인합니다. 2D 이미지의 3D 재질 변환은 후속 유료 기능입니다.

### 도면 가져오기 및 축척 (0.2)
평면도 → **도면 불러오기** → PDF 페이지 선택 또는 이미지 확인 → 자동 분석 결과에서 **검증된 공간 초안 적용** 또는 **벽 초안으로 편집 시작**. 구조선 후보만 남은 도면도 벽을 바로 이동·삭제·추가할 수 있습니다. 축척 미정 초안에서는 벽 길이를 px로 표시하며 작품 추가와 3D·벽면도는 두 점 축척 보정 후 활성화됩니다. 같은 도면을 다시 불러와 **이 도면 배치**를 누르면 분석 결과만 갱신하고 편집한 벽·작품과 축척은 유지합니다.

축척 미정 벽 초안의 보정은 도면과 벽 좌표를 함께 실제 길이에 맞춥니다. 기존 mm 기반 공간에 참고 도면만 배치한 경우에는 도면의 크기만 바뀌며 벽·작품의 실제 크기는 유지됩니다. 닫힌 바닥 경계가 확정된 경우에만 3D 바닥을 생성합니다. 도면·축척·자동 후보 원본은 자동 저장과 JSON 내보내기에 포함됩니다.

PDF는 30MB/200페이지까지, 이미지는 20MB까지 지원합니다. PDF 원본은 업로드하지 않으며 선택한 페이지를 최대 2400px 이미지로 저장합니다. 부분 초안은 닫힌 바닥·문·창문을 임의로 만들지 않으며 벽 후보의 진위와 높이·두께는 아직 확정하지 않습니다.

### 전시장 전체 구조 기반 (0.3)
- 벽 선택 → **벽 용도**에서 `바닥 경계`와 `내부벽 / 가벽`을 선택합니다. 새 벽은 기본적으로 내부 가벽입니다. 외곽을 확장하려면 바닥 경계로 바꾸고 끝점을 연결하세요.
- 내부벽은 외곽과 맞닿아도 바닥을 제거하지 않습니다. 인접 공간의 공유벽은 내부벽 하나로 표현합니다. 아직 실별 이름/영역을 관리하는 기능은 없습니다.
- 닫힌 바닥 경계 내부의 또 다른 닫힌 경계는 중정 구멍으로 처리합니다. 중첩을 자동 해석하므로 내부 전시실의 벽은 반드시 내부벽으로 지정해야 합니다.
- 작품 선택 → **설치 면 A/B**로 가벽 양면에 배치합니다. 벽면도도 A/B를 따로 표시하며 B면은 좌우가 반전됩니다. 위치 숫자는 두 면 모두 벽 시작점 기준입니다.
- 벽 자동 숨김은 내부 가벽을 숨기지 않습니다. 전체 벽을 보려면 자동 숨김을 끄세요. 기본 시점은 전체 벽 범위와 높이에 맞춥니다.

`public/examples/whole-venue.json`은 16×12m 외곽, 3×4m 중정, 공유벽과 양면 작품을 가진 합성 예제입니다. 상단 불러오기에서 열 수 있습니다. 이전 작업은 가져오기 시 JSON으로 백업됩니다.

후속 작업: 원본 도면 보존·정밀 확대·축척 교차 검증, 문/창 개구부·기둥, 전시실 구획 관리, 실내 탐색 및 여러 층. 현재 업데이트가 전시장 전체 기능의 완성을 의미하지 않습니다.

### 복잡한 도면 입력 개선
PDF 가져오기에서 **고해상도 렌더**를 켜면 최대 4800px로 처리합니다. 평면도의 확대/축소·화면 이동·전체 맞춤으로 작은 구간을 확인할 수 있습니다. 이미지 도면은 PNG로 처리하고 최대 4096px로 제한하며 저해상도 입력은 확대하지 않습니다. 품질 안내는 검토를 돕는 기준이며 자동 치수 인식을 의미하지 않습니다.

웹 공개 도면 3종 검증에서 발견한 JBIG2 스캔 렌더 문제를 수정했습니다. PDF 지원 파일은 설치 후 자동 복사됩니다. 자세한 검증과 남은 작업은 `docs/reviews/2026-09-11-web-plan-tests.md`를 참고하세요.

### 회전과 평면 영역 선택
도면 가져오기 → **회전 / 영역 선택**에서 방향을 90도씩 바꾼 뒤 사용할 평면만 드래그하세요. 좌표/크기를 픽셀로 입력할 수도 있습니다. **선택 영역 자르기 → 미리보기로 돌아가기 → 이 도면 배치** 순서로 가져온 뒤 실제 길이로 축척을 보정합니다.

가져오기 창 안에서는 **원래 페이지로** 복원할 수 있습니다. 페이지나 고해상도 옵션을 바꾸면 회전·자르기가 초기화됩니다. 현재는 한 번에 하나의 평면 영역을 가져오며 기울기·원근 왜곡 자동 보정은 지원하지 않습니다.

### 벽 후보 찾기 (실험 기능)
평면도 → **벽 후보 찾기**에서 수평·수직 선 후보를 검토하세요. 맞는 선만 체크하고 도면 축척을 설정한 뒤 **선택한 벽 추가**를 누릅니다. 알려진 실제 길이의 후보 하나로 축척을 설정하거나 기존 두 점 보정을 사용할 수 있습니다. 높이와 두께는 직접 입력합니다.

선택한 후보는 기존 공간에 내부벽으로 추가되며 한 번에 되돌릴 수 있습니다. 이후 속성에서 끝점과 바닥 경계 용도를 조정하세요. 치수선·가구 등 오검출과 벽 누락이 있어 전체 전시장 자동 복원을 의미하지 않습니다. 사선/곡선/OCR/자동 접합은 아직 지원하지 않습니다.

### 문자 기반 자동 인식
도면 가져오기에 PDF 텍스트 추출과 한국어·영어 로컬 OCR을 연결했습니다. 평면도의 **설비 표기**에서 종류 확인·수정·오인식 제외가 가능합니다. 표기 위치만 추출하며 설비 점유 면적이나 설치 금지 영역은 아직 자동 계산하지 않습니다. 상세 검증과 한계는 `docs/implementation/progress.md`를 참고하세요.

숫자 후보는 단위 없는 표기도 포함합니다. 가져오기의 **숫자 정밀 다시 읽기**와 검토 화면의 원본 확대·숫자 정정 저장을 사용할 수 있습니다. 단위 없는 숫자는 자동으로 mm를 부여하지 않으며, 정정값은 원문과 함께 저장합니다.

확인한 단일 숫자는 **벽 치수에 연결**에서 대상 벽·종류·단위를 선택해 적용할 수 있습니다. 적용 전 변경값과 연결된 모서리 영향을 확인하세요. 길이 변경은 도면 축척을 바꾸지 않습니다.

축척을 보정한 도면에서는 숫자 근처의 벽을 최대 3개 추천합니다. **벽 치수에 연결 → 도면 위치로 찾은 벽**에서 원본과 후보를 비교해 선택하세요. 치수선 의미를 해석한 결과가 아닌 거리 기반 추천입니다.

**주변 치수선 분석**은 숫자 근처의 평행선과 양 끝 보조선이 벽과 맞는지 비교합니다. 검출 선을 도면에서 확인하고 길이 연결을 선택하세요. 현재 수평·수직의 연속 선을 대상으로 하며 화살표나 끊긴 치수선은 아직 해석하지 않습니다.

숫자 자리에서 끊긴 수평·수직 치수선도 양쪽 선과 보조선이 맞으면 후보로 묶습니다. 보라 점선은 검출된 원본 선이 아니라 추정 연결 구간입니다.

도면 가져오기에서 문자/숫자와 구조 선 분석이 자동 실행되고 결과가 함께 저장됩니다. 치수 교차 검증을 통과한 경우에는 전체 공간 초안을, 통과하지 못했지만 구조선 후보가 있는 경우에는 축척 미정 벽 편집 초안을 제안합니다. 후보 수는 정답 벽 개수나 전체 공간 복원 성공을 뜻하지 않습니다.

벽 그룹: Shift로 벽 두 개 이상 선택 → 속성 패널의 **그룹 만들기**. 멤버 한 개만 눌러도 전체가 선택되어 이동·회전·복제·삭제할 수 있습니다. 복제 그룹은 원본과 독립적이고, 그룹 해제·Undo/Redo·자동 저장·JSON·구조 Scene에서 유지됩니다. 속성 숫자 입력은 첫 번째 벽을 수정합니다. 작품/벽 혼합 그룹과 중첩 그룹은 아직 지원하지 않습니다.

작품 그룹: 같은 벽·같은 면의 작품을 Shift로 선택 → **작품 그룹 만들기**. 3D·벽면도 드래그와 설치 위치/벽 변경은 그룹 전체를 이동하고 상대 간격을 유지합니다. 크기·회전·프레임은 첫 작품만 수정하며 그룹 전체 회전은 아직 지원하지 않습니다. 복제 그룹은 원본과 독립되고 자동 저장·JSON·Scene·Undo/Redo로 유지됩니다. 벽 삭제로 미배치 보관 시 그룹은 해제됩니다. 자동 숨김 벽은 3D 마우스 선택에서도 제외합니다.
