# 공간 전시 편집기

소스 저장소: [taejunyun1/show_space](https://github.com/taejunyun1/show_space) · 기본 브랜치: `main`

[검증용 웹사이트 열기](https://gonggan-exhibition-preview.taejunyun.workers.dev) · [배포 기록](docs/deployment/cloudflare.md)

현재 우선 구현은 **도면의 대략적인 벽·치수 초안에서 공간을 직접 수정하고 작품을 배치하는 흐름**입니다. 문·주요 설비의 위치 후보까지만 자동 표시 대상으로 두고, 계단·설치 제외 면적의 정밀 생성과 독립 직접 편집은 보류합니다. 페이지·OCR·벽·치수를 항목별로 확인해야 편집이 시작되는 흐름은 피합니다.

[자동 초안 마일스톤 M0](docs/milestones/M0-automatic-plan-to-venue.md) · 상태: 미완료. [직접 편집 단계 계획](docs/implementation/2026-09-27-direct-space-editing-plan.md)의 E2 핵심 도구, E3 부분 도면 편집 진입, S1 보기 전용 공유, E4 작품 조작을 1차 구현했습니다. 3D 벽 이동은 연결된 끝점을 유지하고 끝점·100mm 격자로 맞춥니다. 전체 도면 자동 복원을 출시 조건으로 삼지 않습니다.

## 실행

Node.js 22.13 이상 또는 24를 권장합니다. 이 작업에서는 Node.js 24.14.0으로 검증했습니다.

```sh
npm ci
npm run dev
```

브라우저에서 http://127.0.0.1:5173 을 엽니다.

```sh
npm test
npm run build
npm run preview
```

## 지금 가능한 작업

- 상단 **도면·모델 불러오기**에서 도면 JPG·PNG·PDF, 저장 프로젝트 JSON·백업 ZIP, 정적 3D 참고 모델 GLB(12MB 이하) 선택
- GLB 원본 크기 유지, 위치·회전·배율·표시 조절, 로컬·JSON·Scene 저장 및 PNG 캡처
- **모델 벽으로 공간 만들기**: GLB의 닫힌 직선 벽·바닥을 편집 구조로 전환하고 작품 설치, 저장·캡처·읽기 전용 공유
- .skp 원본 변환, 곡면·문/창이 뚫린 벽의 편집 구조 전환은 아직 미지원. 가져온 전시장 GLB의 원본 형상은 보기 전용 링크에 포함

- 8,000 × 6,000mm 예제 전시장을 3D, 평면도, 벽면도로 확인
- 벽 추가·복제·삭제, 연결된 끝점 이동, 길이·높이·두께 입력
- 평면도 두 점 벽 그리기(W), 끝점·축·격자 스냅, 벽 전체 이동(M)·회전(Q), Shift 다중 벽 선택과 일괄 복제·잠금
- 작품 이미지 업로드, 실제 W/H/D, 설치 벽·중심 높이·벽 기준 거리 입력
- 이미지·3D 작품의 작가·연도·종류·설치 형식·재료·공개용 설명 입력, 잠금·Undo·Scene·JSON·자산 백업 유지
- 왼쪽 **3D 작품 추가**: 정적 GLB·glTF(자산 포함 또는 BIN/텍스처 동시 선택)·glTF ZIP을 실제 조각/설치 작품으로 등록
- 3D 작품 축 이동·XYZ 회전, 평면 드래그, 숫자 W/H/D·바닥에 놓기, 그룹·복제·삭제·잠금·Undo·Scene·자산 백업
- 벽면도 작품 드래그, Shift 다중 선택, 가장자리 기준 간격 정렬
- 손 도구(H)로 3D·평면도·벽면도 시점 이동, 3D 회전·휠 확대
- 작품과 벽 표시·잠금, 프레임 색상, 메모
- Undo/Redo, Scene 저장·복원, IndexedDB 자동 저장
- 프로젝트 JSON 불러오기·내보내기, 3D·평면도·벽면도 1920/3840px PNG 캡처
- 프로젝트 자산 백업: 모든 Scene·미배치/숨긴 작품·벽/바닥 텍스처·도면 이미지·참고 GLB·메모·치수를 `.gonggan.zip`으로 저장하고 다른 브라우저에서 복원
- Spot·Area 조명 추가: 3D 축 핸들/평면 이동, 밝기·2700–6500K·조준점, Spot 조사각/그림자, Area 면 크기, 복제·삭제·잠금
- 현재 전시 배치 GLB 내보내기: 벽·바닥·작품 이미지·표시 중인 참고 모델, 실제 크기와 회전 보존
- glTF 파일 묶음: `scene.gltf`·바이너리·이미지·포함/제외 보고서를 ZIP으로 저장하고 다른 3D 프로그램에 전달
- 전시안 PDF: 현재 배치와 선택한 Scene의 3D·평면·벽면도, 한글 글꼴, mm 치수 목록, A4 가로 출력
- 현재 배치와 선택한 최대 20개 Scene을 읽기 전용 링크로 공유, 3D·평면·벽면 열람, 링크 중단
- 공유의 **작품 상세 정보 공개** 선택: 재료·설명·작품 종류·설치 형식만 선택 공개하고 내부 설치 메모는 계속 비공개
- PDF/이미지 도면 자동 분석, 검증된 공간 초안 또는 축척 미정 벽 후보 편집 초안 적용, 원본 오버레이와 같은 도면 재분석 시 사용자 수정 보존

기본 프로젝트의 치수는 mm로 저장하고 3D 렌더링에서 meter로 변환합니다. 축척 미정 벽 초안의 평면 좌표·길이는 px로 유지하다가 보정 시 mm 좌표로 변환합니다. H 또는 손 버튼을 누른 뒤 드래그하면 세 화면의 시점이 이동하며 벽·작품은 움직이지 않습니다. V로 선택 도구에 돌아옵니다. 빈 3D 공간을 드래그하면 카메라가 회전하고 벽을 드래그하면 벽이 이동합니다. 작품은 3D·벽면도에서 배치하거나 숫자로 위치를 입력할 수 있습니다. 숫자는 Enter 또는 포커스를 옮길 때, 메모는 포커스를 옮길 때 적용됩니다. 적용 후 상단의 로컬 저장 완료 표시를 확인하세요. 단축키: Cmd/Ctrl+Z 되돌리기, Shift+Z 다시 실행, Cmd/Ctrl+D 선택 복제, Delete 삭제, Cmd/Ctrl+S 내보내기.

평면도에서 W를 누르고 시작점·끝점을 클릭하면 벽을 그립니다. 연속해서 다음 점을 선택하거나 Esc로 종료합니다. 벽을 Shift+클릭해 여러 개 선택한 후 함께 끌거나 Q로 회전합니다. 오른쪽 **연결된 벽 함께 수정**이 켜져 있으면 벽 전체 이동·회전에도 맞닿은 끝점을 유지합니다. 끄면 해당 벽만 움직입니다. 3D 벽 이동은 가까운 다른 벽 끝점 또는 100mm 격자에 맞춥니다. 예제 공간의 바닥이 사라진 경우 **기본 공간 배치 복원**으로 네 외곽 벽을 원래 위치로 되돌릴 수 있으며 작품 편집과 실행 취소 이력은 유지됩니다. 3D에서 작품을 드래그하면 가로 위치와 설치 높이가 10mm 단위로 바뀌고, 다른 벽 위에 놓으면 설치 벽도 바뀝니다. 선택 작품의 파란 점을 3D·벽면도에서 드래그하면 15° 간격으로 회전합니다. 오른쪽에서 각도를 직접 입력하거나 90° 버튼으로 돌릴 수도 있습니다. 벽을 삭제하면 그 벽의 작품은 왼쪽 **미배치 작품**에 보관됩니다. 배치할 벽을 고른 뒤 **배치**를 누르면 복원됩니다. 잠긴 작품이 붙은 벽은 잠금을 풀어야 삭제할 수 있습니다. T 또는 줄자 버튼으로 두 점을 클릭해 mm 거리를 재고 치수선을 남깁니다. 카메라 버튼으로 현재 3D·평면도·벽면도를 1920/3840px PNG로 저장합니다. 치수·격자·원본 도면 표시를 선택할 수 있습니다.

왼쪽 **스팟 추가 / 면조명 추가**로 조명을 만들고 오른쪽에서 밝기·색온도·위치·비추는 지점을 바꿉니다. 선택 조명은 3D의 세 축 핸들 또는 평면도의 점을 드래그해 이동합니다. 이동할 때 조준점도 같은 거리만큼 옮겨 방향을 유지합니다. **공간 기본 조명**에서 전체 밝기·주변광·보조광·환경 반사를 조절합니다. 조명은 최대 20개, 동시에 그림자를 계산하는 Spot은 최대 4개입니다. Area는 자체 그림자를 만들지 않습니다. GLB/glTF에는 Spot만 포함하며 Area·기본 밝기·메모와 Scene까지 복구하려면 프로젝트 자산 백업을 사용하세요. 화면 Kelvin은 배치안 비교용 근사 색상입니다.

## 현재 범위와 한계

- 편집 프로젝트는 브라우저의 단일 로컬 초안에만 보존되며 다른 기기로 자동 동기화되지 않습니다. 공유 버튼은 현재 공개 배치와 작품·표면 텍스처 이미지·표시 중인 3D 작품과 전시장 참고 모델 자산을 Cloudflare R2에 업로드합니다. 작성자 키를 가진 사람만 링크를 만들거나 중단할 수 있으며, 링크를 가진 사람은 로그인 없이 열람할 수 있습니다. 장기 편집 보관에는 프로젝트 자산 백업 ZIP을 사용하세요.
- 표시 중인 독립 3D 작품은 보기 전용 링크에 형상·UV·PBR 재질·크기·배치를 포함합니다. 공유 화면에서 이동·회전·삭제할 수 없습니다. 같은 모델은 한 번만 업로드하며 원본 GLB의 이름·extras·생성기 정보와 앱 내부 메모는 제외합니다. 표시 중인 전시장 참고 모델도 실제 형상·재질·XYZ 위치·Y 회전·배율을 포함합니다. 모델만 있는 전시도 공유할 수 있으며 평면의 점선은 바닥이 아닌 모델 범위입니다. 자산은 개별 12MiB·총합 80MiB·서로 다른 모델 자산 최대 51개(작품 50개와 전시장 1개) 이내입니다. 보기 잠금은 모델 파일 다운로드를 막는 기능이 아니며, 치수 비공개는 UI 표시를 끕니다. 모델에 포함된 이미지의 인코딩 메타데이터와 사용하지 않는 바이너리 영역까지 제거하지는 않습니다.
- 공유 링크는 생성 시점의 스냅샷입니다. 원본 도면·내부 메모·다른 Scene은 보내지 않으며, 기존 링크는 이후 편집에 따라 갱신되지 않습니다. 치수 공개 링크에서는 3D·평면·벽면의 **임시 줄자**를 사용할 수 있고 측정값은 저장되지 않습니다. 비밀번호·대상자 제한·작성자별 계정 관리는 아직 없습니다.
- 새 파일을 불러오기 전 현재 작업을 JSON으로 다운로드합니다. 업로드 이미지는 축소된 WebP로 JSON에 포함됩니다. 예제 이미지 경로는 앱에 포함된 자산을 참조합니다.
- **프로젝트 자산 백업**은 예제 작품도 해당 패널 PNG로 포함하고 등록된 이미지/GLB 바이트를 그대로 보존합니다. SHA-256와 크기·참조·편집 구조·이미지 디코딩을 검사한 뒤 복원하며 실패 시 기존 작업을 유지합니다. ZIP·압축 해제 총합·복원 JSON 각각 80MiB 이하, 자산 2,000개 이하입니다. 저장된 도면 이미지는 포함하지만 프로젝트에 보존하지 않은 원본 PDF/JPG 파일, Undo 기록·공유 관리 정보는 제외합니다. 압축을 풀지 말고 상단 **불러오기 → 저장 프로젝트**에서 `.gonggan.zip`을 선택하세요. glTF ZIP은 3D 전달용으로 이 기능과 다릅니다.
- 도면 입력은 PDF 페이지 선택과 PNG/JPG/WebP 이미지를 지원합니다. 두 점 축척 보정과 일부 자동 인식·공간 초안 생성이 가능하지만, 복잡한 실도면을 무개입으로 완성하는 정확도는 아직 검증되지 않았습니다. 축척 미보정 도면의 픽셀을 실측 mm로 취급하지 마세요.
- 닫힌 바닥 경계는 비정형 외곽과 중정 구멍으로 생성할 수 있습니다. 열린 벽이나 교차하는 잘못된 외곽에 가짜 바닥을 채우지 않습니다.
- 새 Scene은 벽 구조·문 개구부·작품과 미배치 작품·저장 치수선·개별 조명과 기본 밝기를 함께 보관합니다. 벽을 추가하거나 삭제한 뒤에도 Scene을 다시 열면 당시 구조가 복원되며, 한 번의 Undo로 되돌릴 수 있습니다. 3D에서 저장한 Scene은 카메라 위치·방향·확대율도 기억하고 다시 열 때 3D 화면으로 전환합니다. 이전 버전의 Scene은 기존 방식대로 작품과 벽 표시 상태만 복원합니다. 조명 값이 없던 이전 Scene은 현재 조명을 유지합니다.
- PNG 캡처는 긴 변 1920/3840px 옵션을 제공합니다. GLB·glTF는 현재 표시 중인 형상과 이미지·3D 작품 원본 형상/재질을 저장하며 메모·Scene·치수선은 JSON으로 보관합니다. glTF ZIP은 모두 압축을 풀고 `scene.gltf`를 glTF 2.0 지원 프로그램에서 엽니다. `buffers/`·`textures/`를 같은 위치에 유지하세요. 공간 참고 모델 입력은 정적 GLB(12MiB 이하), **3D 작품 추가**는 정적 GLB·glTF·glTF ZIP을 지원합니다. 작품 입력은 자산 총합 12MiB, 최대 50개이며 원본의 형상·UV·PBR 재질을 유지합니다. 움직임·스킨·모프·희소 정점·Draco/Meshopt/BasisU 압축·내장 조명은 제외합니다. 원본 SKP는 지원하지 않습니다. PDF는 현재 배치/선택한 Scene을 A4 가로로 출력하며 평면·벽면 선과 치수는 벡터, 3D는 이미지입니다. 기본 벽면도는 작품이 설치된 면이고 모든 표시 벽의 A·B면도 선택할 수 있습니다. 원본 참고 모델은 3D에 포함되며 평면·벽면도는 편집 벽 기준입니다. 내부 메모·원본 도면은 출력하지 않습니다. 출력 축척은 A4 100% 인쇄 기준으로 표시되며 용지 맞춤 시 달라집니다. 현재 프로젝트 스키마의 자산 백업 ZIP은 구현됐으며, 고급 Presentation은 후속 작업입니다.
- 기본 재질은 벽·바닥·작품 표면에 15개 색·반사 프리셋과 거칠기·금속성·불투명도·투과율·재질 두께·굴절률을 지원합니다. 벽/작품 속성의 재질 패널, 왼쪽 `바닥 · 재질`에서 편집하며 로컬 저장·Scene·백업·공유 스냅샷·GLB/glTF·PDF 3D에 연결됩니다. 거울은 환경 반사 근사이며 정확한 거울 상과 물성 재현은 지원하지 않습니다. 벽·바닥에는 JPG/PNG/WebP 텍스처를 직접 불러와 이미지 한 장의 실제 폭·높이(mm)를 조절합니다. 벽 길이나 바닥 면적이 바뀌어도 무늬 크기를 유지하며, 로컬·Scene·백업·읽기 전용 공유·GLB/glTF·PDF 3D에 같은 설정을 보존합니다. 입력 이미지는 20MiB·6,000만 픽셀 이하, 저장 긴 변 최대 2,048px이고 3D 교환 출력은 최대 1,024px입니다. 직접 반복만 적용하며 경계가 이어지는 무늬 생성과 Normal/Bump 생성은 포함하지 않습니다.
- 고급 반사·스냅 도구 전체·SKP 원본 입력과 복잡한 모델 변환은 후속 작업입니다.
- 모바일에서는 편집 패널이 캔버스 아래로 이어집니다. 전체 편집 UX는 데스크톱을 우선합니다.
- 시작 시 예제 이미지가 표시되며 이는 생성된 샘플 작품입니다. 사용자의 실제 작품으로 교체할 수 있습니다.

### 도면 가져오기 및 축척 (0.2)
상단 **도면·모델 불러오기 → 도면 불러오기**(JPG·PNG·PDF) 또는 평면도 **도면 불러오기** → PDF 페이지 선택 또는 이미지 확인 → 자동 분석 결과에서 **검증된 공간 초안 적용** 또는 **벽 초안으로 편집 시작**. 구조선 후보만 남은 도면도 벽을 바로 이동·삭제·추가할 수 있습니다. 축척 미정 초안에서는 벽 길이를 px로 표시하며 작품 추가와 3D·벽면도는 두 점 축척 보정 후 활성화됩니다. 같은 도면을 다시 불러와 **이 도면 배치**를 누르면 분석 결과만 갱신하고 편집한 벽·작품과 축척은 유지합니다.

축척 미정 벽 초안의 보정은 도면과 벽 좌표를 함께 실제 길이에 맞춥니다. 기존 mm 기반 공간에 참고 도면만 배치한 경우에는 도면의 크기만 바뀌며 벽·작품의 실제 크기는 유지됩니다. 닫힌 바닥 경계가 확정된 경우에만 3D 바닥을 생성합니다. 도면·축척·자동 후보 원본은 자동 저장과 JSON 내보내기에 포함됩니다.

PDF는 30MB/200페이지까지, 이미지는 20MB까지 지원합니다. PDF 원본은 업로드하지 않으며 선택한 페이지를 최대 2400px 이미지로 저장합니다. 부분 초안은 닫힌 바닥·문·창문을 임의로 만들지 않으며 벽 후보의 진위와 높이·두께는 아직 확정하지 않습니다.

### 전시장 전체 구조 기반 (0.3)
- 벽 선택 → **벽 용도**에서 `바닥 경계`와 `내부벽 / 가벽`을 선택합니다. 새 벽은 기본적으로 내부 가벽입니다. 외곽을 확장하려면 바닥 경계로 바꾸고 끝점을 연결하세요.
- 내부벽은 외곽과 맞닿아도 바닥을 제거하지 않습니다. 인접 공간의 공유벽은 내부벽 하나로 표현합니다. 아직 실별 이름/영역을 관리하는 기능은 없습니다.
- 닫힌 바닥 경계 내부의 또 다른 닫힌 경계는 중정 구멍으로 처리합니다. 중첩을 자동 해석하므로 내부 전시실의 벽은 반드시 내부벽으로 지정해야 합니다.
- 작품 선택 → **설치 면 A/B**로 가벽 양면에 배치합니다. 벽면도도 A/B를 따로 표시하며 B면은 좌우가 반전됩니다. 위치 숫자는 두 면 모두 벽 시작점 기준입니다.
- 벽 자동 숨김은 내부 가벽을 숨기지 않습니다. 전체 벽을 보려면 자동 숨김을 끄세요. 기본 시점은 전체 벽 범위와 높이에 맞춥니다.

`public/examples/whole-venue.json`은 16×12m 외곽, 3×4m 중정, 공유벽과 양면 작품을 가진 합성 예제입니다. 상단 불러오기에서 열 수 있습니다. 이전 작업은 가져오기 시 JSON으로 백업됩니다.

후속 작업: 원본 도면 보존·정밀 확대·축척 교차 검증, 문/창 개구부·기둥, 전시실 구획 관리, 실내 탐색 및 여러 층. 현재 업데이트가 전시장 전체 기능의 완성을 의미하지 않습니다.

### 복잡한 도면 입력 개선
PDF 가져오기에서 **고해상도 렌더**를 켜면 최대 4800px로 처리합니다. 평면도의 확대/축소·화면 이동·전체 맞춤으로 작은 구간을 확인할 수 있습니다. 이미지 도면은 PNG로 처리하고 최대 4096px로 제한하며 저해상도 입력은 확대하지 않습니다. 품질 안내는 검토를 돕는 기준이며 자동 치수 인식을 의미하지 않습니다.

웹 공개 도면 3종 검증에서 발견한 JBIG2 스캔 렌더 문제를 수정했습니다. PDF 지원 파일은 설치 후 자동 복사됩니다. 자세한 검증과 남은 작업은 `docs/reviews/2026-09-11-web-plan-tests.md`를 참고하세요.

### 회전과 평면 영역 선택
도면 가져오기 → **회전 / 영역 선택**에서 방향을 90도씩 바꾼 뒤 사용할 평면만 드래그하세요. 좌표/크기를 픽셀로 입력할 수도 있습니다. **선택 영역 자르기 → 미리보기로 돌아가기 → 이 도면 배치** 순서로 가져온 뒤 실제 길이로 축척을 보정합니다.

가져오기 창 안에서는 **원래 페이지로** 복원할 수 있습니다. 페이지나 고해상도 옵션을 바꾸면 회전·자르기가 초기화됩니다. 현재는 한 번에 하나의 평면 영역을 가져오며 기울기·원근 왜곡 자동 보정은 지원하지 않습니다.

### 벽 후보 찾기 (실험 기능)
평면도 → **벽 후보 찾기**에서 수평·수직 선 후보를 검토하세요. 맞는 선만 체크하고 도면 축척을 설정한 뒤 **선택한 벽 추가**를 누릅니다. 알려진 실제 길이의 후보 하나로 축척을 설정하거나 기존 두 점 보정을 사용할 수 있습니다. 높이와 두께는 직접 입력합니다.

선택한 후보는 기존 공간에 내부벽으로 추가되며 한 번에 되돌릴 수 있습니다. 이후 속성에서 끝점과 바닥 경계 용도를 조정하세요. 치수선·가구 등 오검출과 벽 누락이 있어 전체 전시장 자동 복원을 의미하지 않습니다. 사선/곡선/OCR/자동 접합은 아직 지원하지 않습니다.

### 문자 기반 자동 인식
도면 가져오기에 PDF 텍스트 추출과 한국어·영어 로컬 OCR을 연결했습니다. 평면도의 **설비 표기**에서 종류 확인·수정·오인식 제외가 가능합니다. 표기 위치만 추출하며 설비 점유 면적이나 설치 금지 영역은 아직 자동 계산하지 않습니다. 상세 검증과 한계는 `docs/implementation/progress.md`를 참고하세요.

숫자 후보는 단위 없는 표기도 포함합니다. 가져오기의 **숫자 정밀 다시 읽기**와 검토 화면의 원본 확대·숫자 정정 저장을 사용할 수 있습니다. 단위 없는 숫자는 자동으로 mm를 부여하지 않으며, 정정값은 원문과 함께 저장합니다.

확인한 단일 숫자는 **벽 치수에 연결**에서 대상 벽·종류·단위를 선택해 적용할 수 있습니다. 적용 전 변경값과 연결된 모서리 영향을 확인하세요. 길이 변경은 도면 축척을 바꾸지 않습니다.

축척을 보정한 도면에서는 숫자 근처의 벽을 최대 3개 추천합니다. **벽 치수에 연결 → 도면 위치로 찾은 벽**에서 원본과 후보를 비교해 선택하세요. 치수선 의미를 해석한 결과가 아닌 거리 기반 추천입니다.

**주변 치수선 분석**은 숫자 근처의 평행선과 양 끝 보조선이 벽과 맞는지 비교합니다. 검출 선을 도면에서 확인하고 길이 연결을 선택하세요. 현재 수평·수직의 연속 선을 대상으로 하며 화살표나 끊긴 치수선은 아직 해석하지 않습니다.

숫자 자리에서 끊긴 수평·수직 치수선도 양쪽 선과 보조선이 맞으면 후보로 묶습니다. 보라 점선은 검출된 원본 선이 아니라 추정 연결 구간입니다.

도면 가져오기에서 문자/숫자와 구조 선 분석이 자동 실행되고 결과가 함께 저장됩니다. 치수 교차 검증을 통과한 경우에는 전체 공간 초안을, 통과하지 못했지만 구조선 후보가 있는 경우에는 축척 미정 벽 편집 초안을 제안합니다. 후보 수는 정답 벽 개수나 전체 공간 복원 성공을 뜻하지 않습니다.

벽 그룹: Shift로 벽 두 개 이상 선택 → 속성 패널의 **그룹 만들기**. 멤버 한 개만 눌러도 전체가 선택되어 이동·회전·복제·삭제할 수 있습니다. 복제 그룹은 원본과 독립적이고, 그룹 해제·Undo/Redo·자동 저장·JSON·구조 Scene에서 유지됩니다. 속성 숫자 입력은 첫 번째 벽을 수정합니다. 작품/벽 혼합 그룹과 중첩 그룹은 아직 지원하지 않습니다.

작품 그룹: 같은 벽·같은 면의 작품을 Shift로 선택 → **작품 그룹 만들기**. 3D·벽면도 드래그와 설치 위치/벽 변경은 그룹 전체를 이동하고 상대 간격을 유지합니다. 크기·회전·프레임은 첫 작품만 수정하며 그룹 전체 회전은 아직 지원하지 않습니다. 복제 그룹은 원본과 독립되고 자동 저장·JSON·Scene·Undo/Redo로 유지됩니다. 벽 삭제로 미배치 보관 시 그룹은 해제됩니다. 자동 숨김 벽은 3D 마우스 선택에서도 제외합니다.

눈높이 촬영: 3D의 **눈높이 시점**에서 120/160/180cm를 선택합니다. 공간 경계 상자의 중심에서 선택 벽을 향하는 초기 투시 시점이며 손 도구로 구도를 옮기고 휠로 확대합니다. 기본 시점 버튼으로 조감도로 복귀합니다. 현재 화면 PNG, 투시 Scene 저장/복원 및 공유 카메라 스키마를 지원합니다. 초기 위치는 복잡한 공간의 내부를 보장하지 않으며, 충돌 방지·실제 보행·평면도에서 카메라 위치 지정은 후속 단계입니다.

2026-09-30 시점 중심으로 단순화: 3D 상단에서 **정면·좌측면·우측면·버드아이뷰**를 선택하고 **좌우 15°**로 회전합니다. 정면은 도면 좌표 +Z 방향에서 보는 기준이며 작품이나 벽을 변경하지 않습니다. 빈 공간 드래그 회전·손 도구 이동·휠 확대와 현재 화면 PNG를 사용합니다. 눈높이는 기타 시점으로 옮겼습니다. 사용자 요청에 따라 평면도 카메라 위치 지정·보행 기능은 진행 대상에서 제외합니다.

상단 **도면·모델 불러오기 → 저장 프로젝트 불러오기**는 전시 프로젝트 JSON을 복원합니다. 이전 작업은 별도 JSON 파일로 백업합니다. SketchUp 도면은 JPG·PNG·PDF, 모델은 GLB로 내보내 가져올 수 있습니다. GLB는 참고 모델로 보거나 **모델 벽으로 공간 만들기**로 전환합니다. 원본의 닫힌 직선 벽·수평 바닥만 변환하며 기존 작업은 JSON으로 백업하고 작품은 미배치 목록에 보관합니다. 가져온 바닥 경계는 벽 수정과 독립적으로 유지합니다. `.skp` 원본 입력은 아직 지원하지 않습니다.

상단 **내보내기 → 3D 모델**은 현재 배치를 하나의 GLB로 저장합니다. 표시 중인 벽·바닥·배치 작품과 참고 모델을 미터 좌표로 내보냅니다. 카메라의 벽 자동 숨김은 적용하지 않고 직접 숨긴 벽·작품, 미배치 작품, 원본 도면, 격자·선택 핸들·치수선·메모·다른 Scene은 포함하지 않습니다. 작품 이미지는 표시되는 패널만 잘라 긴 변 최대 1,024px로 파일에 넣습니다. 참고 모델 이미지와 벽·바닥 텍스처도 최대 1,024px로 내보내며 물리 크기 기반 UV·반복 설정을 포함합니다. 축척 미정 도면은 실제 치수 설정 후 내보낼 수 있습니다. 이미지 읽기가 실패하면 빈 작품으로 저장하지 않고 오류를 표시합니다. 앱의 GLB 다시 불러오기 제한은 12MB이며 초과 출력에는 안내를 표시합니다. GLB 재입력은 참고 모델 경로이고 기존 작품 편집 데이터까지 복원하려면 JSON을 사용합니다.


### 설치 메모·체크리스트·참고 사진

상단 **메모**에서 프로젝트 전체, 바닥 재질 창에서 바닥, 전시장 모델의 **전시장 모델 메모**, 선택 객체 속성의 **NOTE**에서 벽·작품·조명의 설치 정보를 기록합니다. 체크 항목과 JPG·PNG·WebP 참고 사진을 함께 저장할 수 있습니다. 메모는 로컬 자동 저장·Undo/Redo·JSON·프로젝트 자산 백업으로 보존되며 공개 공유·PDF·3D 출력에는 포함하지 않습니다.

텍스트 20,000자·체크 항목 100개·사진 8개까지 지원합니다. 참고 사진은 긴 변 2,048px로 줄여 저장하며 한 장 2MiB, 한 메모 8MiB, 프로젝트의 서로 다른 메모 사진 32MiB 제한이 있습니다. Scene 전환은 같은 객체의 최신 메모를 유지합니다. 이번 업데이트는 계정이나 클라우드 프로젝트 저장을 추가한 것은 아닙니다.


### 프로젝트 목록과 로컬 저장

상단 **프로젝트**에서 새 전시를 만들거나 저장된 프로젝트를 검색·열기·복제·보관할 수 있습니다. 새 전시는 너비/깊이/벽 높이(mm)와 실내/야외를 설정합니다. 보관된 프로젝트는 **보관된 프로젝트 보기**에서 복구할 수 있습니다.

기존 단일 초안은 목록으로 자동 이전됩니다. JSON·백업 ZIP을 불러오면 새 프로젝트 항목으로 추가하고 이전 작업을 유지합니다. 두 탭에서 같은 프로젝트를 바꾸면 오래된 저장을 거부하며 **현재 작업 복사본 만들기**로 보존한 뒤 최신 원본을 열 수 있습니다. 복사본을 저장하기 전에는 충돌 탭을 닫지 마세요. 로컬 저장 데이터는 현재 브라우저/주소에 속합니다. 계정·클라우드 저장 경로는 아래 단계에서 추가했습니다.


### 계정과 클라우드 프로젝트

상단 **계정**과 프로젝트 창의 **내 클라우드 프로젝트**를 추가했습니다. 첫 클라우드 저장 후 해당 프로젝트를 자동 저장하고, 다른 기기의 변경과 충돌하면 덮어쓰지 않고 복사본으로 보존합니다. 클라우드 파일에는 메모·사진·Scene·GLB 자산까지 포함되며 내 계정만 접근합니다. Cloudflare D1/R2 저장소와 마이그레이션은 준비했습니다.

현재 실제 Supabase 프로젝트 설정이 없어 배포 사이트는 **준비 중**으로 표시하며 로컬 저장을 계속 제공합니다. 실제 로그인·메일·Google OAuth·두 기기 왕복은 검증 전입니다. 필요한 설정과 제한은 [계정·클라우드 구현 기록](docs/implementation/2026-10-04-cloud-projects.md)을 참고하세요. 공개 공유 작성자는 기존 작성자 키 방식을 유지합니다.


### 여러 Scene의 보기 전용 공유

상단 **공유 → 함께 공유할 Scene**에서 공개할 저장 Scene을 선택합니다. 기본은 현재 배치만 공개하며 최대 20개의 Scene을 추가할 수 있습니다. 수신자는 링크 상단에서 배치를 전환하고 작품 기본 정보를 볼 수 있습니다. 내부 메모·참고 사진·원본 도면·미선택 Scene은 제외하며 이미 만든 링크는 이후 편집으로 바뀌지 않습니다. 치수 공개 선택은 포함된 모든 배치에 적용합니다.

전체 공유 JSON 1MB·이미지 자산 1,000개·모델 자산 51개/80MiB 제한을 넘으면 Scene을 줄여야 합니다. 공유 중단은 모든 Scene과 해당 자산에 적용합니다. 자세한 범위·검증은 [Scene 공유 구현 기록](docs/implementation/2026-10-04-presentation-sharing.md)을 참고하세요.
